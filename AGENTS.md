hashed source authority carries the mathematical statement and qualifications.

available. A successful status, restoration, build or byte audit is not a proof.

VERIFIED, ACCEPTED and older STATUS headings cannot override a later qualified
handoff. Preserve frozen source/certificate bytes; add wrappers and fresh

unpaid premises with decimal displays or cached verdicts.

imports before auditing probes. Keep Lean builds serial and do not upgrade
dependencies. The A25 framework acceptance is not the arbitrary-center

endpoints are maintainer-side storage, not public download services. Export
only hash-bound assets into new directories. No server or database service
configuration is needed to continue mathematical work.

When handing off work, update the affected order and next actions, attach
precise source hashes, record executed checks and their scope, and explicitly
list missing data and unpaid mathematical obligations. Update the delivery
manifest for maintained/new files; original proof entries must stay unchanged.
