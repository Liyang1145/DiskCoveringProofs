## 2. 代码层面的六个风险点（lead 指定）逐条结论

1. **acos/clamps**：`acos` 只对 `x ≥ 3/5` 实现（内部 `clip(x,'0.6',1)` 与 `clip((1−x)/(1+x),0,'0.25')`）；调用点前有 `assert b.a ≥ I('.6').b`。
   ⇒ **一致且安全**：越界会触发断言（实测 ✓），不会得到错值。代价是证书的**有效性依赖断言开启**（不得 `python -O` 运行）——见 §3.3。
2. **t 范围端点略超 asin R**：`TMAX = 0.3897962964742606…` ≈ asin(19/50) + 5.6e−17，且 `assert sin(TMAX).a > R.b`。
   ⇒ 覆盖的是**超集** [0, TMAX] ⊃ [0, asin R]，对"排除方向"是**保守**的（sound）。超端侧 `clip(R²−sin²t, 0, R²)` 只在 **t > asin R（不可容许区）** 起作用；跨端盒的包络仍包含全部可容许点的真值（逐项复核：sin 区间 ⊇、sqrt 区间 ⊇、cos 区间 ⊇）。**无静默夹掉可容许点**。
3. **两根**：`sgn ∈ {−1,+1}` 同时入栈 ⇒ 内/外根都覆盖。对"覆盖 ⇒ 容量不足"的用法是**保守超集**（外根不是覆盖构型），sound 但会略松；文档明确要求两者都在证书内 ✓。
4. **e 覆盖**：证书本身按 `row['e_interval']` 逐段复算；**并集覆盖 [0,7/50] 是我独立核对的**（§1 A3），不是只信生产者 flag。
5. **非负权重**：代码检验的是**支配性**足够条件 `a_0 ≥ Σ|a_k|`（对 boundary 与 hub 两块），实测 0 违例；目标 `B(e) > 0` 逐跑成立。
   ⚠ 注意：支配性 ⇒ 该三角多项式非负是**充分非必要**；证书用它作为非负性判据 → 只会更保守（sound），但**不等于**"权重非负"的完整刻画。
6. **递归逻辑（全部叶盒通过）**：
   `val = atom(box)`；**只当 `val.b < target.a` 才剪枝**，其余按最宽坐标二分继续；预算用 `assert d<70 and count<300000` **硬失败**。
   ⇒ 栈空 ⇔ 每盒的上界都低于目标 ⇒ 该域上 `Q(c;e) < B(e)/10` ✓。**无"silent pass"路径**（失败会抛异常），且实测无跑接近预算。另有 `ell.a ≥ 2R ⇒ 返回 out`（无弧交互分支）与 `assert b.a ≥ 0.6` 两处早退/断言，均只会在**越界时响亮失败**。

## 3. 发现（按严重度）

### 3.1 语义链不在本证书内（**信息，不是缺陷**）
证书证明的是"在给定权重与目标下，域内每盒的 `Q < B/10`"。**它不验证**
(i) `atom`/`Q` 的公式确实等于 M10-038-EXCLUSION §§3–4 里的每盘容量量；
(ii) `target = π(a_00+a_10)/10` 与"半覆盖"归一化一致；
(iii) `Σ_i Q(c_i;e) ≥ B(e)` 的覆盖论证与 `9B/10 < B` 的收尾（B>0 ✓ 已核）。
⇒ **HUB-ADJACENCY-DUAL.md 的算术前件可引用本证书；其语义步骤需另找 DIRECTIONAL-DUAL-PROOF.md / M10-038 §§3–4 的作者核对**（本审计未读审那一步）。

### 3.2 潜在脆弱点：`rows=[r for r in data['runs'] if r['pass']]`（建议一行加固）
复算脚本**只重放 `pass=True` 的行**。本数据集里**非 PASS 行 = 0**（已实测）且并集覆盖 [0,7/50]，所以当前结论不受影响 ✓；
但若日后 cover 文件出现 `pass=False` 行，脚本会静默跳过，而覆盖性只看生产者 flag ⇒ 形成"覆盖声明 ≠ 被复算行"的缺口。
**建议**（不属本任务）：在 `__main__` 加 `assert all(r['pass'] for r in data['runs'])` 或 `assert set(...) 覆盖 [0,7/50]`。

### 3.3 依赖运行纪律
`acos/atan` 的域限制与预算上限都是**断言**实现的。任何 `-O` 运行、或把断言改成 clamp，都会把"响亮失败"变成"静默错值"。
现有证书文件是在断言开启下产出的（命令无 `-O`，实测断言会触发 ✓）⇒ 引用时应连**复现命令**一起引用。

### 3.4 覆盖的紧性（口径，不是缺陷）
`[0,TMAX]×[−1,1]×E×{±1}` 是**可容许集的超集**（t 超端 5.6e−17、外根、以及 v 全区间）。方向正确（保守），但推论强度略低于可能的紧证书。
