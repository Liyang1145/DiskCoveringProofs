## 1. 模型（按 lead 给的标量）

对 hub j（|h_j|=s_j），其"hub 圈"要求由 **refined ring-neighbors + 另一 hub** 覆盖：

```
βmax(s) = acos( ((1−r) − s) / (2r) )        （单 ring 盘对 ∂B(h_j,r) 的最大半弧，用 ell_min）
βhh     = acos( d / (2r) )  if d=|h₁−h₂| ≤ 2r, else 0
NEC_j   = N_j · βmax(s_j) + βhh ≥ π
```

## 2. 校准（**必须可行** → 通过）

保存的 q=0 认证对象（ring [1,3,4,5,6,7,8,9,10]；hubs |h| = 0.149428, 0.272977；d = 0.422406，βhh = 0.981475；胞剖分实测 K=13、k=(7,6)、hubs 共享边 ⇒ N=(6,5)）：

| hub | s | N_j | βmax | N·βmax+βhh | ≥π |
|---|---|---|---|---|---|
| 1 | 0.149428 | 6 | 0.903107 | **6.400118** | ✓ |
| 2 | 0.272977 | 5 | 1.096617 | **6.464559** | ✓ |

另：该对象上 ∂B(h_j,r)∩D 由 ring 盘 + 另一 hub 覆盖的抽样缺口 = **0/36000（两个 hub 都是）** ✓ ⇒ 模型**前件在该对象上成立**（注意：ring 盘**单独**覆盖时缺口 11245/36000，即 βhh 项是必需的）。

## 3. 解析裁决：**排不掉 N_j = 2，也排不掉 N_j = 3**（method gap）

βmax(s) 关于 s **递增**（ell=(1−r)−s 递减），βmax ∈ [βmax(0), π/2) = [0.6155, 1.5708)；βhh ≤ π/2。

* **N=2**：NEC 最有利情形（βhh=π/2, d=0）需 `βmax(s) ≥ π/4 = 0.7854` ⟺ **s ≥ 0.082599**。
  可容许窗 s∈[0, 0.62)、且 min(s₁,s₂) ≤ 0.294618 ⇒ 窗 **[0.0826, 0.2946] 满足 NEC** ⇒ **N=2 不被排除**。
* **N=3**：最有利情形需 `βmax(s) ≥ π/6 = 0.5236` ⟺ s ≥ **−0.0382**（空下界）⇒ 所有可容许 s 都满足 ⇒ **N=3 不被排除**。
* 反方向：只有 N=2 且 s_j < 0.0826（且 d 接近 0）才可能被 NEC 排斥 —— 与"hub 度数极端"要排的情形（k_j=3 ⇒ N_j ≤ k_j−1 = 2，其 s_j 无小值保证）**不重合**。
* 量化松弛度：保存对象上 `Σ_j (N_j βmax + βhh) = 12.865` vs 目标 `2π = 6.283` ⇒ 标量总量是需求的 **2.05×**，属**非常松**。

## 4. 两个必须写明的 scope（此模型不能直接当必要条件用）

1. **前件非自动**：∂B(h_j,r) 上的点被 hub j **自身**的盘平凡覆盖 ⇒ "必须由 ring-neighbors + 另一 hub 覆盖"**不是**覆盖的一般必要条件；它成立需要额外论证（例如把对象换成 **hub 胞边界 ∂V_j 中不在 hub j 盘内的部分**，或换成"非 hub-j 覆盖"的那一段弧）。本文件对保存对象只做了**抽样校准**（缺口 0），未证明该前件。
2. **标量的两处松**：(i) 对每个邻居都用 **ell_min**（实际 |c_i−h_j| ≥ ell_min ⇒ 实际弧更小），(ii) 完全丢掉了 ring 盘自身的外弧耦合 `t_i`、`ρ(t_i)` 与 `Σ_i 2t_i ≥ 2π`。

## 5. 可复用的更紧必要性（LP 形态，供后续，不在本轮实现）

存在服务分配 σ：两 hub → ring 盘子集 S_j（N_j=|S_j| 受 refined 度数界）使得

```
∀j:  Σ_{i∈S_j} acos( min(1, |c_i−h_j|/(2r)) ) + βhh ≥ π ,
|c_i−h_j|² = ρ(t_i)² + s_j² − 2ρ(t_i)s_j cos(φ_i−ψ_j),
约束: t_i∈[t0, asin r], Σ_i 2t_i ≥ 2π, overlap/private-part 合法, 核心域 (D1)/(D3)
```

这把"每邻居都是 ell_min、且外弧自由"两处松弛换成 **t/ρ 耦合 + 总外宽预算**；在 q=1、K=12/13、k_j 极端（3 或 3+1 的 star）上才会真正有咬合的可能。

## 6. 结论（本任务到此停止）

按 lead 指示：**纯角容量标量不能排除 N=2/3 ⇒ 记录 method gap 并停**。校准通过（保存 q=0 对象可行、前件抽样成立）；下一步若继续，应做 §5 的 LP/资源界（需要 refined 双度数界与 t/ρ 耦合），而不是加样本或加精度。
