# Uniform endpoint lower bound from inwardness
For any genuine inward ring center c and any unit-circle point P, assume actual allowance r>=3/8 and |c|²<=1-r². Then
 |P-c| >=1-|c| >=1-sqrt(55)/8.
Consequently, in fixed R0=19/50 units, every covered endpoint has
 u=|P-c|/R0 >=(50/19)(1-sqrt(55)/8) >19/100.
The last strict comparison is exact: sqrt(55)<9278/1250=7.4224, since 9278²-55*1250²=143784>0 (exact integer arithmetic). The same bound holds for v. Together with u,v<=1 this gives
 |d|=|log(u/v)|/2 < log(100/19)/2.
This is a uniform local endpoint separation, stronger than the pair-center-separation argument for this object. It does NOT improve the lower bound for arbitrary site-site edges or all twenty circumradii.

For the C844 relaxed domain, the same conclusion follows by realizing the nondegenerate triangle on a unit chord: C844's lower allowance part is exactly |c|²<=1-(3/8)². Degenerate alpha=pi is handled by its explicit u=v>=75/76 fiber. Thus these endpoint bounds also safely restrict the explicit C846 fiber representation.
