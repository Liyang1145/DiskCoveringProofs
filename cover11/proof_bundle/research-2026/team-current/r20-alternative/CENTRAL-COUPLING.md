## 0. 记号与对象

- 环位点（固定）：`c_a, c_b ∈ R²`（q0(6,7) 图中"中央"两个 site，即两 hub 与环的邻接三元组涉及的环位）；
- 半径（固定）：`r > 0`；两凸 hub 域（固定、凸、代数边界）：`K_A, K_B ⊂ R²`；
- 变量：`h_A ∈ K_A`、`h_B ∈ K_B`（各 2 个坐标，合计 4 个）；
- 中央约束（两条）：`R_c(h_A, h_B, c_a) ≤ r` 与 `R_c(h_A, h_B, c_b) ≤ r`。

## 1. 精确多项式约束（4 变量、无根号）

对三点 `P,Q,S`（互异、非共线）：`A₁=|Q−S|²`、`A₂=|S−P|²`、`A₃=|P−Q|²`、`X = cross(Q−P, S−P) = 2·面积`，则

```
R_c(P,Q,S) ≤ r   ⟺   A₁ A₂ A₃  ≤  4 r² X²          （X ≠ 0；X = 0 为共线退化支）
```

于是两条中央约束即

```
G_a(h_A,h_B) := |h_B−c_a|²·|c_a−h_A|²·|h_A−h_B|² − 4 r²·cross(h_B−h_A, c_a−h_A)²  ≤ 0      (X_a ≠ 0)
G_b(h_A,h_B) := |h_B−c_b|²·|c_b−h_A|²·|h_A−h_B|² − 4 r²·cross(h_B−h_A, c_b−h_A)²  ≤ 0      (X_b ≠ 0)
```

- `G_a, G_b` 是 **(h_A,h_B) ∈ R⁴ 上的 6 次多项式**（各坐标 6 次；`|h_A−h_B|²` 与 `cross²` 皆多项式，系数全有理若数据有理）。
- Hub 域约束按边界类型分别写成有限多项式不等式：`K_A` 为多边形 ⇒ 线性不等式；为圆盘交 ⇒ `|h_A−q|² ≤ ρ²`。
  ⇒ **整个中央耦合 = R⁴ 中有限个多项式不等式的合取**（半代数集）。
- **退化支必须显式**：`X_a = 0`（三点共线）时 `R_c` 未定义/发散；多项式形式在该支**恒不成立**（除非某边长为 0）。
  故正确写法是 `G_a ≤ 0 ∧ X_a ≠ 0`；而 `h_B = h_A`、`h_B = c_a`、`h_A = c_a` 等边长 0 的退化需按
  "极限是否可行"逐支处理（**本件不决定**，只标出必须入域）。

## 2. Crescent 表示（固定 h_A 后，h_B 的可行集 = 两个"月牙"）

固定 `h_A` 与 chord `(h_A, c)`（`c` 为某 site），令 `d = |h_A−c|`、`m = (h_A+c)/2`、
`n = perp(c−h_A)/d`、`k = √(r²−d²/4)`、`p_± = m ± k n`。

- 由 **R21 Claim 1（已证，见 `R21-PAIR-CONTROL.md`，常数已更正为 4）**：在 `+n` 侧
  `R_c(h_A,h,c) ≤ r ⟺ |h−p_+| ≤ r ∧ |h−p_−| ≥ r`；在 `−n` 侧为镜像（`p_+ ↔ p_−`）。
- ⇒ 单条中央约束的可行集 = **两个月牙之并**（**注意用"闭外" `≥`**）

```
Crescent(chord) = ( B(p_+,r) ∩ {|h−p_−| ≥ r} )  ∪  ( B(p_−,r) ∩ {|h−p_+| ≥ r} )
                = ( B(p_+,r) \ int B(p_−,r) )   ∪  ( B(p_−,r) \ int B(p_+,r) )
```
（若把 `≥` 误写成 `>` 则得到 `\ B` 的**另一个**集合——见下条更正。）

- ⇒ 给定 `h_A`，**两条**中央约束 + hub 域 = `K_B ∩ (C_a⁺ ∪ C_a⁻) ∩ (C_b⁺ ∪ C_b⁻)`
  = **至多 8 个闭盘的 Boolean 组合** ∩ 凸域 `K_B`。
- **退化（第二次更正，lead team-message-3734c9b5）**：
  - `d > 2r` ⇒ 该约束**空**（无半径 `r` 的圆过此 chord）✓；
  - **`d = 2r`（`k = 0`）⇒ 用"闭盘 ∩ 闭外"形式恰好给出整条 Thales 圆 `∂B(m,r)`（1 维）**：
    `{|h−m| ≤ r} ∩ {|h−m| ≥ r} = {|h−m| = r}` ✓。
    *更正留痕*：上一版说"crescent 给空集/塌缩单点"**错**——那是把 `≥` 换成 `>`（即 `B \ B`）所致；
    正确形式（`≥`，即 `B \ int B`）在 `k = 0` 处**不失效**，且恰为整圆（可含任意多非共线点）。
    ⇒ 该圆须按 1 维 stratum 保留（§3 的 W₀/W₁ 覆盖）。

**谓词必须严格三态区分（lead 要求）**：对每个盘 `B(q,ρ)` 与点 `h` 取
`σ ∈ {<, =, >}` 由 `|h−q|² ⋚ ρ²` 决定，并分别处理：
| 语义 | 集合 | `=` 是否通过 |
|---|---|---|
| 闭内 | `\|h−q\| ≤ ρ` | **通过** |
| 开内 | `\|h−q\| < ρ` | 不通过 |
| 闭外 | `\|h−q\| ≥ ρ` | **通过** |
| 开外 | `\|h−q\| > ρ` | 不通过 |

**中央约束用（闭内, 闭外）**（Claim 1 的两条子句都是非严格）；`B \ int B` 与 `B \ B` 是两个不同集合，
本件所有 `Ω` 的写法都必须标注是 `\ int B`（含边界圆）还是 `\ B`（不含）✓。

## 3. 完整有限构造 + 覆盖证明（vertical/cylindrical decomposition；替代上一版"canonical 中心表"）

> **更正留痕（lead, team-message-13362717）**：上一版用"圆盘圆心 + 交点 + 包含判据"的候选表，
> 被 lead 判为**假完备**（中心可能落在其它盘内）。下面给出**正确的有限构造**与覆盖证明；
> 只做解析与有理控制，不做 global optimizer。

**对象**：`Ω = K ∩ ⋂_{i∈I} D_i ∩ ⋂_{j∈J}(R² \ int D_j)`，`D_i = B(q_i, ρ_i)` 闭盘，`K` 紧凸（圆盘或多边形）。
排列 `𝒜 = {∂D_i} ∪ {∂K}`。

**临界 x 集（有限）**：
```
Ξ := { q_{i,x} ± ρ_i（各圆左右极值） }
   ∪ { ∂D_i ∩ ∂D_j 的 x 坐标（i<j，含相切） }
   ∪ { ∂D_i ∩ ∂K 的 x 坐标 }            （K 为多边形时再加线-线与线-圆交点、K 顶点 x）
```

**见证集 W（显式有限，全部可代数计算）**：
- **W₀（0 维）**：所有 `∂D_i ∩ ∂D_j` 交点、`∂D_i ∩ ∂K` 交点、`K` 的顶点；
- **W₁（1 维，覆盖每条弧）**：
  (a) 对每个 `ξ ∈ Ξ` 与每个圆：该竖线上的实根点（圆 ∩ 竖线）；
  (b) 对每个**开条带** `(ξ_k, ξ_{k+1})`（`x_mid := (ξ_k+ξ_{k+1})/2`）与每个圆：该 x 处的两个实根点；
- **W₂（2 维，覆盖每个胞腔）**：
  (a) 对每个开条带、在 `x = x_mid` 上，对所有**相邻根之间的区间**（含最外根到 `K` 竖直上下界的区间）各取区间中点；
  (b) 对每条**临界竖线** `x = ξ`，同样取相邻根之间的区间中点。

**命题（覆盖）.** `Ω ≠ ∅  ⟺  ∃ w ∈ W : w ∈ Ω`。

**证明（完整）**
1. `Ω` 是闭盘与开盘补的有限 Boolean 组合；对 `h ∈ Ω` 定义符号向量
   `σ(h) ∈ {in, on, out}^{m} × {in, on, out}_K`（按 `|h−q_i|² ⋚ ρ_i²`）。
   `Ω` 的谓词只依赖 `σ`（必需盘取 `in/on`，禁止盘取 `out` 严格），
   且同一 `σ` 的点集是**相对开**的排列 strata；故 **`Ω` = 满足谓词的 strata 之并**。
2. **2 维 strata**：非空开胞腔 `C` 的 x-投影含一个开区间，去掉有限个 `Ξ` 点后仍非空
   ⇒ `C` 与某开条带相交；条带内无事件（`Ξ` 已含全部极值与交点 x）
   ⇒ 该条带内各圆竖线根的**顺序不变**，`C` 的截面恰是某个相邻根区间
   ⇒ 该区间的 `x_mid` 中点（W₂(a)）属于 `C` ✓。
3. **1 维 strata**：圆上两相邻顶点间的开弧 `γ`：若其 x-投影非退化，则与某开条带相交，
   该条带内 `x_mid` 处圆的两个实根之一（W₁(b)）落在 `γ` 上 ✓；
   若 x-投影退化为单点（竖直弧/极值点），该点属 `Ξ`，由 W₀ 或 W₁(a) 覆盖 ✓。
4. **0 维**：顶点 ∈ W₀ ✓。
⇒ 每个非空 stratum 都含 W 中一点 ⇒ 命题成立。**有限性**：`Ξ` 有限（每对圆 ≤2 个交点 x + 2 个极值），
每个 x 处根数有限，`K` 紧 ⇒ `W` 有限且可显式枚举 ✓。
（`|W| = O((m+2)² · m)` 量级；实现时可用 `x_mid` 与根的中点坐标的有理/代数表达式。）

**strict / inclusive 谓词处理（三态区分，lead 要求）**
- 谓词表（对每个盘）：闭内 `≤`（`on` 通过）、开内 `<`（`on` 不通过）、闭外 `≥`（`on` 通过）、开外 `>`（`on` 不通过）；
- **中央约束的两条子句是（闭内, 闭外）**；`B \ int B`（含边界圆）与 `B \ B`（不含）是不同集合，逐处标注；
- 见证坐标一般含**多个独立平方根**：`x_mid` 由代数临界 x 中点给出、根为 `q_y ± √(ρ²−(x_mid−q_x)²)`,
  故比较应标为 **real algebraic number 精确比较**（隔离区间 + 在 `Q(√s)`/多重根式或 CAD 内的精确符号判定），
  **不能一律用 `Q(√s)`**；本件的 `Q(√s)` 实现只覆盖**设计好的有理控制**（见 §4b 脚注）。
- 落在 `K` 外的候选点直接丢弃（不会丢覆盖：`Ω ⊆ K` ✓）。

**退化必须显式入域**：圆-圆相切（单点）、三圆共点、`∂K` 与圆相切、`∂D_i = ∂D_j`（重圆，先去重）、
以及 §2 的 `k = 0`（Thales 圆，1 维）——这些事件的 x 坐标均已包含或应加入 `Ξ`/W₀。

## 4. 有理正负例（精确 Fraction 算术，两条**独立**路径互检）

数据（全有理）：`r = 5`，`h_A = (6,0)`，`c_a = (0,0)`，`c_b = (6,6)`（两 chord 长均为 6 ⇒ `k = 4` 有理 ⇒ `p_±` 有理）。
路径 1 = 多项式判据 `A₁A₂A₃ ≤ 4r²X²`；路径 2 = 独立月牙判据（直接比较 `|h−p_±|²` 与 `r²`）。

| 例 | `h_B` | 多项式判据 `(h_A,h_B,c_a)` | 月牙判据（同 chord） | 多项式判据 `(h_A,h_B,c_b)` | 月牙判据 |
|---|---|---|---|---|---|
| **P1 正例** | `(3,4)` | `22500 ≤ 57600` ✓ | ✓（`|h−p_−|²=0 ≤ 25`，`|h−p_+|²=64 ≥ 25`） | ✓ | ✓（`2 ≤ 25`，`50 ≥ 25`） |
| **N1 负例（混合）** | `(3,1/2)` | `12321/4 > 900` ✗ | ✗（`81/4 ≤ 25` 但 `49/4 < 25`） | ✓ | ✓ |

| 负例 | `(9,1)` | `29520 > 3600` ✗ | ✗ | ✓ | ✓ |

**两路径在 4 个例子上逐例一致** ✓（脚本输出为证）。

**含于内部（无边界交点）正例**：`K_B = B((3,4),1)`：
- chord `h_A–c_a`：`p_− = (3,4)`、`|c_B−p_−|² = 0 ≤ (r−r_B)² = 16` ✓ 且 `|c_B−p_+|² = 64 ≥ (r+r_B)² = 36` ✓
  ⇒ `K_B ⊆` 该 crescent（**整个盘**，无需任何边界交点）；

- ⇒ 该 `K_B` 与 4 个 crescent 圆**无边界交点**，非空性由 **canonical 见证点 = 盘心 (3,4)** 检出 ✓
  —— 这正是命题 §3 第 2 条要覆盖的"contained region"情形。
