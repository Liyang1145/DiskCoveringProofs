## §1 对象、必要界与排除判据（D = ring 端点间距，d = hub 距离）

**对象**：半径 `r > 0`；hub 域 `K_A, K_B`（C879 链式 pin 盘交，可选 append 范数盘，见 §5）；两个共享 ring 端点 `c0, c4`；
两个中央三角形 `(hA,hB,c0)`、`(hA,hB,c4)` 均有正面积且 circumradius ≤ r。记
`d := |hA − hB|`，`D := |c0 − c4|`，`m := (hA+hB)/2`，`e := (hB−hA)/d`，`n ⊥ e` 单位，`k := sqrt(r² − d²/4)`，`p_± := m ± k n`。

**引理 1（crescent 包含；比旧版/lead 版少一个假设）** 对 `c ∈ {c0,c4}`：
`ρ(hA,hB,c) ≤ r ⇒ c ∈ B(p_+,r) ∪ B(p_−,r)`。
证明：写 `c = m + x e + y n`。恒等式
`4y²(ρ² − r²) = (|c − p_+|² − r²)(|c − p_−|² − r²)`
（符号验证：A1 残差 = 0）。`ρ ≤ r` ⇒ 左端 ≤ 0 ⇒ 右端两个因子至少一个 ≤ 0（`y = 0` 时乘积 = 0，仍至少一个因子 = 0），
即 `c` 落在某个 `B(p_ε,r)` 中。∎
**注意**：`{ρ ≤ r}` 是 `B(p_+,r) ∪ B(p_−,r)` 中**挖掉两者交集（lens）**后的部分（"exactly one"），
但这只影响"哪一侧"的细分，不影响下面的包含式用法。

**引理 2（span 上界；不需要"对侧"假设）** `d ≤ 2r` 且 `D ≤ 2r + 2k`。
证明：`d ≤ 2r` 是因 circumradius ≥ 最长边/2。对 `c0, c4` 用引理 1：
若两者落在**同一个**盘 ⇒ `D ≤ 2r ≤ 2r + 2k`；若落在**不同**盘（不妨 `c0 ∈ B(p_+,r)`、`c4 ∈ B(p_−,r)`）⇒
`D ≤ |c0 − p_+| + |p_+ − p_−| + |p_− − c4| ≤ r + 2k + r`。∎
（旧版/lead 版把"c0,c4 在 hub 边对侧"列为假设：其实"同侧"自动给出更强的 `D ≤ 2r`，所以无需假设，只需分支。）

**推论（排除判据）** `D ≥ 2r ⇒ d² ≤ 4rD − D²`，等价地 `d² + (D − 2r)² ≤ 4r²`。
证明：`D − 2r ≤ 2k`，且 `D ≥ 2r` ⇒ 两边非负 ⇒ `(D−2r)² ≤ 4k² = 4r² − d²`（A2 恒等式残差 = 0）。∎

**分支表（必须显式）**
| 分支 | 结论 | 用途 |
|---|---|---|
| `D > 4r` | `4rD − D² < 0 ≤ d²` | **直接排除**，不需要算 `dist` |
| `2r ≤ D ≤ 4r` | `d² ≤ T(D) := 4rD − D² ∈ [0, 4r²]` | 主分支：`dist² > T(D)` ⇒ 排除 |
| `D < 2r` | **只有 `d ≤ 2r`**，无 span 信息 | 退到 `L > 4r²`；**不得**把 `D−2r` 平方外推（A5 精确有理反例） |

**环盒版本**（环位置在盒里，`D ∈ [D_lo, D_hi]`）：`T` 在 `[2r, ∞)` 上单调**递减**
（恒等式 `T(D_lo) − T(D_hi) = (D_hi − D_lo)(D_hi + D_lo − 4r) ≥ 0`，A3 残差 = 0）。因此
`D_lo ≥ 2r` 时用 `T(D_lo) = 4rD_lo − D_lo²` 作**上界**；`D_hi < 2r` 时 span 无排除力；`D_lo < 2r < D_hi` 时按 D 切开或退到 `d ≤ 2r`。
**求值严格性**：比较的是 `L`（`d²` 的**下**包络）与 `T` 的**上**包络；**严格 `>` 才排除**，等号不判定。

**A5 精确反例（说明 `D<2r` 分支不可外推）**：`r = 1`，`hA = (−3/5,0)`，`hB = (3/5,0)`（`d = 6/5`，`k = 4/5`），
`c0 = (1/2,1/10)`（上侧），`c4 = (1/2,−1/10)`（下侧，对侧）。两个 circumradius² 均 = `61/100 ≤ 1`（正面积 ✓），
但 `D = 1/5 < 2r = 2` 而 `d² = 36/25 > 4rD − D² = 19/25` ⇒ **"无条件"写法在此分支为假**，分支限制是实质的。

## §2 主 template：无 CQ 的二次对偶（照抄 `lead/HUB-DISTANCE-QUADRATIC-DUAL.md` (1)，不重复猜 KKT 强对偶）

`K_A = ∩_i B(p_i,r_i)`、`K_B = ∩_j B(q_j,s_j)`。任取 `α_i, β_j ≥ 0`，令
`A = Σα`、`B = Σβ`、`P = Σα_i p_i`、`Q = Σβ_j q_j`、`T = Σα_i(|p_i|²−r_i²) + Σβ_j(|q_j|²−s_j²)`、`Δ = A+B+AB > 0`。则对**任意**可行对
```
|a − b|²  ≥  L := T − ((1+B)|P|² + 2P·Q + (1+A)|Q|²)/Δ .                    (1)
```
证明（两行，无 KKT、无 Slater、无极小点存在性、无 a,b 优化变量）：可行对使 `Σα_i g_i(a) + Σβ_j h_j(b) ≤ 0`，故
`|a−b|² ≥ Φ(a,b) := |a−b|² + Σα_i g_i(a) + Σβ_j h_j(b)`；`Φ` 的二次型每坐标 `M = [[1+A,−1],[−1,1+B]]`，`det M = Δ > 0` 且
主元正 ⇒ 无约束 `inf Φ = T − [P,Q]^T M^{-1}[P,Q]`，即 (1)。∎（`K_A` 或 `K_B` 为空时结论空真，配置另行排除。）

**ring-only 排除判据**（用 §1 的推论，D/d 口径正确）：
```
D ≥ 2r  且  L > 4rD − D²        ⇒  这些环上不存在完整覆盖.                (2)
D < 2r  时只能用  L > 4r²（即 d ≤ 2r）；D > 4r 直接排除。
```
**用法/求值注意**：`α, β` 取**有理数**（例如 pin 上的固定权重、或从 variance/KKT 校准得到的四舍五入有理权重）；
`Δ > 0` 之后可交叉相乘避免分母包裹；盒情形取 `L` 的下包络与 `T` 的上包络；**primal 可行对只能给上界，不能用于排除**。

## §3 duality 与 finite support 的正确解析（本次修复的核心）

**3.1 无条件成立的两条**
1. **lead (1)**：弱对偶下界，对任意非负乘子有效；不依赖 CQ、不依赖 `K_A,K_B` 有内点、不依赖强对偶或极小点存在。
   这正是无 CQ 场景（含 singleton）可用的主器械。
2. **分离恒等式**：`dist(K_A,K_B) = max_{‖u‖≤1} [ min_{a∈K_A}⟨u,a⟩ − max_{b∈K_B}⟨u,b⟩ ]`（凸紧集恒真）。
   ⚠ 恒等式恒真，但把它变成**有限可算**的 support 表（`u` 由 active 集生成、每 hub ≤2–3 个 active 盘）就要 CQ，见 3.2。

**3.2 有条件的部分：Slater ⇒ normal cone = active gradient cone（引理 3）**
设 `K = ∩_i B(p_i,ρ_i)` 且 `int K ≠ ∅`（等价：存在一点严格在所有盘内）。则对每个 `x ∈ K`，
`N_K(x) = cone{ x − p_i : i ∈ act(x) }`（`act(x) = {i : |x−p_i| = ρ_i}`）。
证明：记 `g_i(x) = |x−p_i|² − ρ_i²`，线性化锥 `L(x) = {v : ⟨∇g_i(x), v⟩ ≤ 0 ∀ i ∈ act(x)}`。
`N_K(x) = L(x)°` 只需 `T_K(x) = L(x)`（反包含恒真）。取严格可行点 `x0`（`g_i(x0) < 0 ∀i`），任取 `v ∈ L(x)`：
对 `i ∈ act(x)` 由凸性 `⟨∇g_i(x), x0 − x⟩ ≤ g_i(x0) − g_i(x) = g_i(x0) < 0`，于是对固定小 `σ > 0`、
充分小 `τ > 0` 有 `g_i(x + τ(v + σ(x0−x))) < 0`（非 active 的 `g_i` 由连续性也 < 0）⇒
`v + σ(x0−x) ∈ T_K(x)`；令 `σ ↓ 0` 得 `v ∈ T_K(x)`（闭）。∎
**推论（Slater 分支）**：极小点处 KKT 乘子存在 ⇒ 存在**有限** `α,β` 使 (1) **取等**；
且 `u` 由 ≤2 个 active 梯度表示（R² 的 Carathéodory），故"每 hub ≤2（至多 3 个 active 盘）"的 finite support 枚举
**在 Slater 下**是穷尽的。精确 control：B4（crossing lens）给出显式乘子
`α = 2/√3 − 1/2`、`β = 2 − √3/2`，`L = dist² = 19/4 − 2√3`，且 `Φ` 的驻点残差恰为 0（符号验证）。

**3.3 无 CQ 时的确切失效：two tangent disks singleton（B3，精确有理）**
`K_A = B((−1,0),1) ∩ B((1,0),1) = {(0,0)}`（外切 ⇒ active 梯度 `(2,0)`、`(−2,0)` **反向**），`K_B = B((0,3),1)`。
* `K_A = {a*}` 单点 ⇒ `T_{K_A}(a*) = {0}` ⇒ `N_{K_A}(a*) = R²`；而 `cone{(2,0),(−2,0)}` = x 轴 ⇒ **严格不等**；
* 真分离方向 `u = (0,−1)`（由 `a*` 指向 `K_B` 的反向）**不在** active cone 中 ⇒ 该点 KKT 系统无解
  ⇒ 有限 active-set 枚举会漏掉真极小对（"枚举穷尽"声明失效）；
* **但** lead (1) 依然有效：取 `α_1 = α_2 = t`、`β = 2` 得精确闭式 `L(t) = (12t−2)/(1+3t)`（严格增，`L(t) < 4`），
  `sup_t L(t) = 4 = dist²` —— **非达到**（B3 与 lead 的 json 一致：`5/2, 22/7, 118/31, 1198/301`）。
  结论：失效的是"枚举穷尽/达到"的**声明**，不是弱下界的**有效性**。

**3.4 singleton 分支（必须显式）**
* `int K = ∅` 且 `K ≠ ∅` ⇒ `K` 是单点。理由：若 `a,b ∈ K`、`a ≠ b`，则中点 `m` 满足 `|m − p_i| < ρ_i`（严格，
  否则由范数严格凸性推回 `a = b`）⇒ `m ∈ int K`。
* 单点分两类，行为**不同**：
  (a) 某对盘**外切**（active 梯度反向）⇒ `cone ⊊ N = R²`，finite support/KKT **失效**（B3）；
  (b) active 梯度**正生成**（`0 ∈ int conv`）⇒ `cone = R² = N`，finite support 仍成立。精确 control B6：
  三个半径 1 的盘、圆心取单位正三角形顶点，交集 = {0}（用求和恒等式 `2⟨x, Σe_i⟩ = 0 ≥ 3|x|²` 证明），
  且 `cone{active}` = R² ✓。
  另有**内切/内含**情形：`act` 可能有两个元素，但两条 active 梯度**平行同向**（不是反向）⇒ `cone = ray = N`，不失效（B5 精确 control）。
* **处理规则**：排除证书**不需要**分支区分（(1) 无条件）；只有当要声明"枚举穷尽 / 达到 `dist`"时才需要 Slater；
  若要 singleton 上的精确 `dist`，走点-集距离的闭式分支（仍是有限代数判定，不引入优化）。
* Slater 的**证据**：给出严格可行见证点 `x0` 并逐盘精确核验 `|x0 − p_i| < ρ_i`（有限次有理比较，无优化）。

**3.5 open/closed**：见 §0-E4（闭松弛 + 下界即可，不需要 margin）。

## §4 two-disk lens 退化：精确 control 表（读数见 `CENTRAL-DUAL-CONTROLS.md`）

`δ = |p − q|`，半径 `r1, r2`（不失一般性 `r1 ≥ r2`）：

| 情形 | `K = B(p,r1) ∩ B(q,r2)` | Slater | cone{active} vs `N` | control |
|---|---|---|---|---|
| `δ > r1+r2` | `∅` | — | — | 配置排除（空集判定本件不展开：Helly 使对/三重组检查足够） |

## §5 范数盘 `|h| ≤ 1−r` 不是特殊情形（"优化省去"）

* **统一 append**：把 `(p, ρ) = (0, 1−r)` 作为一个盘加入每个 hub 族即可，(1) 对任意盘数与任意中心/半径成立，**无需分支**。
* **取 `γ = 0`**（丢掉它）永远合法（只是更弱）；取 `γ > 0` 也保持有效（对可行点 `|h| ≤ 1−r` ⇒ 该项 ≤ 0），
  但**不是单调变强**：候选处读数 `L = 0.0882 (γ=0) → 0.0546 (γ=0.1) → <0 (γ≥0.5)`（均匀取 γ 是坏选择）。
  正解：只在 Slater 分支用 KKT 给出最优 `γ`；否则默认 `γ = 0`。
* **open/closed**：实际 hub 满足严格 `|h| < 1−r`，属于闭盘 ⇒ 提供下界时用闭盘安全（§0-E4）。
  因此模板里**没有**"范数盘特殊分支"。
