## 1. 算子规范（必须逐项满足，缺一即为不可用证书）

对 `F: R^n → R^n`（本工作区为多项式）、区间盒 `X = [X_lo, X_hi] ⊂ R^n`、点 `x0 ∈ X`（标准取 `x0 = mid(X)`）、
实数矩阵 `Y ∈ R^{n×n}`（≈ `J(x0)^{-1}`）：

```
K(X) := x0 − Y·F(x0)  +  (I − Y·J(X)) · (X − x0)
```

| 部件 | 规范要求 |
|---|---|
| `F(x0)` | **点值**（含外向舍入）——不是区间值；若用区间值则必须额外证明包含性 |
| `J(X)` | `X` 上的**区间 Jacobian 包络**（不是 `J(x0)`；不是"点导数 + 半径估计"） |
| `X − x0` | **完整区间差** `[X_lo − x0, X_hi − x0]`（`x0 = mid(X)` 时对称）——**不得**替换成半径、`[0, X_hi − x0]`、或点 `0` |
| `I` | 单位阵（区间算术中为精确 `[1,1]` 对角） |
| `Y` | 实数或区间矩阵；需 `Y` 非奇异（或区间可逆性另行证明） |
| 包含检验 | `K(X) ⊆ int(X)`：**分坐标严格**（`K_lo > X_lo` 且 `K_hi < X_hi`）；用非严格会丢掉唯一性 |

**注（正确性边界，已更正）**：**不能**依赖"区间乘法会把单侧位移 hull 回对称"这一说法——它只在
`I − Y J(X)` 含对称 0（或等价特例）时成立。一般情形下，把位移写成单侧 `[0, X_hi − x0]` 或点 `0`，
**会**产生 FALSE PASS（§3(f) 的 2D 符号相消反例即此）。真正的错误模式有**三类**：
(i) `J(X) → J(x0)`；(ii) 位移 `X − x0 → 点/单侧`；(iii) 包含检验用非严格不等号。

## 2. 三个定理与 ∞-范数的确切角色

- **(T1 存在)** `K(X) ⊆ int(X)` ⇒ `F` 在 `X` 内**至少一个**零点。
  证明：`φ(x) := x − Y F(x)`；由中值型包含 `F(x) − F(x0) ∈ J(X)(x − x0)` 得 `φ(X) ⊆ K(X) ⊆ int(X) ⊂ X`
  ⇒ `φ: X → X` 连续 ⇒ Brouwer 不动点 ⇒ `F(x*) = 0`（`Y` 非奇异）。
- **(T2 唯一)** 若 `‖I − Y·J(X)‖ < 1`（任何相容矩阵范数，本工作区用 `∞`-范数：行和最大）
  ⇒ `X` 内**至多一个**零点。
  证明：两零点 `x*, y*` ⇒ `x* − y* = (I − Y J(ξ))(x* − y*)`（`ξ` 在连线区间内，区间包络覆盖）
  ⇒ `‖x*−y*‖ ≤ q‖x*−y*‖`，`q < 1` ⇒ `x* = y*`。
- **(T3 两者)** `K(X) ⊆ int(X)` **且** `‖I − Y·J(X)‖_∞ < 1` ⇒ `X` 内**恰有一个**零点
  （Banach：`g := φ` 是 `X → int X` 自映射且 `q`-压缩，`q = ‖I − YJ(X)‖_∞ < 1`）。

**必须说清的角色（已按 lead team-message-cee607fe 更正；收回此前过宽说法）**：
- **标准 Krawczyk 定理（对称居中盒 `x0 = mid(X)`）**：**仅** `K(X) ⊆ int(X)` 即可给出**存在 + 唯一**
  （唯一性经**加权 ∞-范数**推出：按分量半径取权、配合额外平移使行和 < 1；Brouwer 给存在）。
- 故 **T2 的普通 `‖I − YJ(X)‖_∞ < 1` 只是充分条件之一，不是唯一性的必要形式**；
  本件此前"`K ⊆ int X` 单独不给唯一性"**过泛，已撤回**（仅在不假设对称居中盒时才可辩）。
- `q` 仍必须由**区间** Jacobian 计算（点值算出的 `q` 是伪压缩，见 §3(b)）。

## 3. 反控制（精确有理；F 为多项式且**无实零点**）

`F(x) = x² + 1`（恒 `> 0`，**无实零点**），`X = [1/10, 3]`，`x0 = 31/20`，`Y = 10/31`（`J(x0) = 31/10`）。

| 变体 | `I − Y J` | `K(X)` | `K ⊆ int X` | 判读 |
|---|---|---|---|---|
| **(a) 正确**（区间 `J(X)=[1/5,6]` + 对称完整位移 `[−29/20,29/20]`） | `[−29/31, 29/31]` | `[−1121/1240, 2243/1240] ≈ [−0.904, 1.809]` | **False** | **正确 FAIL**（确实无零点）✓ |
| **(b) 点 Jacobian**（`J(X) → J(x0)`） | `0` | `{561/1240} ≈ {0.452}` | **True** | **FALSE PASS** ✗（伪称有零点） |
| **(c) 零位移**（`X − x0 → 0`） | `[−29/31, 29/31]` | `{561/1240}` | **True** | **FALSE PASS** ✗ |

- (d) 该例中**区间** ∞-范数 `q = 29/31 < 1` ✓ —— 说明"`q < 1`"并不能阻止 (b)(c) 的伪 PASS：
  伪 PASS 的根源是**包络失效**（`J` 或位移被点化），而不是范数判据。
- (e) **正控制**：`F(x) = x² − 2`，`X = [1, 2]`，`x0 = 3/2`，`Y = 1/3`：
  `I − YJ(X) = [−1/3, 1/3]`，`K(X) = [5/4, 19/12] ⊂ (1,2)` ✓，`q = 1/3 < 1` ✓
  ⇒ 存在 + 唯一（零点 `√2`）✓ —— T1+T3 的可复现正例。
- **(f) 2D 符号相消控制（lead team-message-cee607fe 的构造，已实际算出）**：
  `E = [[2,−2],[2,−2]]`、`A = I − E`（`det A = 1`，可逆 ✓）、`F(x) = A x − b`、`Y = I`、`X = [−1,1]²`、`b = (3/4, 1/4)`。
  - 真根 `x* = A^{-1} b = (7/4, 5/4)` ⇒ **在 X 外**（A 可逆 ⇒ 恰一根）；
  - **(f1) point radius / 零位移**：`E·(r,r) = (0,0)`（**行和相消**）⇒ `K = b = (3/4,1/4) ⊂ int X` ⇒ **FALSE PASS** ✗；

## 4. 审查 lead 新 Krawczyk 核时的检查清单（独立复核用）

1. `J(X)` 是否真正在**整个盒** `X` 上包络（含：区间算术是否正确处理乘法/幂的单调段；`X` 跨零时 `x²` 的包络是否取 `[0, max(...)]`）；
2. 位移是否为**完整区间差**且 `x0 ∈ X`（最好 `x0 = mid(X)`，使位移对称）；
3. `F(x0)` 是否点值 + 外向舍入（若用区间值，是否有额外包含性论证）；
4. `Y` 的非奇异性/可逆性是否有独立论证（数值近似逆需带误差界定）；
5. `∞`-范数是否在**区间矩阵**上计算（`max_i Σ_j max(|M_ij|)`），且是否 `< 1` **严格**；
6. 包含检验是否**逐坐标严格**（`⊆ int X`，不是 `⊆ X`）；
7. 盒坐标/单位/归一化是否明确（本工作区：`n=11` 覆盖问题的 `q0(6,7)` 归一化与 `r` 的口径）；
8. 退化情形：`J(X)` 含奇异区间、`X` 跨零、`Y` 需重选（重选规则是否给出）；
9. 结论的作用域：证书只对**该盒**成立；不得外推到盒外或"整族"。
