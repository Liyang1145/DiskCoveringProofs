## 0. 口径

环对 `c_i, c_j`，`d = |c_i−c_j| ∈ (0, 2r)`；`m = (c_i+c_j)/2`；`τ = (c_j−c_i)/d`；
`n = perp(τ)`（单位法向，**符号是约定**）；`k = √(r² − d²/4) > 0`；`p_± = m ± k n`。
`h` 的坐标：`s = ⟨h−m, n⟩`，`t = ⟨h−m, τ⟩`。`P` 表示单位边界点（`|P| = 1`）。

## 1. Claim 1（**已证，精确**）：`R_c(c_i,c_j,h) ≤ r ⟺ |h−p_+| ≤ r ∧ |h−p_−| ≥ r`（要求 `s > 0`）

**证明**（一行代数，`s>0` 用于保持不等号方向）：外心在垂直平分线上，`O = m + σ n`；
`|O−c_i|² = |O−h|² ⟺ d²/4 + σ² = t² + (σ−s)² ⟺ σ = (t²+s²−d²/4)/(2s)`，故 `R_c² = d²/4 + σ²`，于是

```
R_c ≤ r  ⟺  σ² ≤ r² − d²/4 = k²  ⟺  |σ| ≤ k
         ⟺  −2ks ≤ t²+s²−d²/4 ≤ 2ks
         ⟺  t²+(s−k)² ≤ r²  ∧  t²+(s+k)² ≥ r²      （用 k² = r²−d²/4）
         ⟺  |h−p_+| ≤ r  ∧  |h−p_−| ≥ r .
```

**SymPy 精确因子恒等式**（`r21_pair_exact_control.py [a]` 实际输出；**常数已按 lead 更正为 4**）：

```
4 s² (R_c² − r²) = (−2ks + s² + t² − u²)·(2ks + s² + t² − u²)        (u = d/2)
|h−p_+|² − r² = −2ks + s² + t² − u²
|h−p_−|² − r² =  2ks + s² + t² − u²
```

> **更正留痕（lead, team-message-75090fa7）**：上一版写成 `16 s² (…)`，是**常数转写错误**（推导给 `4 s²`；
> `R_c` 并未被定义成 quarter）。**等价性不受影响**（正因子 `4s² > 0` 不改变符号）。
> **独立对照**：lead `check_r20_chain_convexification.py` 的 SymPy 恒等式已 PASS。

⇒ 两个因子正是 `|h−p_±|² − r²`，乘积即 `4 s²(R_c²−r²)` ✓ **逐项精确**。
**有理样例（3-4-5）**：`u = d/2 = 3/5`、`r = 1`、`k = 4/5`；对 6 个有理 `(t,s)`
（含边界 `(0,9/5)`、`(1/2,1)`、`(9/10,1/5)`、`(9/5,1)`、`(1,1/10)`、`(3,1)`）双侧判定逐例一致 ✓
（SymPy 有理，零浮点）。

**退化例外（明确）**：
1. **`d = 2r`（`k = 0`）**：`p_+ = p_− = m`，Claim 1 退化为**等式条件** `|h−m| = r`（左右两侧同为此式）；
2. **`s = 0`（`h` 落在弦线 `c_ic_j` 上）**：三点共线 ⇒ 外接圆退化（半径 ∞/未定义），
   Claim 1 的假设 `s > 0` **排除**该情形（含 `h = c_i, c_j`）；
3. `c_i = c_j`（`d = 0`）不是合法环对，排除。

## 2. Claim 2 弱版（**已否证**）：`P∈∂D`、`|P−c_i|,|P−c_j| ≤ r`、`P` 在 `−n` 侧 ⇒ `|p_−| ≥ 1`？

**反例族（lead 预判的"近同径向 nested arcs"确实出现）**——`claim2_counterexample_scan.py [1]`：

| 参数 | 值 |
|---|---|
| `r` | `0.30` |
| `|c_i| , |c_j|` | `0.75 , 0.85` |
| 两心方向夹角 | `2°`（近同径向） |
| 两弧关系 | **nested（包含）** |
| 两交点模长 | `|p_+| = 0.774894`，`|p_−| = 0.923993` ⇒ **两个交点都在 D 内** |
| 共同被覆盖的单位点 | **219 个采样点**（lens 覆盖一段单位圆弧） |

⇒ 取被覆盖弧所在侧的符号作为 `n`（`n` 的符号是约定），则该侧交点即 `p_−`，`|p_−| < 1`，
条件"`P` 在 `−n` 侧"满足 ⇒ **弱版 Claim 2 为假**。
**侧向核验（本件实测，20 万点单位采样）**：被两盘同时覆盖的单位点 **12,209** 个，
其 `n`-投影落在 `−0.2488 … +0.1164`；其中 `p_−` 侧（`s<0`）**8,454** 个、`p_+` 侧 **3,755** 个
⇒ 确有大量共同覆盖单位点在 `p_−` 侧，而 `|p_−| = 0.923993 < 1` ✓。
扫描网格内此类反例 **154 个**（全部为 nested 型）。

**为什么 nested 是关键（独立的事件几何审查）**：
- 若两交点都在 `D` 内，则 lens 覆盖的单位弧必为**嵌套**型（一个弧含于另一个），
  此时两交点都在单位圆内而 lens 仍伸到 `∂D` ⇒ `|p_−| ≥ 1` 不成立；
- 若两弧**非包含**（端点交错），扫描中未出现"两交点皆在 D 内且 lens 覆盖单位点"，
  与"交错 ⇒ 恰一个交点在 D 外"的直觉一致（见 §3，但**仅为网格证据**）。

**两个可独立核验的精确事实（本件已推）**：
1. 假设 `|P−c_i| ≤ r` 与 `|P−c_j| ≤ r` **等价于** `|v|² + d|v_τ| ≤ k²`（`v = P − m`）；
2. 其**必要推论** `|v| = |P−m| ≤ k`（由两式相加得到）；
   —— 但由 1+2 **推不出** `|p_−| ≥ 1`（需要额外的 `|P| = 1` 条件；对称族里两者合起来才给出
   `a² + k² ≥ 1`，即"两交点皆内 ⇒ 无共同覆盖单位点"，这也解释了为何反例必须**非对称/nested**）。
