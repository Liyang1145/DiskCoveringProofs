## 1. 移动交点的**精确一阶/二阶**公式（高杠杆选项）

对两个非共线 ring `i≠j`、`d = |c_i−c_j| < 2ρ`，内根交点

```
p(c_i,c_j,ρ) = m − h·w ,  m=(c_i+c_j)/2 ,  w=perp(c_j−c_i)/d ,  h=√(ρ²−d²/4)      (外根为镜像，推导相同)
```

**一阶（隐式形式，本件主公式）**：令 `v_i = p−c_i`、`v_j = p−c_j`（非共线），则

```
⟨v_i, dp⟩ = ρ·dρ + ⟨v_i, dc_i⟩
⟨v_j, dp⟩ = ρ·dρ + ⟨v_j, dc_j⟩
```

**显式（Cramer）**：

```
dp = [ (ρ dρ + ⟨v_i,dc_i⟩)·perp(v_j) − (ρ dρ + ⟨v_j,dc_j⟩)·perp(v_i) ] / ⟨v_i, perp(v_j)⟩
```

- 二阶：对同一线性系统再微分一次，`dv_k = dp − dc_k` 进入右端 ⇒ `⟨v_i, d²p⟩ = dρ² + 2⟨dp−dc_i, dp−dc_i⟩/…`
  （结构清楚；本件只在一阶上做数值核验，二阶留作显式义务，不作为已验证结论）。
- **域/符号**：要求 `d < 2ρ`（严格余量）；`⟨v_i, perp(v_j)⟩ ≠ 0`（非退化交点）；退化时两条公式同时失效
  ——这正是"相切/多重点"事件，须显式入域。

## 2. 严格孔 membership：精确定义 + **一阶线性预测（未证，按 lead 更正）**

对"定点不动"的迁移规则 `p(c,r) ≡ p`：`p ∈ U ⟺ ∀k: |p−c_k|² > r²`。**精确**条件是

```
|c_k + δc_k − p|²  >  (r + δr)²
⟺  |p−c_k|² − 2⟨p−c_k, δc_k⟩ + |δc_k|²  >  r² + 2r·δr + (δr)²
```

⇒ **必须保留 `|δc_k|² − (δr)²` 项**（不是纯线性式）。下面只是**一阶（线性）预测、无二阶余项保证**：

```
⟨p−c_k, δc_k⟩  <  ( |p−c_k|² − r² ) / 2  −  r·δr          （numeric 线性预测 / 未证）
```

**一阶读数（19 核点，`r=R_D`）**：最近环余量平方 `3.04e-5` ⇒ 线性预测允许 `δr ≲ 4.0e-5`；
与"ring 半径从 `ρ_aux = 0.38` 降到 `R_D`（差 1.6e-5）后仍是严格内点"**一阶**相符，
**但不构成有限位移保证**（有限位移须用上面的二次式，或给出 `|δc_k|`、`|δr|` 的显式上界）。

## 3. 两个 closure 点的迁移是**自动的**（无需旧 C463 向外锥）

两点各是**当前半径的环-环交点**，活跃环数恰为 2。按 R21-RESIDUAL-MEMBERSHIP / C458：
"≤2 个活跃法向总有逃逸方向（两相反法向也可**垂直**逃逸，二次项给出间隙）"。
因此只要（i）该对仍相交（`d < 2r` 有严格余量），（ii）没有**第三个**环进入 `|p'−c_k| ≤ r`，
**membership 在任意方向的小扰动下都保持**——**向内侧向皆可**，不需要任何"向外锥"。
第三个环的排除是显式线性条件：

```
|p−c_k|² − r² + 2⟨p−c_k, dc_k⟩ + 2 r·dr  >  0        （对所有第三环 k）
```

⇒ **可证方向容量**：允许集 = { (dc, dr) : 上式对所有非活跃环成立 } ∩ { d < 2r 的余量 }，
是**有限个线性不等式**，可逐项核验；这比 C463 的"向外锥"严格更宽（内含向内/切向）。

## 4. 一个三点 obstruction（不多做；**非冻结 hub-touch**）+ 可判定迁移条件

- **结构性发现（重要，且是否定性的）**：C462 证书里**所有最紧的三点禁集都是 hub-touch 型**——
  其外心到最近 hub 的距离 `≤ 1e-5`（即 MEC 圆就是"hub 的盘"）。例如最紧的 `[0,5,10]`：
  `MEC = 0.379963472`，外心 `(−0.00016204,−0.14942272)`，距 hub0 `≈ 5.7e-6`。
  ⇒ **在这份证书内不存在"紧且不含 hub"的三点 obstruction**；要找非 hub 型，只能取**松得多**的组合。
- 取最紧的**非 hub** 三点禁集（外心距最近 hub ≥ 0.05）：**`[0,4,13]`**，
  `MEC = 0.420009450540`，外心 `(−0.0855313, +0.1848608)`（距最近 hub `0.1230`），
  **MEC 余量 `M = 4.004945e-02`**（比 hub-touch 型松约 `1.5×10⁴` 倍）。
- **可判定迁移条件（一阶线性预测）——按 lead 更正：这只是 numeric 预测，不是区域保证**：
  `M + Σ_j (∂M/∂param_j)·δ_j > 0` **只作方向读数**；缺少二阶余项、且 MEC 类型/外心支会切换，
  因此**不得**写成"该区域有效"。梯度表（解析 **未认证** vs 有限差分）：

  **这是线性外推的估计，不是实际计算出的反例**——本件**未**计算该位移处的真实 MEC，也**未**证明在该位移内
  余量单调。梯度自身在部分环上与有限差分差 ~50% ⇒ **在完成 MEC 分支界定之前，不得宣称任何"迁移区域/传递"。**

  **MEC 类型/外心支的分段**（何时是直径圆、何时是外接圆、外心是否在三角形内）——这是本件留下的显式义务。

## 5. 能传递到哪些方向 / 边界与反例（结论式）

1. **identity 点（19 个核点）**：任意方向的小扰动均有效，容量由 §2 的线性不等式给出
   （径向收缩上限 `dr ≲ 4.0e-5`；切向位移基本不受限，只受"最近环余量"的线性项约束）。
2. **closure 交点（2 个新增点）**：任意方向均有效（§3），仅需 `d < 2r` 余量与"第三环不激活"；
   **不需要向外锥**——这是相对 C463 的真实（但**属于复用/整理**的）放宽。
3. **三点 obstruction（`[0,4,13]`）**：只有线性预测（§4）；所谓"反例 = 把 ring0 沿 `−x` 推 > 0.127"
   **是线性外推，不是已计算的反例**，本件不据此声称传递失败或成功。
   （或任何使 `MEC < t` 的扰动）。
4. **反面结论（本件最值钱的一条）**：**"紧的、非 hub-touch 的三点 obstruction"在这份证书里不存在**；
   证书的紧度是**围绕 hub 组织**的。若要把迁移做成"全域 ring 移动 + 固定 t"的形式，
   要么必须让 hub 也进入参数（与 lead 的"不要冻结 hub touch"要求冲突），
   要么只能使用**松 1e4 倍**的非 hub obstruction（迁移区域相应地小得多）。
