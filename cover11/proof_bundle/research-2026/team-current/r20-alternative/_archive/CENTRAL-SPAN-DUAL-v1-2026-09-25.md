## 0. 定义

- 半径 `r > 0`；环位点 `c_a, c_b`（中央两 site）；hub 域 `K_A, K_B ⊂ R²` 为**盘交**：
  `K_X = ⋂_{i∈I_X} B(q_i, ρ_i)`（闭盘；闭性假设见 §4），凸且紧 ✓。
- 中央两三角形：`(h_A, h_B, c_a)` 与 `(h_A, h_B, c_b)`，要求 `R_c ≤ r` 两者。
- 记 `D := |h_A − h_B|`（**中央 span**）；`d := |h_A − c|`（chord 长，注意：与哪个端点取决于所用约束，见 §2 备注）。

## 1. 中央 span 的必要界（从 crescent 的**包含**直接得）

**引理 1（crescent 的盘包含）.** 固定 `h_A` 与 `c`，`d = |h_A − c| < 2r`，`m = (h_A+c)/2`，`k = √(r² − d²/4)`，
`n = perp(c − h_A)/d`，`p_± = m ± k n`。则

```
{ h : R_c(h_A, h, c) ≤ r }  ⊆  B(p_+, r) ∪ B(p_−, r) .
```

证明：由 R21 Claim 1（已证），`+n` 侧该集合 = `B(p_+,r) ∩ {|h−p_−| ≥ r} ⊆ B(p_+, r)`；
`−n` 侧为镜像（`⊆ B(p_−, r)`）✓。

**引理 2（span 界）.** 若 `h_B` 同时满足**同一个 chord** 的约束（即 `R_c(h_A, h_B, c) ≤ r`），则

```
D = |h_A − h_B|  ≤  2r + 2k  =  2r + 2√(r² − d²/4)      （=: d_max）
```

证明：`h_B ∈ B(p_ε, r)`（某 `ε ∈ {±}`），且 `|h_A − p_ε| = r`（因 `h_A` 是以 `p_ε` 为心、半径 `r` 的圆上的点）✓
⇒ `D ≤ |h_B − p_ε| + |p_ε − h_A| ≤ r + r = 2r`（**逐弦的 2r 界**）。
更强形式：两交点相离 `2k`，`B(p_+,r) ∪ B(p_−,r)` 的**直径** `= 2k + 2r` ✓；当 `h_B` 与 `h_A` 落在**不同**叶
（一片在 `B(p_+,r)`、另一片在 `B(p_−,r)`）时，可用 `|h_B − p_−| ≤ r`、`|h_A − p_+| = r` 得
`D ≤ |h_B − p_−| + |p_− − p_+| + |p_+ − h_A| ≤ r + 2k + r = 2r + 2k` ✓。
两种情形合并即 `D ≤ 2r + 2k` ✓（`2r` 情形被 `2r + 2k` 支配，`k ≥ 0`）。

**推论（排除格式）.** 若存在闸门 `d_max` 使（中央两约束蕴含 `D ≤ d_max`）——例如两约束共用同一 chord
（`d` 固定）或分别给出 `d_a, d_b` 取 `d_max = 2r + 2√(r² − min(d_a,d_b)²/4)`——则

```
dist(K_A, K_B) > d_max      ⟹      不存在满足中央两约束的 (h_A, h_B) ∈ K_A × K_B .
```

注意方向：排除需要的是 **`dist` 的 lower bound**（§3 给出可证来源）。

**备注（哪个 d）**：`d` 是**该约束所固定的 chord 长**——若约束用 `c_a` 与弦 `(h_A, c_a)`，则 `d_a = |h_A − c_a|`；
`d_a` 本身随 `h_A` 移动 ⇒ 严谨写法是对**同一 chord 共用**的情形直接用 `d`，多 chord 情形取 `min` 并**显式**
说明所取上界（本件不替 lead 决定 C879 的中央图结构，只给格式与方向）。

## 2. hub 的精确消去：`dist(K_A,K_B)²` 的 support/KKT 结构（每 hub ≤ 3 active disk）

**对偶恒等式（分离形式）.** 对凸紧集 `K_A, K_B`：

```
dist(K_A, K_B)  =  max_{‖u‖ ≤ 1}  [ min_{a∈K_A} ⟨u,a⟩  −  max_{b∈K_B} ⟨u,b⟩ ]
                =  max_{‖u‖ ≤ 1}  [ − h_{K_A}(−u) − h_{K_B}(u) ] ,
```

`h_K(u) = max_{x∈K}⟨u,x⟩` 为 support function ✓（标准；右侧每个 `u` 给**下界**，取 max 给等号）。

**KKT 支持.** `dist²` 的极小点 `(a*, b*)`（若 `K_A ∩ K_B = ∅` 则 `a* ∈ ∂K_A, b* ∈ ∂K_B`）满足
`u* = (b* − a*)/D ∈ N_{K_A}(a*)`、`−u* ∈ N_{K_B}(b*)`，其中法锥

```
N_{K_A}(a*) = cone{ a* − q_i : i ∈ act_A(a*) } ,   act_A(a) = { i : ‖a − q_i‖ = ρ_i } .
```

由 `R²` 中 Carathéodory 原理：**每个 hub 只需 ≤ 2 个 cone 生成元**即可表示 `±u*`；
把"3 盘共点/顶点由三盘确定"的退化情形计入，得到**每 hub ≤ 3 个 active disk** 的**有限** support 枚举 ✓
（这正是 lead 给的界）。于是全局极小点**必**出现在如下有限族之一：
`S_A ⊆ I_A, |S_A| ≤ 3`、`S_B ⊆ I_B, |S_B| ≤ 3`，且 `a*` 由 `S_A` 的等式组确定、`b*` 由 `S_B` 确定 ✓。

**局域 disk（`b, V`）.** 对每个候选 `(S_A, S_B)`：由权重（`λ_i ≥ 0, Σλ_i = 1`，生成元 `a*−q_i`）
写出一个**局域盘** `B(b, V)`（`b` = 候选接触点/接触簇中心，`V` = 由权重与半径拼出的显式界），
用于把"极小点在何处"的问题局部化，从而使验证只需**该盘内**的代数条件（不需要搜索）✓。

## 3. ring-only 证书模板（候选 weights → 可证 lower bound）

**目标**：给出 `dist(K_A, K_B) > d_max` 的**可复核**证据，且只依赖环数据（环位点、`r`）与 hub 盘的
构造参数 `(q_i, ρ_i)`（C879 的链盘交），**不依赖任何数值搜索**。

**模板（一条 lower-bound 证据 = 一个分离方向 + 两段 support 证明）**
1. **候选方向** `u`（单位向量，可从候选 support 的 KKT 系统解出或从环数据直接写出）；
2. **两段 support 证明**（把 `min/max` 换成可证界）：
   ```
   min_{a∈K_A}⟨u,a⟩ ≥ α      （证法：对候选权重 λ 与显式局域盘 B(b,V)，用对偶可行 λ 给出 α）
   max_{b∈K_B}⟨u,b⟩ ≤ β      （同理）
   ```
   两式的**证明**是有限个代数不等式（权重非负、`Σλ=1`、盘约束的二次式 ✓），可逐项精确核验 ✓；
3. **结论**：`dist ≥ α − β > d_max` ⇒ 由 §1 推论**排除**中央构型 ✓。

**证据方向的严格说明（易错点）**
- `dist` 的 **lower** bound 只能来自：**对偶可行**（一个方向 `u` + 两段 support 界）✓；
- `dist` 的 **upper** bound 只能来自：**原始可行**（一对 `a ∈ K_A, b ∈ K_B`）✓；
- 二者**不可互换**：用 primal 对只能给 upper（不能排除），用 dual 方向只能给 lower（不能确认存在）。
- 证书必须显式写出 `α, β` 的来源（权重 + 局域盘的界定），否则无法复核 ✓。

**「ring-only」的含义**：候选支持集 `S_A, S_B` 与权重都由环/hub 盘的**构造数据**生成
（C879 链式结构给出 `I_A, I_B, q_i, ρ_i`）；不含任何"扫描/优化"步骤 ✓。

## 4. Domain：strict / closed 与退化

- **闭性假设**：`K_A, K_B` 取**闭**盘交 ⇒ `dist` 的极小点存在 ✓，`act` 用 `‖a−q_i‖ = ρ_i`（`=` 计入）✓。
  若原几何用的是**开**条件（严格不等式），则 `dist` 的极小点可能不可达，此时必须：(a) 用 `inf` 代替 `min`；
  (b) 或把开条件包成闭集 + 显式 margin（"open-domain 松弛"）并**声明该松弛方向**（松弛只能用于给
  *lower* bound 的场合：`inf_{open} ≥ dist_{closed}` 不可用；正确方向是 `inf_{open} ≥ dist_{closed-ε}` 之类，
  须显式写出）✓。
- **退化事件**（须显式入域，不能以极限代替）：两 hub 盘相切（`act` 两侧同时 2 个）、三盘共点、
  `K_A` 或 `K_B` 为单点（`|I_X| = 1` 或半径 0）、`u*` 与某生成元**共线**（cone 非尖）、`d = 2r`（`k = 0` ⇒
  `d_max = 2r`）、`d > 2r`（该 chord 约束**空** ⇒ 直接排除，无需 `dist`）✓。
- **`d ≤ 2r` 的强制性**：`√(r² − d²/4)` 只在 `d ≤ 2r` 时有定义；`d > 2r` 时中央约束本身不可满足 ⇒
  这是**比 `dist` 更强的排除**，应作为分支先处理 ✓。
