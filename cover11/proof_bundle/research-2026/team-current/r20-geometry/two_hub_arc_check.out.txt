== (1) exact two-hub / two-endpoint / arc example ==
r = 19/50 = 0.380000 ; rho = 31/50 ; ring centre c = (19/20, 0), |c| = 0.950000
arc endpoints x1 = (0.646000, 0.228000), x2 = (0.646000, -0.228000) ; middle xm = (0.570000, 0.000000)
arc width = 73.7398 deg <= 180 deg (short side)
hub h1 found (max margin): h1 = (749/2000, 987/2000) ; |h1|^2 = 153517/400000 < rho^2 = 961/2500
  |h1 - x1|^2 = 57681/400000 <= r^2 = 361/2500  (covers x1)
  |h1 - xm|^2 = 22541/80000  > r^2 = 361/2500  (misses the middle, margin 10989/80000)
  |h1 - x2|^2 = 1188549/2000000  > r^2       (does not cover the other endpoint)
  h2 = mirror: covers x2, misses xm, does not cover x1 (verified by symmetry)
  => two hubs in H, each covering one endpoint of a short arc, middle covered by neither.

== (2) single-hub lemma ==
covered direction set of a hub = cap of half-angle beta = arccos(|c-h|/(2r)) <= pi/2;
both endpoints of a width<=pi arc inside the cap => whole arc inside (cap is an angular interval).
equality beta = pi/2 requires h = c, impossible here since |c| >= rho > 0 and |h| < rho.
