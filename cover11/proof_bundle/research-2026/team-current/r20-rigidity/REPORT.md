## 2. 一阶结构（切锥）

### 2.1 rank：x* 上是 18，X60 上是 17（本报告新增，解决接口分歧）

`J` = 18×22（18 个紧距离函数的梯度）。同一套函数/标号在两点上重算（`r20_rank_mechanism.py`）：

| 对象 | σ_18 | 左零向量 | 最优正权关系残差 |
|---|---|---|---|
| **x\***（保存有理候选） | **2.4110e-09** | 逐元 > 0（min 0.0363） | `‖J^T u‖ = 6.567e-10`（min u_i = 9.8947e-3） |
| **X60**（对齐重标号） | **7.67e-17**（= float64 噪声地板） | 同上（同一 u） | `‖J^T u‖ = 8.725e-17` ⇒ **精确关系** |

x* 的 rank 还有独立证据：解析闭式梯度 vs 中心差分 max|Δ| = 0.0e+00；列主元 18×18 子阵**精确有理行列式 ≠ 0**（`log10|det| = −15.11`，cond 4.73e8）；60 dps mpmath SVD σ_18 = 2.411015e-9（次小 5.842e-2）；元素为 1e-26 精度值的 float64 舍入 ⇒ Weyl 给 σ_18(真) > 2.4e-9 − 1e-14 > 0。

**机理（与 §0 的"7.86e-17 离散度"对接）**：
- 在 X60 上 18 个紧值**精确相等**（1e-60 网格上的 7.8e-61 离散度）⇒ 活动集 = 全 18 条 ⇒ 一阶最优性需要 `0 ∈ conv{∇f_i}`，此处**精确成立**（u > 0）⇒ rank 17。这正是 `cline2-r22-chain`/`r23-rigidity` 引理的假设域。
- 在 x* 上 18 个值只到 **7.86e-17** 才相等，argmax **唯一**（余 9.3e-19）⇒ γ 在 x* 处**可微**，`∇γ = ∇f_{V2b(1,7)} ≠ 0`；没有任何理由存在关系 ⇒ rank 18，σ_18 ≈ 2.4e-9 ≈ (1.77e-9 对称破缺) × O(1) 曲率。
- 结论：**引理的形式（H1）在 X60 成立、在 x* 不成立**；在 x* 必须改用 §2.3′ 的"针状"模型。

### 2.2 （作废）v1 的"薄下降锥"读法

`τ := min_{λ∈Δ}‖J^Tλ‖ ≤ 6.57e-10`（λ = u18/Σu18）确实界住"**18 条同时**下降"的斜率（`max_i⟨g_i,w⟩ ≥ −‖J^Tλ‖`）。
但 **γ = max_i f_i 的下降不由它控制**：argmax 唯一时 γ 可微，沿 −∇f_{argmax} 一阶斜率是 O(1) 量级。
⇒ v1 §2.3–§2.4 的"井深 5e-19"是**沿单一方向 v18 的读数**，不是 γ 的最大改进；**作废**。

### 2.3′ 正确的一阶下降模型：针状（needle），改进被"等号离散度"封顶（本报告给出界与初等推导）

沿方向 `w`（单位）一阶展开：`γ(x*+tw) − γ* = max_i [δ_i + t⟨∇f_i,w⟩] + O(t²)`，`δ_i = f_i(x*) − γ* ≤ 0`，`δ_{i*} = 0`（唯一 argmax）。

记 `a_i = ⟨∇f_i,w⟩`。**若存在上升者**（`a_j > 0`）：
- 下降需要 `a_{i*} < 0`；包络的最小值在 `t* = min_{j: a_j>0} (−δ_j)/(a_j − a_{i*})`，对应改进 `D = |a_{i*}|·|δ_j|/(a_j − a_{i*})`。
- 因为上升者要求 `a_j > 0 > a_{i*}`，故 `a_j − a_{i*} = a_j + |a_{i*}| > |a_{i*}|` ⇒ **`D < |δ_j| ≤ max_i|δ_i| = 7.86e-17`**。⇒ 一阶改进 ≤ 7.86e-17（初等；`O(t²)` 项在该尺度 ≤ 1e-32）。
**若无上升者**（`w` 落在 18 条同时下降锥内）：改进 ≤ `t·τ − Q t²`，最优 `t* = τ/(2Q)`、深度 `≈ τ²/(4Q) ≤ (6.6e-10)²/8 ≈ 5e-20`。
⇒ **两个机制合并：x* 的一阶可改进量 ≤ 7.9e-17**（这就是"x* 离稳定有多远"的正确量化，与等号离散度绑定；τ 只出现在无上升者的退化情形）。

**反向检查（说明"argmax 下降 ≠ γ 下降"）**：沿 argmax 行自身的陡降方向 `w = −∇f_{i*}/‖∇f_{i*}‖`（行范数 0.7073），60 dps 实测 γ 从 t=1e-13 到 1e-7 **线性上升**（斜率 +0.330/单位距离，ratio 恒为 −0.467）——因为一个反平行的上升者立刻接管包络，针状窗口在该方向只有 ~1e-19。故下降方向必须（近似）是"共同下降方向"；X60 方向正是这种方向（斜率差仅 ~2.9e-8，窗口 2.8e-9）。

**已实现的下探（独立复算，确认同僚 W4）**：沿 x* → 对齐+重标号的 X60 的直线（Euclid 距离 2.6962e-9）：

```
 s        γ(x*(s)) − γ*            说明
 0        0
 0.001   −1.9327e-20             线性：γ − γ* = s·(−1.9326e-17)
 0.05    −9.6635e-19
 0.5     −9.6633e-18
 1       −1.9326e-17             = γ(X60) − γ(x*)（与注册值逐位一致）
```
斜率 = 1.9326e-17/2.6962e-9 = **7.174e-9 / 单位距离**（与 W4 的 7.1743e-9 独立一致）。
逐函数一阶斜率（per s）从 −2.39e-17（V3 (0,9,10)）到 +5.93e-17（V3 (1,2,7)）：**有上升者**，因此上界 7.86e-17 适用，实际 1.93e-17 ✓。

**结论（口径）**：保存的有理对象 x* **不是 γ 的局部极小**（γ 可微且 ∇γ ≠ 0；存在显式更优的 1.77e-9 邻点，改进 1.93e-17）；但"非稳定"的可利用幅度被 **≤7.9e-17** 封顶。**不要**把 x* 当作局部刚性分析的基点；基点应取 **X60**（精确 18 重等号，一阶条件精确成立）。

## 5. "局部刚性 + 远区全局分离"路线评估

### 5.1 局部半边（基点应为 X60）
- X60：18 条精确等号 + 精确正权关系（u > 0，min 9.89e-3）⇒ 一阶条件精确；二阶用**加权**形式（同僚 `λ_min(K) = 0.1649`，并已给出 `γ − γ* ≥ 0.0206·dist(x,𝒪)²`（`dist ≲ 9e-7`）的修正版定理，含 `C_3` 项）。
- x*：不是稳定点，但**一阶改进 ≤ 7.9e-17**（§2.3′），且 x* 距 X60 仅 1.77e-9 ⇒ 对任何 `ε ≫ 1e-16` 的目标，x* 与 X60 "等价"。
- 严格化剩余（纯计算）：加权乘子/`λ_min`/二次型的区间外包 + 活动集盒内不变性（slack 1.1527e-3 足够）。

### 5.2 远区（真正的缺口）
- 义务形态：`B(X60,ρ0)` 之外 `γ ≥ γ* + ε0`。当前无条件下界仍 **C825：3/8 = 0.375**（低于 γ* 4.98e-3）；q0(6,7) 归约 + C840 紧性 + 局部 patch 排除只覆盖子区域。
- 局部常数（0.1649/0.0206、二次律验证到 ρ0 ≈ 5e-2）**不能**替代远区。
- 标定（1 点，非证明）：在册第二 KKT 分支（`ΔR = +5.339e-3`，模旋转距离 0.1596）满足二次不等式（0.16·0.1596² = 4.07e-3 < 5.34e-3 ✓）；距离口径不同，勿作证据。

### 5.3 判断
路线结构自洽：**局部（X60 处加权二阶 + 活动集稳定）× 远区（全局不等式或紧凑域有限覆盖）**。本轮局部一半被同僚推进到"加权形式 + 显式邻域半径"，但**远区义务没有任何自动蕴含**；把局部精度继续提高不会改变这一点。
