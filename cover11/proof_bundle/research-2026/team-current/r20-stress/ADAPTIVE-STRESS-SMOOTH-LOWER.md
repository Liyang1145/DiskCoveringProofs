## §0 正确对象

* `E_α(U) := min_{z} Σ_e α_e |e_e(U,z)|²`（**Schur 最小化能量**；关于 α **非线性** ✗）；
  dual 用途：`E_α(U) ≤ V(U)²` ✓（极小性 + 加权平均 ≤ 最大 ✓）。
* `B` = balance + 归一化系统（45 未知 ✓）；`N`（45×4，`BN = 0` ✓）；`α(t) = α₀ + Nt` ✓、
  `Bα₀ = e₄₀` ✓、`α₀ ≥ α_min > 0` ✓；角向 `x ∈ R⁸`、`U(x)` ✓。**所有导数只在 root 取** ✓。

## §1 root 处的二阶恒等式（完整证明）

**(a) root free 节点对全 t 平衡**：`∂_z[Σ_eα(t)_e|e_e|²]` 关于 `α` **线性** ✓，在 `α₀` 处为 0 ✓，
而 `N` 在该线性算子的零空间内（`BN = 0` ✓）⟹ 对一切 `t` 仍为 0 ✓；能量对 `z` 凸 ✓ ⟹ `z₀` 对**所有** `t` 都是极小点 ✓✓。

**(b) `E(t,0) = R²`（∀t）⟹ `E_tt(0) = 0`**：`E_{α(t)}(0) = Σ_eα(t)_e|e_e(z₀)|² = R²·Σ_eα(t)_e = R²` ✓
（carrying edge 长 `= R` ✓、`Σα(t) = 1` ✓）⟹ 沿 `N` 方向 `∂²E/∂t²|₀ = 0` ✓（**只**这个方向 ✓，
**不**推广成 `E_{αα} ≡ 0` ✗）。

**(c) 混合 `E_{xt} = G`（envelope；靠 (a) 的"free 不随 t 变"）**：`∂E/∂x_j|₀ = ∂Φ/∂x_j(α₀,0,z₀)` ✓
（`Φ := Σα|e|²`；极小点变分项被 `∂Φ/∂z = 0` 消去 ✓）。对 `t_l` 再导，因 `z₀` **不随 t 变** ✓ 且 `Φ` 关于 `α` 线性 ✓：
```
∂²E/∂t_l∂x_j |₀ = Σ_e (∂|e_e|²/∂x_j) N_{e,l} =: G_{jl}        （8×4 ✓，= lead 的 G = T N ✓）
```

**(d) `H₀` = Schur 的角 Hessian（不是 trial 能量的 Hessian ✗）**：`∂E/∂x_j = ∂Φ/∂x_j(α,x,z*(α,x))` ✓ ⟹
`H₀ = ∂²Φ/∂x² + ∂²Φ/∂x∂z·(∂z*/∂x)` ✓，其中 `∂z*/∂x` 由极小点驻定性 `∂²Φ/∂z∂x + ∂²Φ/∂z²(∂z*/∂x) = 0` ✓ 给出
⟹ `H₀` = **Schur 补在 x 上的 Hessian** ✓（= lead 的 canonical Schur H ✓）。

**(e) 自适应能量**：`t(x) := τGᵀx` ✓、`F(x) := E_{α(t(x))}(U(x))` ✓；由 (b)(c)(d)（只在 root ✓）：
```
F'(0) = 0 ,     H_F(τ) := F''(0) = H₀ + 2τ G Gᵀ        （8×8 ✓）
```
（`F' = τG·(∂E/∂t) + ∂E/∂x` ✓；再导一次：(b) 的 `E_tt(0)=0` ✓ 与 (c) 的 `E_{xt}=G` ✓ 给两个交叉项各 `τGGᵀ` ✓。）

## §2 τ 的**严格**可行条件（正交基 + Schur 补）

取**正交基** `Q_ker, Q_im`（8×4 ✓）张成 `ker(Gᵀ)`、`im(G)` ✓：
```
H_AA = Q_kerᵀH₀Q_ker ✓   H_AB = Q_kerᵀH₀Q_im ✓   H_BB = Q_imᵀH₀Q_im ✓
J := Q_imᵀ G Gᵀ Q_im      （4×4，≻ 0 ✓；与 GᵀG 在 im 上的限制同正特征值 ✓——**不写**字面 GᵀG ✗）
⟹  H_F(τ) ≻ 0  ⟺  H_AA ≻ 0  且  Schur(τ) := H_BB + 2τJ − H_ABᵀ H_AA^{-1} H_AB ≻ 0
```
* **首要条件** `H_AA ≻ 0`（`= H₀|ker(Gᵀ) ≻ 0`）：**C912 已 interval certified** ✓（数值 `[.0074,.0175,.0423,.0712]` 仅 diagnostic ✓）。
* `J ≻ 0` ⟹ `Schur(τ)` 严格单调增 ⟹ 存在**严格**阈值
  `τ > τ* := [λ_max(H_ABᵀH_AA^{-1}H_AB − H_BB)]/(2λ_min(J))` ✓（**严格 >** ✓；`τ = τ*` 时可能只半正定 ✗；
  若右端 ≤ 0 则任意 `τ > 0` 皆可 ✓）⟹ **`H_F(τ) ≻ 0` 于全 8 维** ✓（τ 只压 `im G` 块 ✓，`ker Gᵀ` 块由 `H₀` 承担 ✓）。

## §3 邻域所需的一致界（**更正：Schur 逆的导数不可省** ✗）

1. **α-正性**（`x` 的**线性**条件 ✓）：`α(t(x)) = α₀ + τNGᵀx ≥ 0` ✓ ⟹ `|x|_∞ ≤ α_min/(τ‖NGᵀ‖_∞)` ✓（必须进半径 ✗）。
2. **极小点映射的导数**：`∂z*/∂x = −(∂²Φ/∂z²)^{−1}∂²Φ/∂z∂x` ✓ 与 `∂²z*/∂x²`（= **Schur 逆的导数** ✓）
   在 `|x| ≤ ρ` 上的一致界 ✓——**只** bound `U,N,G` **不够** ✗（v1 之错 ✓）。
3. **Hessian 一致连续**：`‖H₀(x)−H₀(0)‖ ≤ L_H|x|` ✓、`λ_min(H_AA(x)) ≥ λ_min(H_AA(0)) − L'|x| > 0` ✓。
4. **三阶余项**：`C₃(ρ) = sup_{|x|≤ρ}‖F'''(x)‖` ✓，其界需 1–3 与 `Φ` 的三阶导（`U(x)` 三阶导逐坐标 ≤ 1 ✓）。
⟹ 半径形如 `ρ = min(α_min/(τ‖NGᵀ‖_∞), λ_min(H_AA)/(2L'), c(τ)/(2C₃))` ✓（**本轮不代数值、不声称可行** ✗）。
