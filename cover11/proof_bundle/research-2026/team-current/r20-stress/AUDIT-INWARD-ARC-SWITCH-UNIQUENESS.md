## §2 细节与（新的）替代推导

### 2.1 半角的精确界（比原文更明确的阈值）
盘心距 `ρ`、半径 `r`，与单位圆的交点满足（三角形 0-c-x 的余弦定理）`cos a = (ρ²+1−r²)/(2ρ)` ✓。
`a ≤ asin(r) ⟺ cos a ≥ sqrt(1−r²) ⟺ ρ²+1−r² ≥ 2ρsqrt(1−r²) ⟺ (ρ−sqrt(1−r²))² ≥ 0` ✓（恒真，等号 iff `ρ = sqrt(1−r²)`）。
故 `|A| = 2a ≤ 2asin(r)`，8 弧总长 `< 2π` 的**精确**条件是 `r < sin(π/8) = 0.382683…` ✓（n11 的 `r ≤ 0.38` 满足）。

### 2.2 审计原文的"至多一个"证明
记 `m = (a+b)/2`、`d = |a−b|`、`e = (b−a)/d`、`n = Je`；`k² := r² − d²/4`；equality points 为 `x = m + tn` 与 `|x| = 1` 的交点 `P± ↔ t±`，
根满足 `t² + 2(m·n)t + (|m|²−1) = 0` ⟹ `t₊t₋ = |m|²−1 < 0`（`|m| ≤ (|a|+|b|)/2 ≤ sqrt(1−r²) < 1` ✓）与
`t₊² + t₋² = 4(m·n)² + 2(1−|m|²)` ✓（原文的"average = 1−|m|²+2(m·n)²" ✓）。到任一圆心的距离为 `d²/4 + t²` ✓
（圆心在 `m ± (d/2)e`，而 `e ⊥ n` ✓）。两 equality point 都被覆盖 ⟺ `max(t±²) ≤ k²` ✓ ⟹
`k² ≥ max ≥ (t₊²+t₋²)/2 ≥ 1−|m|²`；另一侧 `|m|² + k² = a·b + r² < 1` ⟹ `k² < 1−|m|²` ✗ 矛盾 ✓。
**审计判定：无跳步、无隐含假设**（`d < 2r` 是"两个都覆盖"的推论——`k² ≥ max(t±²) > 0` 需要 `k² > 0` ✓；
`d ≥ 2r` 时两盘不交、无可覆盖 equality point，命题空真 ✓）。

### 2.3 更简洁的**不同**几何推导（本审计的主要增量）
**只用三条初等事实**：(i) 盘凸；(ii) 平行四边形恒等式；(iii) 弦长 vs 直径。

> 若 `P₊, P₋` **都被覆盖**（即都在 `B(a,r) ∩ B(b,r)` 里，因 equality point 到两心等距 ✓），
> 由凸性 **整条弦 `[P₋,P₊] ⊂ B(a,r) ∩ B(b,r)`** ✓；
> 对 `x ∈ B(a,r) ∩ B(b,r)`：`|x−m|² = (|x−a|²+|x−b|²)/2 − d²/4 ≤ r² − d²/4 = k²` ✓
> （平行四边形：`|(x−a)+(x−b)|² + d² = 2|x−a|² + 2|x−b|²` ✓）
> ⟹ 透镜 `B(a,r)∩B(b,r) ⊂ B(m,k)` ⟹ **弦长 ≤ 2k** ✓。
> 另一方面弦长 `|t₊−t₋| = 2sqrt((m·n)²+1−|m|²) ≥ 2sqrt(1−|m|²)` ✓。
> ⟹ `(m·n)² + 1 − |m|² ≤ k² = a·b + r² − |m|²`（用 `a·b = |m|² − d²/4` ✓）
> ⟹ `(m·n)² + 1 ≤ a·b + r² < 1` ⟹ **`(m·n)² < 0`** ✗ 矛盾 ✓。

比原文短，且因为保留了 `(m·n)²` 项，最后的矛盾形式更"硬"（不是"平均下界"而是直接非负量 < 0）；
两处都用同一对恒等式（`a·b = |m|²−d²/4`、`k² = r²−d²/4`）✓。

### 2.4 存在性（含单点相切）
两条短弧（长度 `< π`，实际 `≤ 2asin(r) < π/4·2`）覆盖 `∂D` 且互不包含时，在共同展开区间上端点序为
`l_a < l_b ≤ u_a < u_b` ✓（`l_b = u_a` 即"单点相切" ✓）。令 `Δ(x) = |x−a|² − |x−b|²`（连续 ✓）：
在 `l_b`：`b` 距离 = r ✓ 且 `l_b ∈ A_a` ⟹ `Δ ≤ 0`；在 `u_a`：`a` 距离 = r ✓ 且 `u_a ∈ A_b` ⟹ `Δ ≥ 0` ⟹ 中间有 `Δ = 0` ✓，
该点 ∈ `A_a ∩ A_b` ⟹ **被两盘共同覆盖的 equality point 存在** ✓。单点相切时该点就是切点 ✓（且它满足
`|x−a| = |x−b| = r`，是三点共点（triple point）✓，与 C892 候选的 tie 结构一致 ✓）。
配合 §2.2/§2.3 的唯一性 ⟹ **恰有一个** ✓。

## §3 "9 条 essential 弧的 cyclic adjacency ⟹ C879 假设"（逐步写出）

**给定**：`r ≤ 0.38`；9 个盘，心满足内向界；其边界弧 `A_i = {x ∈ ∂D : |x−c_i| ≤ r}` 是 proper 弧、**覆盖 `∂D`**。
**结论（逐边 tie 唯一性）**：对每一对"在循环覆盖序中相邻（相交且互不包含）"的弧 `(A_i,A_j)`，
`(c_i,c_j)` 满足 C879 的边界 tie 假设：**恰有一个共同被覆盖的等距点**。

1. （essential / 无包含）§2.1 的精确阈值给出每弧 `|A_i| ≤ 2asin(r)`，8 弧总长 `< 2π` ⟹ 每弧 essential、无包含 ✓。
2. （循环相邻必相交）若某弧的某个端点之外没有别的弧覆盖，则紧邻该端点的点无覆盖 ⟹ 与覆盖矛盾 ✓；
   又因无包含，该"邻居"与 `A_i` 相交且互不包含 ✓（单点相切也算相交 ✓）。**故每个弧的两端各至少有一个相邻弧** ✓。
3. （逐边唯一 tie）对每个相邻对用 §2.4（存在）+ §2.2/§2.3（至多一个）⟹ **恰好一个共同 covered equality point** ✓
   = C879 的"每边唯一公共覆盖等距点" ✓。
4. （`d < 2r` 自动）相邻对共享一个被覆盖点 `x`：`d ≤ |x−c_i| + |x−c_j| ≤ 2r` ✓；等号要求 `|x−c_i| = |x−c_j| = r`
   且 `x` 在圆心连线上 ⟹ `x = m`、`|m| = 1`，与 `|m| < 1` 矛盾 ⟹ **`d < 2r` 严格** ✓（C879 的另一条件 ✓）。

**剩余（不算本引理，必须显式保留）**：

（原文第 14 行已声明这是 separate graph interface ✓）。若某条链边不是弧序相邻对，本引理不给它 tie 唯一性 ✓。
(b) ~~C879 的 `p_out` 条件不在本引理射程~~ → **已在 §4 补上**：lead 统一命名后，该条件对 canonical 相邻弧

## §4 `p_out` 条件自动成立（lead 统一命名 + 我的独立确认）

**命名（lead 统一）**：两 RING 圆的交点 `m ± kn` 中 **norm 较大者 = `p_out`**、较小者 = `pin`。

**新引理**：若 `(A_i,A_j)` 是 canonical 相邻弧（= §3 意义下"恰好一个共同 covered equality point"），则
`pin < 1 ≤ p_out`（即 `p_out ∉ int D` ✓，C879 的该条件自动成立）。

**我的独立推导**（只用抛物线符号 + §1/§3）：单位圆等式点参数 `t±` 是
`φ(t) := |m + tn|² − 1 = t² + 2(m·n)t + (|m|²−1)` 的根，`t₋ < 0 < t₊` ✓（常数项 `|m|²−1 < 0` ✓）；
"covered" 等价于 `|t| ≤ k` ✓（到任一圆心距离 `= sqrt(d²/4 + t²) ≤ r` ✓）。
§1 的唯一性给"至多一个"、§3 的相邻性（存在性）给"至少一个" ⟹ **`[−k,k]` 恰含一个根** ✓。
* 若 `t₊ ∈ [−k,k]`（`0 < t₊ ≤ k`；另一根 `t₋ < −k` ✓）：`φ(k) ≥ 0`（`k` 在右根之外 ✓）⟹ `|m + kn| ≥ 1` ✓；
  而 `−k ∈ (t₋, t₊)` ⟹ `φ(−k) < 0` ⟹ `|m − kn| < 1` ✓。
* 反支 `t₋ ∈ [−k,k]`（`t₋ ≥ −k`，`t₊ > k`）：`φ(−k) ≥ 0` ⟹ `|m − kn| ≥ 1` ✓；`k ∈ (t₋,t₊)` ⟹ `φ(k) < 0` ⟹ `|m + kn| < 1` ✓。
两支都给出：**落在单位圆内的交点是 norm 较小者（`pin`），另一个 `≥ 1`（`p_out`）** ✓；等号 `p_out = 1` 当且仅当
`φ(k) = 0 ⟺ k = t₊`（或对称地 `−k = t₋`），即 **tie 恰为三点共点**（tiling / C892 情形 ✓）。

**与旧版代数的关系（命名更正）**：三点共点情形下，"另一圆-圆交点"（= `pin`，norm 较小 ✓）满足
`|pin|² = (a·b + r²) − 2σk(m·n) = 2(a·b + r²) − 1 < 1` ✓（内向界 + 相异 ⟹ `a·b + r² < 1` ✓）——与 `pin < 1` 一致 ✓，
与"`p_out` = 较大者、此时 `= 1`（boundary）"也一致 ✓。此前我把它标成 `p_out` 是**命名错误**（非数学错误），按 lead 定名已改正 ✓。

**数值控制（独立实现，随机 canonical 对，`r = 0.38`）**：在"proper 弧（`|c| > 1−r`）+ 内向界"的随机对中，筛出
`[−k,k]` 恰含一个单位圆根者共 **34 844** 对：`pin < 1` 违例 **0**、`p_out ≥ 1` 违例 **0**、
`pin < 1 ≤ p_out` 违例 **0**；另 65 548 对 proper 内向对中 `[−k,k]` 内根数分布 = **30 766 / 34 697 / 0**（0/1/2 根）✓
——**没有"两根都被覆盖"的对**，与唯一性引理一致 ✓（0 根 = 无共同 covered equality point，即非相邻对 ✓）。
数值仅为控制，引理由解析推导给出 ✓。
