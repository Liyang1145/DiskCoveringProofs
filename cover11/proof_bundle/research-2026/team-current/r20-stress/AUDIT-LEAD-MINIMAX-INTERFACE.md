## §3 `TC-SYMMETRIC-SECOND-VARIATION.md` 接口核验

### 3.1 `H = −Σλ_i D²f_i = Σμ_i D²f_i = ∇²L`（图坐标内）
`R` 是图表坐标之一 ⇒ `∇²R = 0`，故 `L := R − Σλ_i f_i` 满足 `∇²L = −Σλ_i D²f_i = H` ✓；且 `∇L(z*) = 0`
正是 TC 平稳（`Dfᵀλ = e_R`）✓。

### 3.2 `ker Df` 上的二阶含义（原文的"约束 Hessian"断言）
取 `x(t) ⊂ {f=0}`，`x(0)=z*`，`x'(0)=v ∈ ker Df`。则 `R'(0) = ∇R·v = Σλ_i ∇f_i·v = 0`，
且 `0 = d²/dt² f_i = ∇²f_i[v,v] + ∇f_i·x''(0)`，于是

```
R''(0) = ∇²R[v,v] + ∇R·x''(0) = 0 + Σλ_i ∇f_i·x''(0) = −Σλ_i ∇²f_i[v,v] = H[v,v] .
```

⇒ 原文"约束目标 Hessian = 拉格朗日 Hessian 在该向量上的取值"✓（**依赖平稳性**，不是"二阶导与非线性坐标变换可交换"）。
这也说明 `G = ZᵀHZ` 就是 `R` 沿饱和族 `S_int={f=0}⊂R⁷` 的二阶变分（自由 hub 坐标 `(y0,y1)` 下）✓。

### 3.3 与 minimax `H=Σw_i D²g_i` 的关系（本轮补充的结构事实，全部解析）
在完全饱和流形 `S = {F_i=0 (9), g_j=0 (9)}`（在反射对称 12 维空间里 `dim=2`）上，**每个分支函数恒等于 R**：
`F_i = 0` 经乘积恒等式 `4y²(ρ²−R²)=Fin·Fout`（`y≠0, Fout>0`）给出 `ρ_face = R`；`g_j = 0` 给出 `t_j = R`。
（这两条是**解析蕴含**；区间只认证 `y≠0`、`Fout>0` 这两个正因子，见 §5 口径。）
于是对 `v ∈ T_z S` 与 `x(t) ⊂ S`：`g_i(x(t)) = R(x(t))` 对所有 `t`，故 `∇g_i·v = R'(0) = 0` ⇒ `T S ⊆ K`；
反向 `K ⊆ T S` 由约束微分定义直接得到（`∇F_i·v = c_i(∇γ_i·v_c − δ)`，`δ := v_R = 0`）。
**⇒ `T_z S = K`（同一 2 维空间）**，并且对 `v∈K`、`x(t)⊂S`、`x'(0)=v`：

```
Σ w_i ∇²g_i[v,v] = Σ w_i [ d²/dt²(g_i∘x)(0) − ∇g_i·x''(0) ]
                 = R''(0)·Σw_i − (Σ w_i ∇g_i)·x''(0) = R''(0) = ∇²L[v,v] .
```

（第二个等号用到 `g_i∘x ≡ R∘x`；第三个用到 `Σw_i=1` 与**加权平稳**。）
故 lead 的 `G` 与 minimax 核块是**同一二次型**（只差 `S` 上两组坐标之间的线性坐标变换，即原文的
"congruent" —— 这个措辞是**保守**的）。原文关于"不要把这些特征值与正交 TC 基或物理欧氏坐标比较"的警告 ✓ 必要且正确。
