## 2. 输入 1：exact-root equilibria + positive radial flux（承重前提）

**用到的三条，缺一不可：**

**(i) 归一化平衡族。** `B N=0`；`B α0=(0^{40},1)`（前 40 行 = free-node 平衡在根处成立，最后一行 = `Σ_e α0_e=1`）。⇒ 对 `α=α0+N t`：前 40 行仍为 0（平衡），最后一行仍为 1（归一化）。因为所有权重 `α_e>0`，Dirichlet 能量 `E_α` 对 free 坐标严格凸 ⇒ **根位形 `X0` 是 `E_α` 的（唯一）自由极小点**。

**(ii) 所有 carrying 边长 = R\*。** 于是对族内每个 `α`：`E_α(X0)=Σα_e·R*²=R*²`（**精确定值，不靠 Taylor**）。这一条把"能量的绝对水平"钉死在 R*²，是整个链的常数量纲来源。

**(iii) anchor 载荷径向且向外。** 定义（半梯度约定）`l_j=Σ_{e∋j}s_{je}α_e(X_j−X_e)`。要求 `l_j=a_jU_j`、`a_j>0`。
我的核查：9/9 anchor 的切向分量区间含 0（宽度 ≤1.0e-6），径向 `a_j∈[0.009161,0.022374]`（区间下界 0.0091600>0）✓。

**（iii）有三处独立用处**（这是我在核查中最想强调的接口）：
1. **径向不等式**：`2⟨l0,δ⟩ = 2Σ_j a_j(U_j·δ_j) = 2Σ_j a_j(cos x_j−1) ≥ −Σ_j a_j x_j²`（用 `cos s≥1−s²/2`；**若 a_j<0 则此项反向**）。
2. **一阶驻点（隐藏承重）**：切向载荷给出线性项 `2Σ_j b_j sin x_j`（`b_j:=⟨l0,JU_j⟩`）；**只有 b_j=0 才使 F 在 x=0 有一阶临界点**。若 b_j≠0，`V²≥R*²+c q²`（c>0，小 q）立刻不可能。所以"载荷径向"不是装饰，而是二次下界的前提。
3. **H0 的识别**：certified 的角向 Hessian 是 `H_{ij}=2Λ0_{ij}⟨U_i,U_j⟩ (i≠j)`、`H_{ii}=−Σ_{j≠i}H_{ij}`（行和为零）。它与能量 Hessian `H0:=2[J_U^T(Λ0⊗I2)J_U−diag(a)]` 相等，等价于
   `Σ_j Λ0_{ij}⟨U_i,U_j⟩ = a_i`（即 `Λ0U0=diag(a)U0`，正是 (iii)）。
   我的核查：该逐项恒等式残差 ≤1.8e-10（`a` 尺度 0.016，相对 1.1e-8，受模块 Schur 求解条件数限制）；另以 100 个随机 x 验证 `½x^TH0x = ⟨v,Λ0v⟩−Σa_jx_j²`（相对误差 ≤1.8e-8）。**注意：这条恒等式在文献里常被略过，它是 H0 与认证矩阵的接缝。**

## 3. 输入 2：能量-半径接口（初等，无条件）

`V` 与 `E_α` 都含"对 free 节点取 min"（`V(U)=min_free max_{51}|u_v−u_w|`、`E_α=min_free Σ_e α_e|u_v−u_w|²`）。正确的推导是**先逐配置、再两侧同时取 min**：

对**任意**允许的 free 配置 `z`（anchor 固定）与任意 `α_e≥0, Σα_e=1`：
```
max_e |u_v(z)−u_w(z)|² ≥ Σ_e α_e|u_v(z)−u_w(z)|²                       (★_z)
```
（加权平均 ≤ 最大——这一步只用 `Σα=1, α≥0`，与 V 的边集口径无关）。由于 (★_z) 对每个 `z` 成立，对两侧**同时**取 `min_z` 保持不等号（min 单调）：
```
V(U)² = (min_z max_e ℓ_e(z))² = min_z max_e ℓ_e(z)² ≥ min_z Σ_e α_e ℓ_e(z)² = E_α(U)   (★)
```
即 `V`、`E` **各自在自己的 minimizer 处取值**即可，**不需要**（也不允许）把 free 坐标固定成同一个配置来"逐配置比较"。存在性：能量严格凸 ⇒ E 的唯一 minimizer；V 是连续函数在闭有界自由坐标集上的 min（若 oracle 的自由集紧）。

**因此 (★) 是 V 与 stress 的接缝，且不含任何几何猜想。**

## 4. 精确展开（无 Taylor 余项）—— 我自己的写法

记 `H_α(z):=min_{free} E_α(free,z)`（anchor 位置 `z` 的函数）。`H_α` 是 `z` 的**二次函数**，故
```
F(x) := E_{α(x)}(U(x)) = H_{α(x)}(X0_anch+δ)
      = H_{α(x)}(X0_anch) + 2⟨Λ_{α(x)}X0_anch + c_{α(x)}, δ⟩ + δ^T Λ_{α(x)} δ
```
其中 `c_α` 是 `H_α` 的一次项。用 (i)（`X0` 对每个 `α` 都是 free 极小点 ⇒ `H_α(X0_anch)=E_α(X0)=R*²`）与 (iii)（`Λ_αX0+c_α=l_α(X0)`，anchor 载荷在**未动位置**上取值）得
```
F(x) = R*² + 2⟨l_{α(x)}(X0), δ⟩ + δ^T Λ_{α(x)} δ ,      l_{α(x)}(X0) = l0 + Mx      (E1)
```
**关键点**：`l_{α(x)}(X0)=Σ_e α_e(x) s_{je}(X_j−X_e)` 对 `α` 是**逐项线性**的（位置固定），所以 `M x` 无需任何余项；而"free 坐标重最小化"使二次项只剩 anchor 块 `Λ_{α(x)}`。**(E1) 是恒等，不是 Taylor 展开。**
（我核查的一致性：`H_{α(x)}(X0)=R*²` 在 chart 两端都成立；误差即 §2(ii) 的 1.4e-13。）

## 5. 三项估计（isotropic 版）

**(a) 径向**：由 §2(iii)-1，`2⟨l0,δ⟩ ≥ −Σ_j a_jx_j²`。
**(b) adaptive 线性**：`2⟨Mx,δ⟩ = 2⟨Mx,v⟩ + 2⟨Mx,w⟩`。
 - `2⟨Mx,v⟩ = ⟨Qx, T8^T x⟩`（`T8` 是 **8×45**，`T8^T x = Σ_{j<8}x_j T8[j,·] ∈ R^{45}`；把 `v_j=x_jJU_j` 代入、交换求和）`= x^T (Q^T T8^T) x = τ x^T G'G'^T x = τp²`，最后一步用 `Q'=τN'(G')^T`、`G'=T8N'`（**纯代数**：`(Q^TT8^T)_{jk}=τΣ_eΣ_mN'_{em}G'_{jm}T8_{ke}=τΣ_mG'_{jm}(T8N')_{km}`；数值 300 例误差 ≤8.1e-14）。
 - `w` 项：`‖w‖_F ≤ q²/2`（`w_j=x_j²∫₀¹(1−s)U_j''(sx_j)ds`，`|U_j''|=1`；分量式对**任意符号**成立）、`‖M'x‖ ≤ τ‖A'‖p`（`M'=τA'(G')^T`）⇒ `2⟨Mx,w⟩ ≥ −τ‖A‖pq²`。数值：`‖δ‖/q≤1`、`‖v‖/q=1`、`‖w‖/q²≤0.434`，`‖A‖_F=1.0733`（与 C919 注册的 1.074 一致）。
**(c) 二次项（α 依赖 x 的 minimized-energy 比较）**：设 `β0(x):=max_e|(Q'x)_e|/α0_e`。则逐边 `(1−β0)α0_e ≤ α_e(x) ≤ (1+β0)α0_e`，于是**对同一个 δ** `E_{α(x)}(δ) ≥ (1−β0)E_{α0}(δ)`；对 anchor 块做自由最小化（min 单调）即得
```
(1−β0)Λ0 ≤ Λ_{α(x)} ≤ (1+β0)Λ0    （作为二次型）                                (E2)
```
并且 `β0 ≤ τ B' p`（`B':=max_e‖N'_e‖/α0_e`；`|(Q'x)_e|=τ|N'_e·(G'^Tx)|`）。数值核查：两 chart 各 60 个 x（球内），120/120 满足 (E2)，且 `β0/(τB'p) ≤ 0.795 ≤ 1` ✓。
展开 `δ=v+w`、丢掉 `w^TΛ0w≥0`：
```
δ^TΛ_{α(x)}δ ≥ (1−β0)[⟨v,Λ0v⟩+2⟨v,Λ0w⟩] ≥ ⟨v,Λ0v⟩ − d q³ − β0 d q² ,
```
第一项损失用 `‖v‖=q, ‖w‖≤q²/2, Λ0≤dI`（`d=‖Λ0‖`），第二项用 `δ^TΛ0δ≤d‖δ‖²≤d q²`。

**组合（isotropic）**：把 (a)(b)(c) 与 (E1) 相加，注意 `½x^TH0x=⟨v,Λ0v⟩−Σa_jx_j²`（§2(iii)-3）恰把 (a) 的径向损失与 (c) 的 `⟨v,Λ0v⟩` 合成 `½x^T[H0+2τG'G'^T]x`：

F(x) ≥ R*² + ½x^T[H0+2τG'G'^T]x − [d(1+b)+m] q³ ,   b:=τB'‖G'‖ (≥β0/q), m:=τ‖A‖‖G'‖

## 6. 各向异性版（p 替换 q）与配方

### 6.1 mixed cubic 恒等式（我的推导，可逐项检查）
不丢 `w`，而把 `w` 拆成显式二次部分 + 三次余项：定义
`R_j := δ_j − v_j + (x_j²/2)U_j = w_j + (x_j²/2)U_j`。**精确积分余项**（`U_j(x)=e^{ix}U_j` 为半径 1 圆弧，`|U_j'''|=1`）：
```
R_j = x_j³ ∫_0^1 ((1−s)²/2) U_j'''(s x_j) ds    ⇒   |R_j| ≤ |x_j|³/6      (对 x_j 任意符号)
```
（不是 `O(x⁴)`，也不含可负的 `x_j³`：右端是 `|x_j|³/6`。）
因为 `w=R−(x²/2)U`：
```
2⟨v,Λ0w⟩ = 2⟨v,Λ0R⟩ − 2⟨v,Λ0(x²U/2)⟩
          = 2⟨v,Λ0R⟩ − Σ_{i,j} Λ0_{ij} x_i x_j² ⟨JU_i,U_j⟩ =: 2⟨v,Λ0R⟩ − x^T·Cross·x^{(2)}    (E3)
```
其中 `Cross_{ij}=Λ0_{ij}⟨JU_i,U_j⟩=Λ0_{ij}(U_i^xU_j^y−U_i^yU_j^x)`、`x^{(2)}=(x_j²)_j`。**(E3) 是恒等**（数值误差 ≤3e-27，机器精度）。两个界：
`|x^T·Cross·x^{(2)}| ≤ ‖Cross‖_F·q·‖x^{(2)}‖₂ ≤ C_cross q³`（`‖x^{(2)}‖₂=√(Σx⁴)≤q²`；数值比 ≤0.135 说明该界松弛约 7 倍），
`2⟨v,Λ0R⟩ ≥ −2‖v‖·d‖R‖ ≥ −(d/3)q⁴`（数值 `|·|/q⁴ ≤ 0.0102 ≤ d/3=0.0267` ✓）。
**full i,j 求和必需**：`Cross_{ii}=Λ0_{ii}(U_i^xU_i^y−U_i^yU_i^x)=0` **恒等**（对角项恒为零，我上一版写"对角非零"是错的，撤回）；但**非对角项（i≠j）一般不消失且成对出现**，所以 (E3) 的 i,j 全和不可省。

### 6.2 p q² 配方（我补全的代数）
```
V²−R*² ≥ ½x^T H0 x + τp² − C_cross q³ − (d/3)q⁴ − τ(B'd+‖A‖) p q²      (E4)
```
推导：`δ^TΛ_αδ ≥ (1−β0)δ^TΛ0δ ≥ ⟨v,Λ0v⟩ − C_cross q³ − (d/3)q⁴ − β0 d q²`（β0d q² ≤ τB'd·p q²）；`2⟨Mx,w⟩ ≥ −τ‖A‖pq²`；径向与 `⟨v,Λ0v⟩` 经 §2(iii)-3 合成 `½x^TH0x`。
取 `τ0<τ` 使 `H0+2τ0G'G'^T ≥ μ0I`：`½x^TH0x+τp² = ½x^T[H0+2τ0G'G'^T]x + (τ−τ0)p² ≥ (μ0/2)q²+(τ−τ0)p²`。配方
```
min_{p≥0}[(τ−τ0)p² − c p q²] = −c²q⁴/(4(τ−τ0)),   c=τ(B'd+‖A‖)
```
于是
```
V²−R*² ≥ [ μ0/2 − C_cross q − ( d/3 + τ²(B'd+‖A‖)²/(4(τ−τ0)) ) q² ] q²             (E5)
```
**C920 的 τ0=τ/2 恰使 `τ²/(4(τ−τ0))=τ0`**（1468/734：`1468²/(4·734)=734` ✓ 我独立验算），所以四次系数 = `d/3+τ0(B'd+‖A‖)²`。用注册常数复算：`quartic=1.7305099683`、`μ/2−C_cross ρ−quartic ρ² = 1.0170420782e-5 > 1e-5`（ρ=0.01458）；正性 `τB'‖G'‖_F ρ = 0.16277 < 1` ✓。加上 §5 的单调性 ⇒ 整球成立。

## 7. 基变换（任意 dyadic R）的合法性：我的判定

**(a) 代数层面：不变。** 若 `N'=NR`（45×4）、`G'=T N'=G8R`、`A'=AR`，则 `B N'=0`、`1^TN'=0`（⇒ 平衡+归一化仍在）、`Q'=τN'(G')^T`、(E1)(E2)(E3)(E4)(E5) 的推导**逐字适用**（每步只用 `N',G',A'` 的定义与 `H0` 的结构）。`R` 不必对称/可逆/白化 —— **这一点我确认**。

**(b) 假设层面：必须逐基重认（"任意 R"不是自动的）。** `B'、‖G'‖、μ0、b、m` 全是 `R` 的函数；数值反例：

所以正确的读法是"**对任意固定 R，同一套代数可用，但每条不等式都要以该 R 重新区间认证**"。

**(c) 覆盖层面：无新增义务（撤回上一版 §7(c)）。** `x` 是**物理 raw-θ8 chart**（anchor 角位移），与 `R` 无关；`R` 只换**应力 basis**（同一 `x` 对应的应力族不同）。因此各 chart 的结论都是关于**同一个物理球** `{‖x‖≤ρ}` 的陈述：每个 chart 在自己的正性条件 `τB'‖G'‖ρ<1` 成立处给出有效下界，(E1)–(E5) 的推导不涉及、也不需要任何"图像/覆盖"账。我上一版提出的"奇异 R 使图像退化 ⇒ 需新覆盖账"**撤回**（那是对"R 变换物理坐标"的误读）。

## 9. 口径澄清与撤回（按 lead 核对结果修订；不影响 §0/§8 的判定）
