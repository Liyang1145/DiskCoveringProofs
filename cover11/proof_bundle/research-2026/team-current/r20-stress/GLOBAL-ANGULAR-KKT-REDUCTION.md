## §0 结论（****v2 修正****：第 3 点按 lead 反驳重做）

1. **内点角向极小 ⟹ 存在"每个 anchor 负载都径向"的最优负载系** ✓（存在性，不是唯一性 ✗）。
   机制：`V(U) = max_{dual} Σ_i⟨l_i,U_i⟩` ✓，`∂V` 是一族线性函数的上确界的次微分 ✓；
   对每个 anchor 的**独立**角变量求导只牵涉该 anchor 自己的块 ⟹ `0 ∈ ∂(V∘U)(θ*)` 等价于
   **存在**对偶点 `ξ = Σλ_jξ^{(j)}` 使 `⟨ξ_i, JU_i⟩ = 0` ∀i ✓（每个 `ξ_i` 径向 ✓）。
2. **这不足以消掉自由角** ✗：被钉住的只是每个 anchor 负载的**切向**分量 ✓；**径向分量仍自由** ✗，
   角向驻定条件（`⟨ξ_i,JU_i⟩ = 0` 这 8 条）仍然必须在 ✓。**也不强制固定 active 模式** ✗
   （同一模式在邻域内保持需要非退化/严格互补，非一阶 KKT 所蕴含 ✗）。
3. **径向非负：只对optimal dual 成立**（v1 的"任意 feasible"版本按 lead 反驳**撤回** ✗）。正确论证 = **投影 + 互补**：
   * **(投影引理)** 把全部自由节点投影到 `conv(U)` **不增加任何边长** ✓（投影 1-Lipschitz；anchors 本就在凸包内 ✓）
     ⟹ 投影后的 primal 以同一 `V` 可行 ⟹ **存在所有自由节点都在 `conv(U)` 内的 primal 最优** ✓；
   * **(互补 + aligned 引理)** 取任意 **optimal** dual `α` 与这样的互补 primal 最优：互补松弛 ⟹ 每条 `α_e ≠ 0` 的边**紧**
     （长度 `= V` ✓）；其单位方向 `u = (U_i − X)/V`（`X` = 自由端）满足
     `⟨u, U_i⟩ = (1 − ⟨X,U_i⟩)/V ≥ (1 − |X|)/V ≥ 0` ✓（`X ∈ conv(U) ⊂ B̄(0,1)` ✓，锚在单位圆上 ✓）
     ⟹ 在 SOCP 乘子符号约定（aligned：`α_e ≥ 0` ✓）下 `⟨l_i,U_i⟩ = Σ_{e∋i} α_e⟨u_e,U_i⟩ ≥ 0` ✓；
     **严格 > 0** 当某入射边 `α_e > 0` 且 `|X| < 1` ✓；若自由端落在 `∂D` 只有弱不等式 ✓。
   * **关键区分**：`α ≥ 0`（aligned）与"边紧"是**最优/互补的额外条件** ✓，**不是** dual feasible 的普遍性质 ✗；
     oracle 的 sites **自由** ⟹ 本论证**不**引用真实 cover 的 inward 界 ✗。另：`V` 是 **1 次**齐次 ✓ ⟹ Euler 给
     `Σ_i⟨l_i,U_i⟩ = V` ✓（**不是** `2V` ✗；`2V²` 属 `V²` ✓）。
4. **最大原理尝试失败** ✗，但留下一条有用结构：把每个 anchor 的**切向平衡**写成 2×2 分裂
   （lead §5 line 35：`α = s_d/(s_d − s_c)`，`s_c = ((U−c)/R)·T` ✓），其**正性**恰好等价于
   "两个切向斜率异号且非零" ✓（= 我在 `fresh_acute_slopes_interval.py` 认证的 9/9 + `|slope| ≥ 0.51` ✓）。
   这条给出的是**最优互补的额外条件**（局部可解性/正性 ✓），不是极值原理 ✓。

## §1 内点一阶条件（含 active cap 的口径）

* 角向图：`U(θ)`，`θ ∈ R^8`（固定整体旋转 ✓）；`V∘U` 是 Lipschitz ✓（`V` 凸且正齐次 ✓、`U` 光滑 ✓）。
* **Clarke 链式（包含，非等式 ✓）**：`∂(V∘U)(θ*) ⊆ (∂U/∂θ)^T ∂V(U*)` ✓。
  故 `0 ∈ ∂(V∘U)(θ*)` ⟹ **存在** `ξ ∈ ∂V(U*)` 使 `(∂U/∂θ)^Tξ = 0` ✓。
* 具体化：`∂U/∂θ` 的第 `i` 块是 `JU_i`（`J` = 90° 旋转 ✓，`θ_i` 只出现在第 `i` 个 anchor ✓）⟹
  `⟨ξ_i, JU_i⟩ = 0` ∀i ✓ ⟹ **每个 anchor 的（选定的那个最优）负载块径向** ✓。
* 为何可"选一个径向的代表"：`V` 是**线性函数族的上确界** ✓ ⟹ `∂V(U*) = conv{ξ^{(j)} : j ∈ 活跃极点}` ✓
  （CX909 的 lift 给出一个极点 ✓；一般情形是凸包 ✓）；凸组合**仍是极优** ✓ ⟹ 存在最优负载系使所有块径向 ✓。
* **active cap 的情形**（lead 提示 ✓）：若某个宽度/角约束活跃，则一阶条件变成
  `0 ∈ ∂(V∘U)(θ*) + N_{active}(θ*)` ✓——**累积乘子可以吸收切向残量** ✗ ⟹ "存在径向负载系"可能失效 ✗
  （这解释了为何内点性是这句结论的前提 ✓，也解释了 lead 为何允许累积乘子 ✓）。

## §2 为什么"消自由角"不成立

* 一阶条件只给 `⟨ξ_i, JU_i⟩ = 0`（**切向**）✓；`⟨ξ_i, U_i⟩`（**径向**）完全不被约束 ✗——
  径向方向**不是**角向图里的可行方向 ✓（anchor 被单位圆约束 ✓）。
* 因此 `V∘U` 的角向驻定性**不能**把角变量消掉 ✗；能消的只是每个块的一个分量 ✓。
  要真正消角，需要**二阶或全局**信息（例如 `H_0|_K ≻ 0` 型的局部二次增长 ✓，或外层 8-angle 的非凸处理 ✓）。
* **固定 active 模式**：一阶 KKT 只决定 `θ*` 处的一个/一组对偶点 ✓；该模式能否在 `θ*` 的邻域保持
  需要**非退化性**（严格互补 / Slater 型 ✓），一阶条件不蕴含 ✗。故"内点 KKT 强制某固定 active 模式"**不成立** ✗
  （但在 nondegenerate 情形下可以*局部*固定 ✓——这是条件性陈述，不是无条件结论 ✓）。

## §3 径向非负：**投影 + 互补**论证（v1 的"任意 feasible 非负"已按 lead 反驳撤回 ✗）

**(a) 投影引理（成立；只用 oracle 自身结构，不引入真实 cover ✓）**：设 `(X, α)` 是固定 anchor tuple `U` 下的 primal/dual 最优对。
令 `C := conv(U_1..U_9)`（锚在单位圆上 ⟹ `C ⊂ B̄(0,1)` ✓），把**每个自由节点**换成 `Π_C(X_v)` ✓。
投影 1-Lipschitz ⟹ 任意两节点间距离**不增** ✓；锚已在 `C` 内 ⟹ 位置不变 ✓ ⟹ 所有边长不增 ⟹ `max_e|e_e| ≤ V` ✓ ⟹
`V(ΠX) ≤ V` ✓，而 `V` 为最小 ⟹ `= V` ✓ ⟹ **存在所有自由节点都在 `C` 内的 primal 最优** ✓✓。

**(b) 互补 + aligned 引理**：取**任意** optimal dual `α`（乘子符号约定：约束 `|e_e| − V ≤ 0` 的乘子 `α_e ≥ 0` ✓，
即 aligned 方向 = 沿边从自由端指向另一端 ✓）与该 primal 最优（自由节点 ∈ `C` ✓）：互补松弛 `α_e(|e_e| − V) = 0` ✓
⟹ 每条 `α_e ≠ 0` 的边**紧**（`|e_e| = V` ✓）。设该边连 anchor `U_i` 与自由端 `X` ✓，则
```
⟨(U_i − X)/V, U_i⟩ = (1 − ⟨X,U_i⟩)/V ≥ (1 − |X|)/V ≥ 0        （|X| ≤ 1 ✓，因 X ∈ C ⊂ B̄(0,1) ✓）
```
⟹ `⟨l_i,U_i⟩ = Σ_{e∋i} α_e⟨u_e,U_i⟩ ≥ 0` ✓（每项 `≥ 0` ✓、`α_e ≥ 0` ✓）。**严格 > 0** 当某入射边 `α_e > 0` 且 `|X| < 1` ✓；
若自由端恰在 `∂D`（例如 `X` 就是某个 anchor ✓）则该项 `= 0` ⟹ 只有弱不等式 ✓（边界情形已列 ✓）。

**(c) 平移/凸性/齐次性各自给什么（Euler 错误已修）**：
* `V` 关于 Cartesian anchors **凸**且 **1 次正齐次** ✓（lead §3 ✓）⟹ Euler：`⟨∇_UV, U⟩ = V` ✓
  （**不是** `2V` ✗——`2V²` 属 `V²` 的 Euler 恒等式 ✓）。它只定"总体径向缩放" ✓，对单个 anchor 的径向分量无信息 ✗。
* 刚性运动（平移/旋转）下 `V` 不变 ✓ ⟹ 这些方向无有用变分 ✓；**凸性不延伸到单位圆角域** ✓（lead §3 ✓）= §2 的困难根源 ✓。
* ⟹ 逐 anchor 定号**不能**由平移/凸性/Euler 得到 ✗——只能来自 (a)+(b) ✓。

**(d) 为什么"任意 dual feasible"版本必假（采纳 lead 反驳）**：只要求 `α` 可行（不要求最优/互补）时，`α_e` 可取负号（未 aligned）
或对应非紧边 ⟹ (b) 的每项非负不再成立 ✗ ⟹ `⟨l_i,U_i⟩ ≥ 0` 不可能普遍成立 ✓。
故 **`α ≥ 0`（aligned）+ 边紧 = optimal/互补的额外条件** ✓，不是可行性的普遍性质 ✗。

**(e) 最大原理尝试与其不足**：可试的量 = 负载沿 ring 环的传播（用 site 平衡自一条 anchor 边推下一条 ✓），
其正性 ⟺ 两切向斜率异号非零 ✓（lead §5 的 `α = s_d/(s_d − s_c) ∈ (0,1)` ✓）。不足：
(i) 传播可解性 = 对偶可行性自身（循环 ✗）；(ii) 圆上无单调方向（`V` 旋转不变、无极大/极小端 ✓）；
(iii) 负载非调和/单调 ⟹ **无真正极值原理** ✗。留下可用事实：§3(a)+(b) 的径向非负（**optimal dual 专属** ✓）、
`Σ_i⟨l_i,U_i⟩ = V` ✓（Euler，1 次齐次 ✓）、切向由 2×2 分裂确定 ✓。

## §4 明确不足（不得越界引用）

1. §0.1 是**存在性** ✓；**不**声称所有最优对偶系都径向 ✗（C909 的 radial 只针对 C897 lift ✓，且 C909 scope 是 single exact anchor tuple ✓）。
2. §0.3 的径向非负**只对 optimal dual** 成立 ✓，且依赖 §3(a) 的投影互补 primal ✓；
   **不得**推广到任意 dual feasible `α` ✗（未 aligned 可取负号 ⟹ 必假 ✓）；也**不蕴含** angles 的驻定 ✗（它对所有 optimal 对成立 ⟹ 对 angles 无约束力 ✓）。
3. **oracle 的 sites 自由** ⟹ 本件（含 §3）**不**引用真实 cover 的 inward 界（`|c| < 1`、`|c| ≤ sqrt(1−r²)`）✗；
   §3(a)+(b) 只用 oracle 自身结构（固定 anchors、自由节点、`conv(U) ⊂ B̄(0,1)` ✓）。
4. 内点性、非退化性、active cap 三者必须写清：**有 active cap 时**结论 1 可失效 ✗；
   **无非退化时**"固定模式"不成立 ✗。
5. 本件**不**做尺寸计数、不把数值秩当 exact ✗；C909 的区间部分（acuteness `> 7/100`、`|slope| > 51/100` ✓）
   我已在 `fresh_acute_slopes_interval.py` 侧独立认证过 ✓（本件只引用，不重复计算 ✓）。
6. 本件**不**给 global 结论 ✗、**不做二阶扩展** ✗：外层 8-angle 的非凸性仍在（`VECTOR-FORCE-DUAL-AND-ORACLE.md` §4 ✓）。
