## §1 定理与证明（写成可逐行核对的形式）

记号：`D` = 单位闭盘，`X = (c_1..c_11) ⊂ R²`，`d_X(y) = min_i |y − c_i|`，`R_D(X) = max_{y∈D} d_X(y)`，
`R = R_D(X)`，`E = d_X^{-1}(R) ∩ D`。

**定理**：若 `E` 有限且 `0 ∉ E`，则对任意有限 `Q ⊂ D` 存在 `θ ∈ [0,2π)` 使 `max_{q∈Q} d_X(R_θ q) < R`。

**证明**：对 `q ∈ Q` 定义 `Θ_q = {θ : R_θ q ∈ E}`。
* 对每个 `e ∈ E`，方程 `R_θ q = e` 在 `θ` 中**至多一个解**：若 `q ≠ 0` 且 `e ≠ 0`，两边取模得 `|q| = |e|`（否则无解），
  再比较角得唯一 `θ`；若 `q = 0`，则 `R_θ q = 0`，而 `0 ∉ E` ⟹ 无解；`e = 0` 不可能（`0 ∉ E`）。
* 故 `Θ_q` 有限（`|Θ_q| ≤ |E|`），从而 `Θ := ⋃_{q∈Q} Θ_q` 有限；取 `θ ∉ Θ`。
* 对任意 `q`：`R_θ q ∈ D`（旋转不变）且 `d_X ≤ R` 于 `D` 上（`R` 是覆盖半径的定义），而 `d_X(R_θ q) ≠ R`（因 `θ ∉ Θ_q`）
  ⟹ `d_X(R_θ q) < R`。有限集上取 max 仍 `< R`。∎

**推论 1（sharpness 的普适排除）**：记 `r_fin(Q) := inf_{Y} max_{q∈Q} d_Y(q)`（= 对固定 `Q` 的 11-center 有限问题）。
由旋转不变性 `R_D(R_θ X) = R` 与上式得 `r_fin(Q) ≤ max_{q∈Q} d_{R_θ X}(q) = max_{q∈Q} d_X(R_{−θ} q) < R = R_D(X)`。
即：**任何固定有限 witness 集都不可能达到候选半径 `R`（= C529）**；任何"sharp/精确"形式的固定 witness 下界被排除。
（注：这只排除"达到 R"；不含任何定量差距，见 §3 的定量版与 §6 的边界说明。）

**推论 2（对偶/组合路线同样被排除，对同一 Q0）**：若 `r_fin(Q0) ≤ 0.3278`（§3 认证），则对每个 `r > 0.3278`
（特别 `r = T_cert`）覆盖是**可行**的：11 个半径 `r` 的圆盘可以覆盖 `Q0`。「conflict graph 的团/chromatic 下界」
或任何 LP/Farkas 对偶证书，都只能证否"可行"，故在 `r ≥ 0.3278` 处**不存在**任何这样的证书。

**前提的合法性来自 C892 结构**（lead 所述"C892 11facets + boundary arc 严格 < 中间 直接 exact E = 18 active"），
我把它做成区间核验（§2）。

## §5 lifting / 对偶：18 个正权重能否救固定 witness 路线？—— 不能

* **power-lifting（paraboloid）**：`w` 被以 `(c_i, R)` 为心的盘覆盖 ⟺ `power_i(w) = |w|² − 2⟨w, c_i⟩ + (|c_i|² − R²) ≤ 0`
  —— 对固定 `w`，这是**提升变量** `(c_i, σ_i := |c_i|² − R²)` 的**线性**不等式 ✓。对**固定 assignment**，覆盖可行性
  （固定 `R`）是 SOCP（凸）✓；真正的非凸只来自 **assignment 的析取**（组合结构）✓。
* 因此"固定 witness 集的 exact 下界"若要有对偶证书，只能是：某个 weighting / colored-clique / Farkas 证书证否
  "11 盘覆盖 `Q`" ✓。而 §3 给出 `Q0` 在 `r = T_cert` 处**可覆盖**（值 ≤ 0.3278 ≪ T_cert）⟹ **此类证书不存在** ✓。
* **18 个正权重的正确角色**：它们在候选处给出**一阶支撑结构**——`Σ_f w_f ∇_c γ_f = 0`（lead lift 的中心分量部分）
  且 `w_f > 0` ⟹ 对任意方向 `v`：`max_f ⟨∇γ_f, v⟩ ≥ Σ w_f⟨∇γ_f, v⟩ = 0` ✓。这是**真目标**（移动 witnesses）在候选处
  的一阶不可下降性；而固定 witness 目标在同一构型可被 rotation 一阶下降 −0.1242（§4）⟹ 两条目标在候选处**一阶分离**，
  这正是"固定 vs 移动 circumcenter"的区别所在（lead 强调必须保留的一点）。
* 结论：lifting/对偶本身没有障碍，障碍是**固定 witness 松弛严格弱于真问题**；要 sharp 的全局不等式必须让 witness
  随构型移动（即用 configuration-dependent 的临界值，或既有 stress 形式 `Φ_λ`），或在无限/稠密 witness 极限下工作。
