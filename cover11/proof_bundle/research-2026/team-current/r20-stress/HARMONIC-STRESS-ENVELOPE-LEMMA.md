# Harmonic-stress envelope：**角向图**下的局部充分条件（v2；纯解析；不作 global 声称）

> 写作用域：本目录（sole write）。**v2 修正 lead 指出的 v1 四处接口错误**：
> ① 变量是**角度 `θ`**（固定整体旋转的角向图），不是 Cartesian `δU` ✗→✓；
> ② **撤**"F 二次型 ⟹ 无三阶项" ✗——`U(θ) = (cosθ, sinθ)` 是三角的，角向展开**有**非零高阶项，必须给**显式 Taylor 余项** ✓；
> ③ **Euler 齐次障碍**：`F_α` 关于 `U` 二次齐次 ⟹ Cartesian 梯度凸包**不可能**含 0（`E* = R² > 0`）✗ ⟹ `g, H` 必须在**角向图**里定义 ✓；
> ④ 权重 `λ` **必须**零梯度平均（`Σλ_jg_j = 0`），否则 `δ_S = O(|δ|²)` 方向的 `O(δ²)` 抵消会毁掉二次增长 ✗——
> 唯一安全的平均是 distinguished 的 `f_0 = f_{α_radial}`（`g_0 = 0` ✓）。数值一律只作 numeric（§5）✓。

## §0 对象

* 图：11 center + 11 aux（自由）、9 anchor（固定）、51 edge；slack 面 6 条边 `α = 0` ⟹ **45 未知** ✓。
* `A* = {α ≥ 0, Σα = 1, α_slack = 0, 自由节点散度 Σ_{e∋v} α_e(X_v − X_w) = 0}`（40 非平凡约束 + 归一化 ⟹ 线性 polytope ✓；
  `α_radial` 是其中 distinguished 一点 ✓，其余 `α` 的角向梯度一般非零 ✓）。
* `F_α(U) := min_{free} Σ_e α_e|X_v − X_w|²`（加权 Laplacian 对自由块的 **Schur 补**，关于 `U` 是二次型 ✓）。
* **角向图**：`U(θ) = (cos θ_i, sin θ_i)_{i=1..9}` ✓，`θ ∈ R^8`（固定整体旋转 ✓）；`f_j(θ) := F_{α_j}(U(θ))` ✓，`δ := θ − θ*` ✓。
  **所有 `g_j, H_j, K, S` 都在这个图里** ✓。

## §1 两条基本事实

**(F1) 无条件下界**：任意 `α ≥ 0, Σα = 1`（**不需**散度条件）：`F_α(U) ≤ Σ_e α_e|e_e(z*)|² ≤ max_e|e_e(z*)|² = R(U)²` ✓
（极小性 + 加权平均 ≤ 最大 ✓）⟹ 任意有限族：`R(U)² ≥ max_j F_{α_j}(U)` ✓（散度条件只在候选处确保**取等** ✓）。

**(F2) 候选处锚定**：`α ∈ A*` ⟹ 候选自由位置是能量驻点；对自由块凸 ⟹ 驻点即全局极小 ✓；候选带力边长度全 `= R`、`Σα = 1`
⟹ `F_α(U*) = R²` ✓ ⟹ **整个 `A*` 在候选处同值** ✓。推论：`f_j(θ*) = R²` ✓ 且 `Φ(θ) := max_j f_j(θ) ≤ R(U(θ))²` ✓。

## §2 角向展开 + **显式余项**（撤 v1 的"无三阶项" ✗）

`f_j(θ* + δ) = R² + ⟨g_j, δ⟩ + ½⟨H_jδ, δ⟩ + Rem_j(δ)` ✓，其中
* `g_j = 2(∂U/∂θ)^T S_{α_j}U*` ✓（`S_{α_j}` = Schur 补；`∂U/∂θ` = cos/sin 的 1-Lipschitz 块 ✓）；
* `H_j = 2(∂U/∂θ)^T S_{α_j}(∂U/∂θ) + 2(∂²U/∂θ²)S_{α_j}U*` ✓——**第二项非零** ✗（v1 漏掉的就是它 ✓）；
* `|Rem_j(δ)| ≤ C_j|δ|³` ✓，`C_j` **由显式求和给出（不是"量级 ≤ 2"** ✗）：把能量写成**成对余弦形式**
  `E(θ) = Σ_{i≠j} Λ_{ij}cos(θ_i − θ_j)`（`Λ` = 边界 Schur 读数 ✓，见 §5；对角项并入常数 ✓），则三阶导只由
  `cos` 的三阶导落入 `sin(θ_i − θ_j)`（`|·| ≤ 1` ✓）组合而成 ⟹
  ```
  C_j ≤ κ · Σ_{i≠j} |Λ^{(j)}_{ij}|        （κ = 显式组合常数：由三元组计数给出，非"数量级"估计）
  ```
  一般 `S_{α_j}` 形式同样：`C_j ≤ κ · Σ|(S_{α_j}) 的条目|` ✓——**不是零余项** ✗。

**Euler 障碍（v1 第 3 处错误）**：`⟨∇_UF_α, U⟩ = 2F_α` ✓；若 `0 ∈ conv{∇_UF_j(U*)}`，对 `U*` 取内积得
`0 = 2Σλ_jF_j(U*) = 2R² > 0` ✗ ⟹ **Cartesian 梯度凸包永不含 0** ✓ ⟹ 只能在角向图里表述 envelope ✓。

## §3 修正后引理 E′（split 两支；不用任意 λ-平均 ✗）

输入：`f_0 := f_{α_radial}`（`g_0 = 0` ✓、`H_0` 在**临界空间 `K`** 上正定 ✓）与**对称有限族** `{f_k^± = f_{α_0 ± t_kδ_k}}`（`δ_k` = `A*` 零空间方向 ✓）。

**引理 E′**：设 (E1) `f_j(θ*) = R²` ∀j ✓（由 (F2) ✓）；
(E2′) 角向锋利性 `max_k|⟨g_k, δ⟩| ≥ c_1|δ_S|`（`δ_S` = `δ` 在 `S := span{g_k} = im(G)` 上的投影，`c_1 > 0` ✓）；
(E3′) **只在 `K` 上**：`⟨H_0δ, δ⟩ ≥ c_2|δ|²` **对 `δ ∈ K`** ✓（`K := ker(G^T) ∩ rot^⊥`；`c_2 > 0` ✓）——
**注意**：`H_0` 在 `K` 外**indefinite** ✗（§5 的单点读数：负特征值 `−9.28e−3` ✓），故
**不得**写成"`⟨H_0δ,δ⟩ ≥ c_2|δ_K|²` 对整个 `δ`" ✗✗（交叉项与 `δ_{K^⊥}` 部分可以把它拉负）；
(E4′) `|Rem_0(δ)| ≤ C_0|δ|³` ✓（`C_0` 由 §2 的 `Σ|Λ|` 型显式和给出 ✓）；
则 `∃ρ,c>0`：`R(U(θ))² ≥ Φ(θ) = max_j f_j(θ) ≥ R² + c|δ|²`（`|δ| ≤ ρ`）✓。

**正交分解（先把空间说清）**：在固定旋转的 `8` 维空间里，`rot ⊂ ker(G^T)` ✓，且
`R^8 = im(G) ⊕ (ker(G^T) ∩ rot^⊥) = S ⊕ K` ✓（`dim = 4 + 4` ✓，与 lead 的 4 个非零奇异值 + `dim K = 4` 一致 ✓）。
记 `δ = δ_S + δ_K` ✓（正交 ✓）。

**证明（split；只用 (E3′) 在 `K` 上的正性）**：取 `M > 0`。
1. `|δ_S| ≥ M|δ|²`：对称族给 `max_{±}⟨±g,δ⟩ = |⟨g,δ⟩| ≥ c_1|δ_S| ≥ c_1M|δ|²` ✓；而 `f_0` 的一阶项为 0、二阶项与余项合计
   至多 `‖H_0‖·|δ|² + C_0|δ|³` ✓（`H_0` indefinite 也不影响**上界** ✓）⟹ 存在只依赖 `(c_1M, ‖H_0‖, C_0)` 的小 `ρ_1` 使
   `|δ| ≤ ρ_1` 时 `≥ R² + (c_1M/2)|δ|²` ✓。
2. `|δ_S| < M|δ|²`：用 `f_0`（`g_0 = 0` ✓）与**正交分解**：
   `⟨H_0δ,δ⟩ = ⟨H_0δ_K,δ_K⟩ + 2⟨H_0δ_S,δ_K⟩ + ⟨H_0δ_S,δ_S⟩` ✓；
   第一项 `≥ c_2|δ_K|²` ✓（(E3′) ✓），后两项**只能**用 `‖H_0‖` 上界：
   `≥ c_2|δ_K|² − 2‖H_0‖|δ_S||δ_K| − ‖H_0‖|δ_S|²` ✓ ⟹ 由 `|δ_S| ≤ M|δ|²`、`|δ_K| ≤ |δ|` 得后两项 `= O(|δ|³)` ✓
   ⟹ `f_0 ≥ R² + (c_2/2)|δ_K|² − C'|δ|³`（`C'` 显式 ✓）。又 `|δ_K|² = |δ|² − |δ_S|² ≥ |δ|²(1 − M²|δ|²)` ✓
   ⟹ `≥ |δ|²/2` **当且仅当 `|δ| ≤ 1/(√2 M)`** ✓（**这个条件此前漏写** ✗）⟹ 在
   `|δ| ≤ min(1/(√2M), c_2/(8C'))` 上得 `≥ R² + (c_2/8)|δ|²` ✓。
* **（不写显式 `ρ`）**：完整不等式组需要 `M`、`‖H_0‖`、`c_1`、`c_2`、`C_0`（及其相互依赖，如 `ρ ≤ 1/(√2 M)` ✓）
  ——在这些常数的**界**给出之前**不**写显式 `ρ` ✗（v2 此前写的 `ρ = min(c_1M/(4C), c_2/(16C_0), 1)` 缺 `‖H_0‖` 依赖 ✗，**撤回** ✓）；
  引理只作**存在性**陈述 ✓。

**必须保留的三点**：(i) 任意 `λ` 平均不安全 ✗（`Σλ_jg_j ≠ 0` 时在 `δ_S = O(|δ|²)` 方向线性增益降为 `O(|δ|³)` ✗，
**分方向单独修不了** ✓）；(ii) `H_0` **只**在 `K` 上正定 ✓（`K` 外的负方向由 (E2′) 的一阶锋利性处理 ✓——
**不是**由 `H_0` 的正性处理 ✗）；(iii) 余项**必须**带 ✓ 且常数由 `Σ|Λ|` 型显式和给出 ✓（§2 ✓）。
