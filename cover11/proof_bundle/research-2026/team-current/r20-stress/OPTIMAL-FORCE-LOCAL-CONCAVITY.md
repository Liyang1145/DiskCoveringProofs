**正确事实**：力向量 `p` **固定、与 anchors 无关**；力平衡是**纯 incidence 关系** ⟹ **对全锚位恒成立** ✓

`a_i, d_i` 的正确取值见 §4（= 载荷的径向/切向分量 ✓）。另：§2 的等式链**不得**预设对齐 ✗，见 §2 的双不等式写法 ✓。

## §2 等式的链（双不等式 + 全非负 gap + 总 gap 0 ⟹ 逐项 aligned；**不预设**等号）

```
Σ_e p_e·e_e  ≤  Σ_e |p_e||e_e|  ≤  Σ_e |p_e|·V  =  V·Σ_e|p_e|
```

两处 gap 都**非负** ✓（Cauchy–Schwarz；`|e_e| ≤ V` ✓）。对 optimal 对，等式链首尾相等（归一化 `Σ|p_e| = 1` ✓，
或 `≤1` 版取 `≤V` ✓）⟹ **总 gap = 0** ⟹ 每个 gap 都为零 ⟹
(i) 每条边 `p_e = 0` 或 **`p_e` 与 `e_e` 同向（aligned）** ✓；(ii) 每条 `p_e ≠ 0` 的边 `|e_e| = V` ✓。**（aligned 是推出来的 ✓。）**

## §2 **等式的链**（任意 optimal dual 与任意 projected primal 都 aligned）

取任意 optimal dual `α` 与任意 optimal primal `X`（可先投影 `X_v ↦ Π_{conv(U)}X_v`，见 §3 前置引理；投影不增边长 ⟹ 仍最优 ✓）。
由 `Σ|α_e| = Σα_e = 1`、`α_e ≥ 0`、`|e_e| ≤ V` ✓：

```
V  =  Σ_i ⟨l_i, U_i⟩                      （力平衡 ⟹ 边项在自由节点全消；目标恒等式）     (E1)
   =  Σ_e α_e ⟨u_e , e_e⟩                  （u_e 定义 ✓）                                   (E2)
   =  Σ_e α_e |e_e|                        （aligned: ⟨u_e,e_e⟩ = |e_e| ✓）                 (E3)
   ≤  Σ_e α_e V                            （每个 |e_e| ≤ V ✓ 且 α_e ≥ 0 ✓）                (E4)
   =  V·Σ_e α_e = V                        （归一化 ✓）                                      (E5)
```

首尾相等 ⟹ (E4) 的每一项都取等 ⟹ **互补松弛**：`α_e > 0 ⟹ |e_e| = V` ✓（且松弛项贡献 0 ✓）。
**要点**：这不是"引一个标量 Lagrange 符号"，而是 (E1)–(E5) 的**等式链**对**任意** optimal 对成立 ✓——
故 aligned（`α ≥ 0` 且严格边紧）是**推出来的**，不是额外假设 ✓。

## §3 严格正性：`⟨l_i, U_i⟩ > 0 ⟺ l_i ≠ 0`（不引用 `|c| < 1` ✗，也不需 `|X| < 1`）

**(P) 投影前置引理**（同 `GLOBAL-ANGULAR-KKT-REDUCTION.md` §3(a)）：`C := conv(U_i)`，把每个自由节点换成 `Π_C(X_v)` ✓；
投影 1-Lipschitz ⟹ 任意两节点距离不增 ✓；锚已在 `C` 内 ⟹ 位置不变 ✓ ⟹ 所有边长不增 ⟹ `max_e|e_e| ≤ V` ✓
而 `V` 最小 ⟹ `= V` ✓ ⟹ **存在最优 primal 使其全部自由节点落在 `C ⊂ B̄(0,1)`** ✓。

**引理 A**：设 `V > 0`、anchors 在单位圆上、`X` 为上述 projected optimal primal、`α` 为任意 optimal dual。则对每个 anchor `i`：
```
⟨l_i, U_i⟩ > 0   ⟺   l_i ≠ 0          （即"存在入射边 α_e > 0" ⟺ "载荷非零"）
```
*证明*：`⟨l_i,U_i⟩ = Σ_{e∋i} α_e ⟨u_e, U_i⟩`，其中入射边连 `U_i` 与自由端 `X_e` ✓，且 `u_e = (U_i − X_e)/|U_i − X_e|` ✓ ⟹
`⟨u_e, U_i⟩ = (1 − ⟨X_e, U_i⟩)/|U_i − X_e|` ✓。
* 若 `α_e > 0`：由 §2 互补松弛得 `|U_i − X_e| = V > 0` ⟹ **两端点不同** ⟹ `X_e ≠ U_i` ✓；
  又 `X_e ∈ C ⊂ B̄(0,1)`、`|U_i| = 1` ✓ ⟹ `⟨X_e,U_i⟩ ≤ |X_e| ≤ 1` ✓，而**等号 ⟺ `X_e = U_i`**（Cauchy–Schwarz 取等 ✓）
  ⟹ 严格 `⟨X_e,U_i⟩ < 1` ✓ ⟹ `⟨u_e,U_i⟩ = (1 − ⟨X_e,U_i⟩)/V > 0` ✓。（**不需** `|X_e| < 1` ✓；lead 的简化正确 ✓。）
* 故每项 `α_e⟨u_e,U_i⟩ ≥ 0` ✓ 且 `α_e > 0` 的项 `> 0` ✓ ⟹ `l_i ≠ 0 ⟺ ∃e∋i: α_e > 0 ⟹ ⟨l_i,U_i⟩ > 0` ✓；
  反向：`⟨l_i,U_i⟩ > 0` ⟹ 某 `α_e > 0` ⟹ `l_i ≠ 0` ✓。∎
**zero-load 特殊情形**：`l_i = 0`（例如该锚全部入射 `α_e = 0`）⟹ `⟨l_i,U_i⟩ = 0` ✓（**弱**为零，不是正 ✓）；
下文 §4 的凹性对该锚退化（`|l_i| = 0` ⟹ 该锚对 `f` 无贡献 ✓）。

## §4 固定 optimal field 在 anchor 附近的**凹性**与显式半径

**设定**：固定 §2–§3 得到的 optimal field `{α_e, l_i}` ✓（这是 lead 说的 "固定该 optimal field" ✓——只用于局部，
**不**声称它对所有锚位都有效 ✗）。把锚 `i` 沿单位圆移动角 `h_i`：`U_i(h) := R_{h_i}U_i` ✓，其余不动 ✓。

**(C1) 纯凹性（代数部分，两行）**：固定场的泛函
`f(h) := Σ_i ⟨l_i, U_i(h_i)⟩ = Σ_i |l_i| cos(h_i − ψ_i)` ✓（`ψ_i` = `l_i` 与 `U_i` 的夹角 ✓）——
每个余弦在 `|h_i − ψ_i| ≤ π/2` 上**凹** ✓。在**内点角向极小**处（`GLOBAL-ANGULAR-KKT-REDUCTION.md` §0.1 ✓）
可取**径向代表** `l_i ∥ U_i` ⟹ `ψ_i = 0` ✓ ⟹ `f_i(h_i) = |l_i|cos h_i` ✓ **在 `|h_i| ≤ π/2` 上凹**（`<` 内严格 ✓）。

**(C2) 显式半径（**正确版本**；v1 的自由节点松量/敏感度与 `atan` 依据**整段作废** ✗）**：
固定场 `{p_e, ℓ_i}` ✓（它**对全锚位都 dual feasible** ✓——所以无需任何"重新对齐/残量控制" ✗）。令
```
a_i := ⟨ℓ_i, U_i*⟩ > 0        （径向分量；引理 A ⟹ ℓ_i ≠ 0 时严格正 ✓）
d_i := ⟨ℓ_i, JU_i*⟩           （切向分量；内点角向极小处取径向代表时 d_i = 0 ✓）
⟨ℓ_i, U_i(h)⟩ = a_i cos h + d_i sin h = √(a_i²+d_i²)·cos(h − φ_i),   φ_i := atan2(d_i, a_i)
```
* **work 非负**：`a_i cos h + d_i sin h ≥ a_i cos h − |d_i| sin|h| ≥ 0` ✓ 当 `|h| ≤ atan(a_i/|d_i|)` ✓
  （此时 `|d_i| sin|h| ≤ a_i cos h` ✓）。
* **凹性**：`a_i cos h + d_i sin h` 是余弦曲线 ✓，在 `|h − φ_i| ≤ π/2` 上凹 ✓；而
  `atan(a_i/|d_i|) = π/2 − |φ_i|` ⟹ `|h − φ_i| ≤ π/2` ✓ ⟹ **该 box 内既非负又凹** ✓✓。
* ⟹ 固定场在逐锚角盒 `|h_i| ≤ atan(a_i/|d_i|)` 内：`Σ_i⟨ℓ_i,U_i(h)⟩ ≥ 0` ✓ 且逐项凹 ⟹ 总和凹 ✓。
* **零载荷特殊**：`ℓ_i = 0 ⟹ a_i = d_i = 0` ✓（该锚对 work 无贡献，半径规则单独处理 ✓）；`d_i = 0` 时半径 = `π/2` ✓。

**(C3) 口径**：需 `V > 0` ✓；§3 的严格性在整个 box 保持（`⟨X_e,U_i⟩ = 1` 不可能 ✓）。
