## 1. 口径（先写清，再给结论）

**域与量词**

```
D_legal = {42 角 : 13 线性等式 = 0，8 非线性等式 = 0（2 正弦环 + 6 圆比），正性 > 0}
S       = D_legal ∩ {R_shape < 0.38}          ← C837/POSITIVE-METRIC-INFIMUM 的主域
本测试域 = D_legal ∩ {R_shape ≤ 0.38}          ← 比 S 宽一个闭边界（对人类指令的严格照做）
Φ_λ(a)  = Σ_f λ_f (log γ_f + log R_shape) = log R_shape − spread,  spread ≥ 0
```

**为什么主域是 `R < 0.38`（不是整个 D_legal）**：C837 已证 `r_D(11) = inf_S R`
（C835 把每个正性构型变成真实覆盖；反向每个 `r<.38` 覆盖给出 S 中的点）。要证
`r_D(11) ≥ Tcert`，只需在 S 上 `R ≥ Tcert`；`R ≥ 0.38 > Tcert` 的点自动满足。

**目标命题（第二阶段）**：`Φ_KKT(a) ≥ log Tcert` 对 `a ∈ 本测试域` 是否成立。
它是 lead 计划的充分条件：`Φ_λ ≤ log R_shape` 恒成立，故 `Φ_λ ≥ log Tcert ⇒ R ≥ Tcert`。

**预算内必须记住的紧性**：候选处 `Φ_KKT(a0) = log R_shape(a0)`（18/20 半径饱和，spread=0），
而候选精确对象 `C529 = 0.37998385311983870905…`，`Tcert = 0.37998385311983868972…`，
二者只差 `1.93e-17`。所以该充分不等式**在候选处紧到 1.9e-17**；任何数值判定必须写明数值分辨率。
浮点模型在候选处的读数 `0.37998385311983757` 比 Tcert **低 1.12e-15**（≈20 ulp），
因此"Φ 是否低于 log Tcert"在 1e-15 量级不可分辨；本报告用 1e-9 作为"决定性"门限。

### 2.2 附带诊断：候选处 21 维**可行切空间** reduced Hessian（不是 lead 的 off-manifold 实验）

> **⚠ 本节读数已被第三阶段取代（2026-09-25，lead 读码确认）**：这里算的 `H_red = Zᵀ H Z` 只是
> Φ_KKT 的裸 Hessian 投影，**漏掉等式二阶 normal correction `Σ_j μ_j ∇²c_j`**，
> 因此"min = −4.8197、10 个负特征值"**不能**用来支持"候选非局部极小"（"4 组步长一致"也只是
> 同一对象的数值鲁棒性，不是独立证据）。正确对象与独立验证见 `PHASE3-LAMBDA-HESSIAN.md`：
> `H_red = Zᵀ(H_Φ + Σ_j μ8_j H_{c8_j})Z` 的 min = **−0.3354**（7 个负特征值，max +0.0895），
> 且 `½vᵀH_Lv = −0.1677217` 与显式重投影减半梯 `ΔΦ/t² = −0.1677263` 一致到 2.8e-5。
> 结论"候选不是 Φ_KKT 在可行流形上的局部极小"在**修正后的对象上仍是 numeric 结论**（min = −0.3354，
> 且由显式重投影梯独立验证）；但注意三点 caliber：(i) 该数值矩阵是在固定 λ 的精化点上算的，而该点
> **丢失了 18 条 ties**（g-spread 8.2e-8，见 `PHASE3C-DIM-RESOLUTION.md` §1），不能当作 sharp 候选；
> (ii) σ₁₈ = 6e-11 ≠ 0 只是浮点读数，不是精确 rank 结论；(iii) 因此只能作**路线优先级**判断，
> 不作方法级数学判死。

## 3. 独立核验（`phase2_refine_and_verify.py`，两条算术路径）

\* 候选的精确对象 `C529` 满足 `C529 − Tcert = +1.93e-17 > 0`；上表的负号来自**保存角度向量的
float64 存储**（模型读数比 Tcert 低 1.12e-15）。这是模型分辨率，**不是**覆盖反例。

**结论（区分两类）**

- **numeric counterexample（成立）**：保存的数值 KKT λ 的应力不等式 `Φ_λ ≥ log Tcert`
  在 `{R ≤ 0.38}` 上为假 —— 域内最弱 −1.31e-9（P1b，严格在 `R<0.38` 内 2.97e-8），
  边界 −1.80e-9（P1）；在完整形式域 D_legal 上为假 −1.36e-4（P2）。
  两条独立算术路径一致到 ~1e-16，故不是单点数值假象。
- **不是 exact disproof**：λ 本身是浮点 KKT 乘子（驻点误差 3.06e-10），模型为 float64
  （A2 换了算术但共享同一组公式/incidence）；没有区间/精确认证。
- **没有覆盖级反例**：12 起点 + 局部下降中**未发现任何 `R < Tcert` 的合法点**；
  因此 C249/C529/C825 与"候选即最优"的猜想均未被触及。

### 3.1 边界细化（同一见证的后续，不新增 start）

把 P1 投到 `{c₈ = 0, R = 0.38}` 边界上再做投影梯度下降（每步 6 次 Newton 重投影，
要求 `res<1e-11`、`|R−0.38|<1e-12`）：

| 阶段 | R | spread | Φ−log Tcert |
|---|---|---|---|
| 起点 P1 | 0.38 | 4.24945e-5 | −1.802e-9 |
| SLSQP（R=0.38 作等式） | 0.3800000018698 | 4.25017e-5 | −4.071e-9 |
| 重投影下降（125 步，收敛/停滞） | 0.3800000000001 | **4.24960e-5** | **−3.308e-9** |

在 `R=0.38` 边界上，spread 可达 **4.24960e-5**，而该处预算
`log(0.38/Tcert) = 4.2492693e-5`：越界量 ≈ `3.3e-9`。下降在 125 步后停滞在
1e-13 量级改动（残差 9.5e-15、余量 0.174），即这条路径的边界极小值 ≈ −3.3e-9。
（注意：这是**一条路径的局部**读数；`R=0.38` 边界上 spread 的全局上界未被本测试解决，
不得外推为"边界最大 spread ≈ 预算"。）

## 4. stress 域与 cover 域的关系（本轮必须写明的接口）

```
cover 域（几何）：        D 的 11 等盘覆盖（r<.38，9 环+2 hub，C450/C451/C464/C818/C819/C824/C825）
         ↕  C835 / C837（双向、已证）
stress 域（形式）：       S = D_legal ∩ {R < 0.38}（42 角 + 21 等式 + 正性）
                         r_D(11) = inf_S R
```

1. **两域在 infimum 层等价**（C837），所以"形式域上的反例"若能验到 `R < Tcert`，
   就是**覆盖级**的反例（会把认证上界改进到 < Tcert，即候选不是最优）。本测试没有找到。
2. **`Φ_λ ≥ log Tcert` 比目标更严格**：`Φ_λ ≤ log R` 恒成立，所以
   - 在 `R < Tcert` 的点上（若存在）该不等式**自动为假**；
   - 反之，在任何域上证明它 ⇒ `R ≥ Tcert` ⇒ 目标。
   因此它不是"松开目标"，而是把目标**升级**成"半径亏损不能超过 `log(R/Tcert)`"的
   预算型命题；亏空与预算都在候选处为 0，谁在域边界胜出是真正的困难。
   **逐点最优的 λ**（把权重全放在取到 max 的因子上）给出 spread=0，但取到 max 的因子集合
   随点变化；固定 λ 的困难正是"赤字预算的全局分配"。~~保存的 KKT λ 只差 ~1e-9，所以换 λ 仍是有意义的
   下一步~~ —— **此句已被第三阶段推翻**：sharp 驻点 λ **唯一**（近零空间 1 维、与保存 λ 差 1.5e-10），
   所以不存在"另一组 λ"可换；固定-λ 族是单点集且已被证明局部不可能（`PHASE3-LAMBDA-HESSIAN.md`）。
3. **域外反例（P2，R≈0.3976）无害但杀死原始口径**：lead 计划写的是"在 legal angular domain 上"，
   即整个 D_legal；P2 表明该口径下 Λ_λ 通道不成立。若把口径收窄到 S（或 {R≤0.38}），
   P2 不构成障碍，但 P1/P1b 仍然落在域内，故**收窄口径后该 λ 通道仍被数值证伪**（幅度 1e-9）。
4. **数值 1e-9 的意义**：它远大于模型/λ 的噪声（~1e-15…1e-10），不是舍入；但它发生在
   `R > Tcert` 的边界层（`R ∈ [0.38−3e-8, 0.38]`），对下界无直接威胁 ——
   只有当某条路径能把反例推到 `R < Tcert` 时，才会伤到目标。本测试没有。
5. **与第一阶段 M1 的关系**：M1（cap 通道）的 20 个见证全部 `R∈[0.3885,0.3907]`，
   **同样在主域之外**；见 `REPORT.md` 置顶更正。两个通道在"域外大量失败、域内只剩 1e-9 级失败"
   这一点上表现一致，提示困难集中在 `R=0.38` 边界层附近的结构，而不是流形内部。

## 5. 剩余义务（可直接执行的下一最小步骤）

1. ~~**换 λ（首选）**~~ —— **已降级（第三阶段，numeric）**：sharp 驻点 λ **数值上唯一**
   （`PHASE3-LAMBDA-HESSIAN.md` §2；σ₁₈ = 6e-11 ≠ 0 只是浮点读数，精确性未决），且修正后的
   reduced Hessian min = −0.3354 ⇒ 固定-λ sharp log-stress 在候选邻域内不可行，按**路线优先级**
   （numeric route deprioritization）处理，**不是**方法级数学判死；且固定 λ 的精化点丢失 18 ties
   （见 `PHASE3C-DIM-RESOLUTION.md` §1），sharp 版论证若要继续必须先解 18 ties + 8 eq + stationarity。
   仍然开放的只有**非 sharp** 修饰（例如领口的残差增强泛函 `F = S_t + μ·C + ρ‖C‖²`，
   `ROUND8-AUDIT-AND-STRESS.md`）——但任何非 sharp 的 λ 在候选处 `Φ_λ < log Tcert`，**必须先**给出
   别的不等式结构，不能再指望"sharp + 换权重"。
2. **域边界层分析（结构性）**：第三阶段已给出机制——候选处的负曲率方向一阶 R-速率 +0.813，
   离开 `{R≤0.38}` 于 t≈2e-5；零速率子空间 V0（dim 3，是 lead 旧 dim 4 tie-切空间的超平面，
   见 `PHASE3C`）上 Hessian 全正。若要把域内失败做成定理，
   需要 `R∈[0.38−ε,0.38]` 薄层上 spread 与 `log(R/Tcert)` 的显式比较。
3. **M1 限制版（未做，独立义务）**：把第一阶段的 M1 命题限制到 S 上重测
   （`min_{S} max_i D_i ≥ Tcert`）。第一阶段 20 个见证全部域外，故该命题既未证伪也未经检验；
   注意 §2.2 的 T1 只说明损失机制，不排除限制版成立。
4. **不要再做**的事：重复 lead 的线性乘子 off-manifold 负曲率实验；把本测试的 1e-9 级读数
   当作"全局最小值"；把候选的 float64 读数当作 `R < Tcert` 的证据。
