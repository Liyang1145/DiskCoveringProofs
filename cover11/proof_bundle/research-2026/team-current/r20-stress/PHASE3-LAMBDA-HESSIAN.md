## 1. 口径（本轮全部量词）

```
a0        : 保存候选的 42 角向量（lead 模型 x0[:42]）; |c(a0)|∞ = 7.5e-15
y ∈ R^29  : 13 条线性角等式的精确零空间坐标（a = a0 + Nr y）
M         : 可行流形 {y : c8(y) = 0}（8 条非线性等式：2 正弦环 + 6 圆比），dim 21
b_f       : 20 个半径分支 log γ_f + log(q0/ell0)（光滑，无 max）；Φ_λ = Σ λ_f b_f
A         : 18 个候选活跃分支（2 个 site-face 5,7 松弛 u≈0.9969665）
sharp     : supp(λ) ⊆ A（否则 Φ_λ(a0) < log R(a0) = log Tcert，不等式在候选处即失败）
Tcert     = 0.37998385311983868972…（C249 上界对象）;  R(a0) = C529 = 0.37998385311983870905…
```

**二阶对象（正确形式）**：对任意可行曲线 y(t) ⊂ M, ẏ(0) = v ∈ ker J8，
由 ∇L = 0（L = Φ_λ + μ8·c8，驻点）得

```
d²/dt² Φ_λ|_0 = vᵀ [ H_Φ + Σ_j μ8_j H_{c8_j} ] v  =  vᵀ H_L v        （无额外线性化余项）
```

即 H_red(λ) = Zᵀ H_L Z，Z = ker J8（29×21）。`Σ_j μ8_j H_{c8_j}` 就是 lead 指出的 normal correction。

## 2. λ 唯一性（线性方程，50 位 Jacobian）

**方法**：驻点条件 `Σ λ_f ∇b_f ∈ span{∇c}` ⇔ `(I − P_row) W_Aᵀ λ = 0` ⇔ `M λ = 0`，M = P_tangent·W_Aᵀ（29×18）。
M 与 Jacobian 都用 50 位 mpmath 中心差分（h=1e-20）在**候选点**计算；`mp_model_r20.py` 的
mpmath 实现已对 lead float64 模型逐分量校验（b 差 ≤7.4e-16，c8 差 ≤3.2e-15）。

| 检查 | 读数 |
|---|---|
| sv(J8)（8 条非线性等式） | `[41.59, 22.84, 7.20, 4.54, 3.35, 1.72, 1.40, **0.843**]` → 秩 8，无冗余 |
| sv(13 条线性等式) | σmin = 1.160 → 秩 13，无冗余 |
| sv(M)（18 列，29×18） | σ_17 = **4.642406e-2**，σ_18 = **1.6143e-9**（比值 3.5e-8）→ 近零空间**1 维** |
| ‖M λ_saved‖（50 位） | 3.129e-9（lead 自报驻点残差 3.06e-10，其 float64 Jacobian 误差 ~3e-9） |
| 单纯形上最小 ‖Mλ‖ | 3.81e-9（SLSQP，两个起点；λ_saved 本身已是最优级） |

**点精度诊断（lead 要求"确认 x 是候选精确近似"）**：固定 λ（不重优化），用 Gauss-Newton 在流形上
把点移动到驻点：

| 量 | 值 |
|---|---|
| 起点缺陷 ‖M(a0)λ_saved‖（50 位） | 3.129e-9 |
| 移动量 ‖Δy‖ | **2.103e-7**（float64 迭代，受 float64 Jacobian 噪声限，trace 停在 ~7e-11） |
| 精化点缺陷（50 位重算） | **4.78e-11** |
| 精化点 R / Φ / max\|res21\| / 正性余量 | 0.37998388011164197 / −0.96762651895440455 / 2.8e-15 / 0.1742 |
| 精化点 sv(M) | σ_17 = 4.642e-2，σ_18 = **6.263e-11**，零空间维数 **1** |
| 零向量归一 λ_r（Σ=1） | min = 9.894693e-3 > 0，max = 1.270147e-1，sum = 1.000000000000000 |
| **‖λ_r − λ_saved‖∞** | **1.54e-10** |

**结论**：sharp 驻点 λ **唯一**（近零空间 1 维、正向量、Σ=1 定标），且就是 lead 保存的 KKT λ
（到 1.5e-10）。无规范/冗余自由度可商掉：J8 满行秩（σmin 0.843）、13 条线性满秩（σmin 1.16）、
μ8 由 λ 唯一确定（8×8 系统良态）。支持集也不能缩小：M 的零空间只有 λ_r 一个方向且其 18 个分量全正。

## 5. 主域相容性（lead 的 cusp 提醒的直接检验）

R = exp(max_f b_f) 在 18 个分支并列处是**尖点**；主域约束是 R ≤ 0.38 而 R* = Tcert < 0.38。
对方向 v 的一阶 R-速率 = `max_{f∈A} ∇b_f·v`：

- 修正负方向：R-rate = **+0.8133**（顶点直出）⇒ 离开 {R ≤ 0.38} 于 **t_exit ≈ 1.98e-5**（在 t=1.56e-4 时 R 已 0.38003）。
- 域相容子空间 `V0 = {v ∈ ker J8 : ∇b_f·v = 0 ∀ f∈A}`：dim = **3**（因 Σλ∇b_f ∈ N，全不增 ⇒ 全为 0），
  V0 上 R-rate ≤ 1.2e-15；**H_red 限制在 V0 上全正**：`[+0.0443247, +0.0564136, +0.0588168]`。

**读法**：候选处的**全部负曲率方向都指向主域外**（一阶 R 增）；域内可行的一阶方向曲率为正。
所以固定-λ log-stress 的局部失败是"流形上"的，而在 {R ≤ 0.38} 内局部只留极薄一层
（沿 v 的 t_exit ≈ 2e-5 → 二阶估计 ΔΦ ≈ −7e-11），这与第二阶段域内反例只有 1e-9 量级自洽
（第二阶段的 P1b 是有限距离点的现象，不是候选邻域的）。
**关于 dim 3 与 lead 旧 dim 4 的关系（已修正）**：两者不是"同量级旁证"而是**同一对象的两个版本** ——
`ker[J8; Jg−∇Φ_λ]`（居中/差分，lead 的形式，**dim 4**，K2 最小 σ = 5.0e-2 稳健）与
`ker[J8; Jg]`（裸/V0，**dim 3**，最小 σ = 8.2e-10 = λ 驻点缺陷）相差一个"18 并列共同移动"方向；
上表 V0 的 3 个特征值正是 lead 旧 4D 谱 `[.0413,.0499,.0568,.0590]` 的 Cauchy 交错子集。
根因、raw SVD、g-spread、谱对账与分级见 **`PHASE3C-DIM-RESOLUTION.md`**（我方第二轮的措辞错误已在此更正）。

## 6. 结论（对 lead 三阶段问题的回答；**等级：numeric**）

1. **λ 唯一（numeric）**：近零空间 1 维（σ₁₇ = 4.64e-2 vs σ₁₈ = 6.26e-11 @ 精化点）、归一零向量全正、
   Σ=1，与保存 λ 差 1.5e-10；无规范/冗余可商。**σ₁₈ ≠ 0 是浮点读数，不是精确 rank 结论**：
   它随点精化从 1.6e-9 降到 6.3e-11，是否精确为 0（即精确候选处是否存在精确 sharp 驻点 λ）
   **未决**，仅能按数值倾向描述。
2. **修正后的 reduced Hessian 确负（numeric）**：min = −0.3354，7 个负特征值；由显式方向 +
   重投影减半梯验证到 2.8e-5 相对（不是步长对照）。
3. **由此得到的只是"路线优先级"结论，不是方法级数学判死**：若精确候选处存在 sharp 驻点 λ，
   唯一性与负曲率表明该 λ 在候选邻域内不能给出 `Φ_λ ≥ log Tcert`；若不存在，
   则该族本身为空。两种情形都**未被证明**（点只到 2e-7/缺陷 4.8e-11 的浮点精度，且 ties 在精化中丢失），
   所以正确的表述是：**固定-λ sharp log-stress 路线在候选邻域内不可行（numeric route deprioritization），
   待精确性判定；不作为定理或全局否证。**
4. **ties 状态（raw）**：原候选 a0 处 18/18 并列（g-spread 6.7e-16）；固定 λ 精化点
   g-spread 8.2e-8、仅 1/18 保持 ⇒ **该精化点不能当 sharp 候选**（sharp KKT 求解应 18 ties + 8 eq +
   stationarity 一起做；本期未做）。
5. 作用域：以上均针对流形 M；在**主域 {R ≤ 0.38}** 内负方向被 R-边界截断（t_exit ≈ 2e-5），
   域内只有 1e-9 级现象（第二阶段显式点）。
