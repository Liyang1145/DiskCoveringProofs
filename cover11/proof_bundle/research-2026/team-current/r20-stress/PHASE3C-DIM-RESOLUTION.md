> 本文件只解决 lead 指定的 **dim discrepancy 与 ties 检查**；不含优化、不含区间化、不下证明结论。
> 数据：`out/phase3c_dim_resolution.json`（SVD/g-spread）、`out/phase3c_spectra_reconciliation.json`（谱对账）。
> 脚本：`phase3c_dim_resolution.py`、`phase3c_spectra_reconciliation.py`。

## 0. 一句话根因

**不是矛盾，是两个不同的子空间 + 一个精确的代数依赖，且差异恰好由 λ 的驻点缺陷决定：**

| 对象 | 定义 | dim（a0） | dim（refined 点） | 性质 |
|---|---|---|---|---|
| **K1** = `[J8 ; Jg − gbar]`（lead 的形式，`nonlinear_stress_probe.py` L13–15） | `gbar = λᵀJg = ∇Φ_λ` | **4** | **4** | 18 个居中行有**精确**依赖 `Σλ_f(∇b_f−∇Φ_λ) ≡ 0` ⇒ rank ≤ 17+8 = 25 ⇒ 零空间 **≥ 4（严格）**；数值上恰为 4（其余 σ ≥ 4.6e-2，**无阈值敏感性**） |
| **K2** = `[J8 ; ∇b_{f_i} − ∇b_{f_1}]`（lead 的"differences"字面形式，25 行） | 参考分支差分 | **4** | **4** | 与 K1 行空间相同；最小 σ = **5.0e-2**（健康），零空间 = 4 ⇒ **dim 4 是稳健的数值事实** |
| **K3** = `[J8 ; Jg]`（我第二轮用的 V0 形式） | 18 个裸梯度 | **3**（tight 阈值）/ 4（rcond 1e-7） | 3 / 4 | 无精确依赖；最小 σ = **8.17e-10（a0）/ 1.51e-11（refined）**，即 **λ 的驻点缺陷本身** |
| 我的 `M = P_tangent·W_Aᵀ`（第三阶段唯一性矩阵） | 29×18 | σ₁₈ = 1.61e-9（a0）/ 6.26e-11（refined） | — | 与 K3 的同一个量（切向投影） |

**关系**：`ker K1 = ker K3 ⊕ R·d`，其中 `d` 是"18 个并列分支以共同速率移动"的方向；共同速率
`c(v) = ∇Φ_λ·v`。在 a0 上实测该方向的 R-速率 = **3.8e-10**（K3 的 3 个方向则是 ~1e-15）。
若精确候选处存在**精确** sharp 驻点 λ（`∇Φ_λ ∈ span(J8行)`），则 `c ≡ 0`、`K1 = K3`、两者**都是 4**；
现在 `c ≠ 0` 只在 1e-10 量级，故"4 vs 3"是**阈值/定义**问题，而不是哪一方算错。

## 2. 谱对账（4 个特征值 vs 我此前的 3 个，同一 a0、同一 H_L）

lead 早期 `nonlinear_stress_probe.py` 的 4D common-kernel 谱 = `[.0413, .0499, .0568, .0590]`。
用**同一 λ、同一 H_L = H_Φ + Σμ8_jH_{c8_j}** 在 a0 重算：

| 子空间 | 特征值 | 对照 |
|---|---|---|
| `ker K1`（居中/差分，dim 4） | **`[0.041318, 0.049897, 0.056839, 0.059048]`** | 与 lead 旧值四位一致 ⇒ **其诊断被精确复现** |
| `ker K3`（裸/V0，dim 3） | `[0.049897, 0.056388, 0.056870]` | 与 K1 谱满足 Cauchy 交错（0.0413 ≤ 0.0499 ≤ 0.0499；0.0499 ≤ 0.0564 ≤ 0.0568；0.0568 ≤ 0.0569 ≤ 0.0590）⇒ 一致 |

所以"dim 3 vs dim 4"与"3 个 vs 4 个特征值"是**同一件事的两面**：多出来的那个方向正是
"保持 18 个并列、共同速率 ≈ 1e-10"的方向（其 H_L 曲率 = 0.0413）。我第二轮把它当成"同量级旁证"
是**措辞错误**，正确说法是"同一个对象少一个维度（且差异由驻点缺陷决定）"。

## 3. 对称性检查

候选确实带一个镜像对称：站点 `i ↦ (4−i) mod 9`（诱导边标号 `i ↦ (3−i) mod 9`）。
实测（保存角向量）：switch 半角在该反转下 `maxdiff = 4.9e-9`（refined 点 2.6e-8）——
即**保存的点只在 ~5e-9 水平上对称**（lead 的数值解没有显式强制对称）。
对称性**没有**引入额外秩亏：K2 的最小奇异值 5.0e-2，零空间恰好 4 = 代数下界
`29 − (8+17)`，无第五维。故 dim 4 的**唯一**来源是 §0 的那条 λ-依赖。

## 4. 数值 vs 严谨（分级）

**严谨（可写进证明，不依赖浮点）**：
1. `Σ_f λ_f (∇b_f − ∇Φ_λ) ≡ 0`（定义式恒等）⇒ K1/K2 的 18 个居中/差分行秩 ≤ 17；
2. 若 rank J8 = 8 且两行空间交为 {0}，则 `dim ker K1 ≥ 4`；`dim ker K1 ≤ 4` 需要 `rank = 25`（数值）。

**数值（当前 float64 点的事实，非定理）**：
3. `dim ker K1 = 4`、`dim ker K3 = 3`、K2 最小 σ = 5.0e-2（秩/零空间判定稳健）；
4. K3 最小 σ = 8.2e-10（a0）/1.5e-11（refined）**等于** λ 的驻点缺陷 ⇒ 用 1e-7 阈值会把
   K3 也读成 4；`σ₁₈ = 6e-11 ≠ 0` **不是**精确 rank 结论；
5. a0 的 g-spread 6.7e-16、18/18 ties ✓；refined 点 g-spread 8.2e-8、1/18 ties ✗；
6. 保存点的镜像对称只到 ~5e-9。

**因此**：dim 4（lead 的对象）是**正确且稳健**的；dim 3（我的 V0）是**另一个**对象（零速率超平面）。
两者相等当且仅当精确候选处 λ 精确驻点——这是一个**未决的精确性问题**，float64 数据只能给出
"缺陷 ~1e-10 且随点精化而下降"的数值倾向，**不能**据此宣称任一情形成立。任何"路线判死"只能按
**路由优先级（numeric route prioritization）** 表述，不是方法级数学否定。
