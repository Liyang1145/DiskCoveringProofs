## §3 `s < 1` 是否"真必要"：**不是独立前提，而是 R-平稳恒等式的推论**

用户提出的结构在这里被区间核对通过：

1. 物理约束取 `γ_f − R ≤ 0`（face）与边界分支 `B_j = t_j(c) − R ≤ 0`（gap，`t_j` 只依赖圆心）。
   lead 的 lift 定理给出**精确** `e_R + Σμ_i∇F_i + Σν_j∇g_j = 0`（根方程 + 图正则性 + reflection 平均）。
2. 两条正因子转换：`∇F_i = c_i(∇γ_i − e_R)`（`c_i = 4y²/F_out > 0`，本文区间认证）；
   `∇g_j = μ_j ∇B_j`（`μ_j := a_{R,j} + a_{R,j+1} > 0`，lead L5 / r20-rigidity W11 独立复核）。
3. `γ_i`、`t_j` 都**只依赖圆心**⇒ 它们的 **R 分量 = 0**。取第 12 个（R）分量：

```
1 − Σ_i μ_i c_i − Σ_j ν_j (a_{R,j} + a_{R,j+1}) = 0
⟺   s + Σ_j ν_j (a_{R,j} + a_{R,j+1}) = 1                （总权重 = 1，精确）
⟹   s < 1  ⟺  Σ_j ν_j (a_{R,j} + a_{R,j+1}) > 0
```

所以 `s < 1` **不需要**任何独立读数：它由 `ν_j > 0` 与 `a_{R,j} > 0` 立即得到。本文的区间读数是
`1 − s ∈ [0.55502141924, 0.55502171943] > 0`，边界总权重 `∈ [0.55501534621, 0.55502779247] > 0`，
两者与恒等式相容（相对闭合 1.1e-5，纯由区间宽度造成）。先前 `PHASE5 §3` 把 `1−s` 记作"9 个 switch
分支的总权重"，与此**不矛盾**：因为 `∇γ_sw ≡ e_R (mod rowspan{∇g_j})`（switch 腿在约束流形上 ≡ R），
故分支形式中 `e_R` 的系数就是 switch 权重，而它由 R-平稳恒等式**等于**边界乘子总量。
