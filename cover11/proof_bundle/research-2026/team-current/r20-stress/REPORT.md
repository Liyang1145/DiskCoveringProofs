## 2. 机制 M1（半径消除—亏损分解）：精确表述与推导

**动机（从候选等号反推）**：保存候选处 20 个局部半径中 **18 个**取到地板 `u_f = 1`（9 个 switch 全部饱和 + 9 个 site-face），只有 2 个 site-face（编号 5、7）松弛；于是"把 `u` 换成 cap 得到只含角的界"在候选处**无损**。M1 就是把这一想法做成全局不等式。

### 引理 1（弦的凸性 ⇒ 盒最大）
`ell(u,v,α) := sqrt(u²+v²−2uv cos α)`，`ell²` 是 `(u,v)` 的二次型，矩阵 `[[1,−cosα],[−cosα,1]]`，特征值 `2sin²(α/2)`, `2cos²(α/2)`；在 `α ∈ (0,π)` 上**正定**，故凸（`α→0,π` 退化端点仍凸）。对任意盒子 `[0,c]×[0,c']`：
```
Lambda(c,c',α) := max_{box} ell = max( c, c', ell(c,c',α) )
```
（凸函数在盒上的最大在顶点取到。数值盒抽样 4000 点 × 9 扇区：超出量 = 0，见 `out/witness_check.json:box_sampling_max_excess`。）

### 引理 2（两类合法 cap）
对任意 legal 形状：
```
(C0) u_f ≤ 1                            （地板）
(C1) u^{sw}_i ≤ Γ_i := min( 1, sin A_i / sin b_i )   （边界边正弦律 + site-face 半径 ≤ 1）
```

### 引理 3（亏损恒等式，精确）
```
R = q_i/ell_i = D_i + E_i ,     D_i := q_i / Lambda_i(合法 cap) ,
E_i = q_i ( 1/ell_i − 1/Lambda_i ) ≥ 0
```
其中 `E_i` = 第 `i` 扇区的**容量亏损**（cap 相对真实弦的放大造成的损失）。

### 2.2 定理 T1（cap 通道耗尽：要么平凡、要么有损）

**(a) 最小合法 cap = 真实半径。** 任一 `D_legal` 上的角量 cap 必须满足 `c_f ≥ u_f`（逐点），而 `u_f` 本身是角量的函数，故最小 cap 就是 `c_f = u_f`。把地板 `u ≤ 1` 沿 21 条精确比例关系做单调传播（路径最小、对数域 Bellman–Ford）得到的**最小不动点恰为** `u_f`：
> 沿从 `h` 到 `f` 的路径，比例之积 = `u_f/u_h`（精确），故 `c_f = min_h u_f/u_h = u_f / max_h u_h = u_f`。
数值验证（见证点）：传播口径 cap `ub` 与实际 `u` 的差 `≤ 1.5e-10`（= 该点 2 条 cycle 残差量级），即 `ub ≡ u`（见 `out/witness_check.json:ub_propagated`、`validity_controls.max_u_minus_ub`）。

**(b) 即使 cap 精确，盒最大仍有损。** 由引理 1：
```
D_i = q_i/max( u_{i−1}, u_i, ell_i )  ，  R = q_i/ell_i
D_i = R  ⟺  ell_i ≥ max(u_{i−1}, u_i)   （α_i ≥ π/2 时自动成立；α_i < π/2 时可能失败）
```
故 **cap 通道的值不可能超过** `q_i/max(u_{i−1},u_i) ≤ R`：它要么恒等（无信息），要么有损（`ell_i < max(u_{i−1},u_i)` 或 cap 松弛）。

**(c) 有损方向不可由同一数据控制。** 亏损 `E_i = R(1 − s_i)`，`s_i = ell_i/Λ_i`；等腰近似下 `E_i/D_i = 1/u_i − 1`，即亏损由相邻 switch 的**地板松弛**驱动，而松弛量在模型里除 `u ≤ 1` 外**没有任何不等式约束**。故 M1 的锐利性不可能靠"更好的 cap"修复（这正是 §3 见证的来源）。

## 4. 同一等号结构下的另一通道（评估，不新增反例优化）

恒等式（任意 `λ ∈ R^20_{≥0}, Σλ = 1`；`b_f := log γ_f + log R = log(u_f·R)`）：
```
log R = Phi_lambda + spread ,      Phi_lambda := Σ_f λ_f b_f  ,
spread := log(1/u_max) − Σ_f λ_f log u_f = Σ_f λ_f log(1/u_f) ≥ 0
```
于是 `log R ≥ Phi_lambda`，**充分不等式 Φ_λ ≥ log r***。这就是 lead 已登记的 stress 通道（本轮不新注册，只做量化耦合）。

| 权重 λ | 候选处 `Φ − log R` | 20 个见证上 `Φ − log Tcert` 最小值 | 违反数 |
|---|---|---|---|
| `U20`（20 因子均匀） | **−3.04e-4（候选处即失败）** | −1.22e-3 | 20/20 |
| `U18`（18 活跃因子均匀） | −4.4e-16（紧） | **−3.07e-5**（run00） | 1/20 |
| `U9`（9 个 switch 均匀） | −4.4e-16（紧） | −2.65e-3 | 20/20 |
| `KKT`（lead 数值乘子：支撑 = 18 活跃，min λ = 0.00989，驻点误差 3.1e-10） | **−1.1e-16（紧）** | **+1.024e-3**（cond00） | **0/20** |

**读法（关键）**：
- 候选处 `spread = 0`（18 重并列）⇒ 两个通道在候选处都紧。
- 但在 cap 通道失败的见证上：cap 通道**差 1.46e-3**（需要的量 `log(Tcert/max D)`），而 `KKT` 通道的 `spread ≈ 0.021–0.024`（干净点；收敛差的 run00 为 0.0265），即**富余约 15–18 倍**；`Φ_KKT − log Tcert ∈ [+1.02e-3, +1.21e-3] > 0`。
- 权重**不能随手取**：`U18` 在 run00 处差 3.1e-5、`U9/U20` 大面积失败 ⇒ 存活义务里 λ 必须真的被优化（lead 的数值 λ 只是候选，未认证）。

## 5. 精确剩余义务（第一阶段交付）

**(O1)［存活义务：加权锐利不等式］**
> 给出**显式有理数** `λ_f ≥ 0 (f=0..19), Σλ_f = 1`（候选：lead 数值 KKT 乘子的有理化，支撑 = 18 个活跃因子），并证明
> ```
> Φ_λ(a) := Σ_f λ_f ( log γ_f(a) + log R(a) )  ≥  log Tcert      ∀ a ∈ D_legal
> ```
> 其中 `γ_f(a)` 为根规范局部半径（由 21 条正弦律从角度唯一确定，无需任何 cap），`Tcert = 0.379983853119838689722261606136093214308718957`。

**接口（若 (O1) 成立则主目标闭合）**：对每个 legal 形状 `log R ≥ Φ_λ ≥ log Tcert`，即 `R ≥ Tcert`；由 C837（形式域 infimum 等式）与既有归约链 C450/C451/C464（9+2）、C809/C818/C819/C824（只剩 q0(6,7)）、C825（> 3/8）得 `r_D(11) ≥ Tcert`；与 C249（`Tcert` 是认证构型的上界）相夹 ⇒ **无条件全局最优**。

**证伪判据（下一轮可直接执行）**：显式 legal 形状 `a` 使 `Φ_λ(a) < log Tcert`。本轮 20 个 M1 见证上 `KKT` 权重均未违反（余量 +1.0e-3 上下），lead 早期 12 起点扫描（`nonlinear_stress_attack`）亦无负见证；但**全局**未证。

**(O2)［等价困难点表述，便于分工］**
> 证明：`{ a ∈ D_legal : max_i D_i(a) < Tcert } ⊆ { a : Φ_λ(a) ≥ log Tcert }`。
> 第一阶段数据：该"硬位点集"非空（20 个见证），且在其中有 `spread ≥ 15 × log(Tcert/max D)` 的量化富余；故 cap 通道的失败**不等于** stress 通道的失败，两通道由 `log R = max_i[log D_i] + min_i log(Λ_i/ell_i) = Φ_λ + spread` 精确耦合。

**必须写明的缺口/不成立范围**：
1. (O1) 的 `λ` 目前只有**浮点数值**（驻点误差 3.1e-10）；有理化与"该 λ 在 20 见证上都成立"未认证；`U18/U9/U20` 已被否 ⇒ λ 不能取 canonical 均匀值。
2. (O1) **不能靠全局凸性证明**：lead 的 `nonlinear_stress_convexity.py` 在距候选 0.15 处给出方向二阶导 −0.865（真负，非实现 bug）；本轮的 cap 通道失败与之一致——障碍是域的非凸结构（"全体半径同时缩水"方向），不是 logsumexp 光滑化的假象。
3. (O1) 在候选处**紧**，故任何证明必须锐利（不能靠松弛常数）。
4. 本轮 falsification 的见证是 `D_legal`(形式正性域) 的合法点，且满足 C840 可量化条件；但它们是否是**内向最近图覆盖**的极限未判定（需要重建平面实现检查最近性/Voronoi 结构）。这不影响 M1 的 falsification（M1 的推导只用地板约束），但影响"cap 通道在更窄内向域上是否也失败"的措辞——按 §2.2，即使在任意窄子域上该通道仍是"平凡或有损"。

## 7. 方法级负结果（建议 lead 复核后入 DEAD，本轮不注册）

> **"用候选 18 重等号把 20 个半径逐个换成角量 cap，从而把锐利下界化成纯角不等式"这条通道，在第一阶段被判为关闭**（不是"未找到"）：
> 1. 分析理由（定理 T1）：合法 cap 的最小值就是真实半径（路径传播恰为 `u`），故该通道的值不可能超过 `q_i/max(u_{i−1},u_i) ≤ R`，只在 `ell_i ≥ max(u_{i−1},u_i)` 时与 `R` 相等（此时**无信息**），否则**有损**；
> 2. 有损方向被 20 次明确反例优化击中：`max_i D_i` 最低到 `0.379430906080`，低于 `Tcert` 5.53e-4，且在所有扇区强制非平坦 2.86° 后仍低于 5.44e-4；
> 3. 失败根源是可度量的：亏损 = 相邻 switch 的地板松弛的一阶函数；候选的 9 个 switch 全饱和是非典型的（一般点 1/20 饱和）。
> 4. 不受影响：lead 的加权 stress 通道在同一 20 个见证上余量为正（+1.0e-3 上下），两通道由恒等式耦合；C825 下界、C249 上界、以及任何既有 claim 均不因本轮改变。
