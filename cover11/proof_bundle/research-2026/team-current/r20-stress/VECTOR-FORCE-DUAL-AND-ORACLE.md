## §1 对偶推导（弱对偶 → 力平衡 → 锚载荷下界）

记自由节点位置 `z`（合并写成一个元组），固定锚 `U = (U_1..U_9)`；边集 `E`，第 `e` 条边连接节点 `u_e, v_e`。

**Primal**：`min r` s.t. `|z_{u_e} − z_{v_e}| ≤ r`（`∀e ∈ E`；锚节点取固定值 `U_i`）。等价写法（消去 `r`）：
`min_{z} max_e |z_{u_e} − z_{v_e}| =: V(U)` ✓——注意 `V` 只依赖 `U`（自由节点已优化掉），这正是 lead 说的 **oracle value** ✓。

**Lagrange 对偶**：乘子 `y_e ≥ 0`，
`L = r + Σ_e y_e(|z_{u_e} − z_{v_e}| − r) = r(1 − Σ_e y_e) + Σ_e y_e |…|` ✓。

* **`r` 的系数**：要下界有限必须 `Σ_e y_e ≤ 1` ✓（= lead 的 "edge `y_e` norm sum ≤ 1"；这里的 `Σ y_e` 是标量和的 ≤1 ✓）。
* **自由节点极小**：对每个自由节点 `v`，`inf` 关于它的位置只出现在 `Σ_{e∋v} y_e |z_v − (另一端)|` 里 ✓——
  这是**加权 Fermat–Weber 泛函**，其极小点 `z_v^*` 满足
  **`0 ∈ Σ_{e∋v} y_e ∂|z_v − other_e|`**（子微分 Ø 条件 ✓）。
* **弱对偶**：`min r ≥ max_{y ≥ 0, Σy ≤ 1} [ inf_z Σ_e y_e|z_{u_e} − z_{v_e}| ]` ✓。

**把 inf 写成"向量力"形式（关键恒等式）**：对每个自由节点的每个 incident edge 取单位向量
`w_e := (other_e − z_v)/|other_e − z_v|`（当该端点是自由的时，`other` 是该边另一端；当另一端固定时就是 `U_i`）✓。
由 `|other − z| = sup_{|w| ≤ 1} ⟨w, other − z⟩` 得

```
inf_z Σ_e y_e |z_{u_e} − z_{v_e}|  =  max { Σ_e y_e ⟨w_e , U-dependent data⟩ : |w_e| ≤ 1,
                                          Σ_{e∋v} y_e w_e = 0  ∀ free v }        (⋆)
```

（把每个 `|·|` 的对偶变量 `w_e` 引入、再对自由 `z` 取极小：`z` 的系数为 `Σ_{e∋v} y_e w_e`，
不 vanциш 则 `inf = −∞` ⟹ 必须**力平衡** ✓✓。）其中 `U-dependent data` 只需保留与锚相连的部分：
若边 `e` 的一端是自由节点、另一端是锚 `U_{i(e)}`，则贡献 `y_e ⟨w_e, U_{i(e)}⟩`；两端都自由的边贡献 `0` ✓。

**⟹ 向量力对偶（本任务的主结论）**：

```
V(U) ≥ Σ_{i=1..9} ⟨ l_i , U_i ⟩ ,   l_i := Σ_{e : e 连到锚 U_i} y_e · w_e ,
subject to   y_e ≥ 0,  Σ_e y_e ≤ 1,  |w_e| ≤ 1,  Σ_{e∋v} y_e w_e = 0  (∀ free node v)
```

—— 即：**给每条边一个力 `y_e w_e`（大小 `y_e`、方向 `w_e`），所有自由节点处力平衡，总"质量" `Σy_e ≤ 1`，
则 `r ≥ Σ_i ⟨l_i, U_i⟩`**（"anchor loads 点乘锚坐标" ✓，正是 lead 要的形式 ✓）。

**强对偶/取等的正确论证（按 lead 修正：不用 "finite index ⟹ Sion" ✗——自由节点无界，那个理由不成立 ✗）**：
* 固定 switch 后 primal 是**凸** SOCP（每条约束 `|z_{u_e} − z_{v_e}| ≤ r` 是 SOC，目标 `min r` 线性 ✓）；
* **Slater 严格可行点显式存在**：取**所有自由节点 = 0**、`r = max_i |U_i| + 1` ⟹ 每条边满足 `|0| = 0 < r` ✓
  且 `r > 0` ✓ ⟹ 严格可行；目标有下界（`r ≥ 0`）⟹ 最优值有限 ⟹ **强对偶成立** ✓（不需要 Sion ✓）。
* **`r` 的口径两版**（lead 指出）：加 `r ≥ 0` 时对偶约束为 **`Σ_e y_e ≤ 1`** ✓；把 `r` 当**无限制标量**时，
  `(1 − Σy)r` 项迫使 **`Σ_e y_e = 1`** ✓（否则 `inf_r = −∞` ✗）——两者只是归一化差异 ✓。
* **证书口径（永远有效，不必是紧对偶）**：只要 `y_e ≥ 0`、`|w_e| ≤ 1`、自由节点力平衡、且向量预算
  `Σ_e |y_e w_e| ≤ 1`，则 `r ≥ Σ_i⟨l_i, U_i⟩` **恒为合法下界** ✓（弱对偶；预算形式只影响紧度 ✓）。

**两个方向的读法**：
* **下界方向（有用）**：任何满足平衡的 `(y, w)` 给 `r` 的一个下界（弱对偶，**无需凸性** ✓）；
* **最优性方向**：若 `(y,w)` 与某个可行 `(r,z)` 使 `Σ⟨l_i,U_i⟩ = r`，则 `r` 是固定 switch 的**全局最优** ✓。

## §2 退化与"dual zero"陷阱（lead 特别提醒）

自由节点的 Ø 条件有两支，**必须**分清：

1. **内点支**（`z_v` 不等于任何 incident anchor/节点）：`w_e` 由几何决定且 `Σ_{e∋v} y_e w_e = 0` ✓（真正的力平衡）。
2. **锚点支**（`z_v = U_j`，`j` 是某个 incident 锚）：`∂|U_j − z_v| = ` **单位球** `B̄` ✓，故
   `0 ∈ y_j B̄ + Σ_{e≠j} y_e u_e`，即**只需 `|Σ_{e≠j} y_e u_e| ≤ y_j`** ✓（不是 `= 0` ✗）。
   这正是 gluing 的 "dual zero" 错误：**一个自由节点不可能同时等于两个不同的锚 `U_i ≠ U_j`** ✗——
   若证书里同时把 `z_v = U_i` 与 `z_v = U_j` 当成立，则它既不满足支 1（两条边零距离、`u_e` 未定义 ✗）
   也不满足支 2（子微分允许的是"被支配"，不是"两边同时零"✗）。**合法的锚点支证书必须写明**：
   哪一条 incident 边的力**支配**其余 incident 力的合向量（`|Σ_{e≠j}| ≤ y_j`），其余 incident 边在此处是"松弛"的 ✓。
3. `Σ_e y_e = 1` 时 `r` 的系数为零 ⟹ 下界**刚性**（锚载荷不可再放大）✓；`Σ < 1` 时下界可被 `(1−Σy)r` 项吸收，
   仍有效但更弱 ✓（实践上取 `Σ = 1` ✓）。

## §3 固定 switch ⟹ 凸、KKT 即全局（lead 的 "fixed-switch KKT can be globally optimal convex"）

* 固定 switch（= 固定哪些边"贴住"、哪支子微分、哪些面用哪个 aux 节点）后，可行集是**有限个** `|·| ≤ r` 的交 ✓，
  目标 `min r` 线性 ✓ ⟹ **凸程序**（SOCP）✓；Slater（`r > 0` 内点存在）⟹ **强对偶、无对偶间隙** ✓。
* 因此**固定 switch 下**：`V_switch(U) = max` over §1 的对偶可行集 ✓，且 KKT 点即全局最优 ✓✓。
* **候选处的 exact stationarity dual（构造配方，供 alternative 的 pilot 对照）**：
  * **face aux node 的角色**：中心面/扇形面的 aux 点取该面的 **circumcentre**；则由"外心 = 三顶点的重心组合"
    （`barycentrics` 与面积/边长成比例，均为有理式 ✓）给出该面上三条边力的**方向权重** ✓；
  * **boundary anchor 的角色**：锚 = 两个相邻 ring 的边界 tie ✓；tie 处两侧弧的**切线**给出一对方向 `±t̂` ✓，
    由 C897 权重按 tie 的切向**分配**到相邻边 ✓；
  * 把上述两族权重**拼起来**（`Σy = 1` ✓、每个自由节点平衡 ✓）得到对偶可行点；若其值 `= r` 则该点是**精确驻点** ✓
    （= 候选的 KKT 乘子在**对偶**侧的显式表示 ✓）。**注意**：这与 C897 的"移动 witness"一侧一致，
    但**不要**用"某节点 = 两个锚"来简化分配 ✗（§2）✓。

## §4 8-angle 外层 oracle 的性质（要 lead 的那条）

外层把 9 个锚限制在单位圆的 8 个自由度上：`U_i = (cos θ_i, sin θ_i)` ✓（整体旋转 ±1 自由度被商掉 ✓）。
定义 `V(U) := min_{free nodes} max_{e ∈ E} |z_{u_e} − z_{v_e}|` ✓（= §1 的 oracle ✓）。

**性质 1（正齐次）**：`V(tU) = t·V(U)`（`t ≥ 0`）✓——把自由节点同乘 `t` 即得 ✓（`t ≥ 0`；`t < 0` 无意义/不要求 ✓）。

**性质 2（关于 Cartesian `U` 凸）**：`V(U) = max_dual Σ_i ⟨l_i(U-independent) , U_i⟩` ✓ 由 §1 的 (⋆) 与 §2 的对偶可行集
（**不含 `U`** ✓）⟹ `V` 是**一族线性函数的上确界** ⟹ **凸** ✓✓（而且 = 某个凸紧集 `K`（对偶可行体）的**支撑函数**
`h_K(U)` ✓）。由此还可得：`V ≥ 0` ✓、`V` Lipschitz（关于 `Σ|U_i|` ✓）、`∂V(U)` = 达到最大值的对偶点集 ✓。

**性质 3（不能直接 global）**：外层可行的 `U` 落在**单位圆的 9 重乘积**上（8 维 torus）✓——这是**非凸**集 ✓
（例：`U_1, U_2` 在单位圆上，其中点 `(U_1+U_2)/2` 一般不在 ✓）。于是全局问题是
`min_{θ ∈ T^8} V(U(θ))` = **凸函数 ∘ 非凸参数化** ✗ ⟹ 没有全局凸性、不能直接 global 化 ✓
（`V` 的凸性只能用在**固定 switch / 固定 `U` 的邻域**内做局部/一阶结论 ✓，或对 `U` 做凸松弛（如允许 `|U_i| ≤ 1` ✓）
再补回"落在圆上"这一步 ✗——后者正是难点 ✓）。
更强的否定性提醒：即便允许 `|U_i| ≤ 1` 的凸松弛，`V` 在松弛集上的极小也不等于原问题 ✗（圆上的点可能被松弛到内部 ✓）。

## §7 一般 lift 引理（承重）+ 候选实例化的条件清单

### 7.1 引理（fixed-switch SOCP optimum = `R*`）

**引理 L**：设 fixed-switch primal 为：自由节点 `z`（11 center + 11 aux）、固定锚 `U_1..U_9`、边集 `E`（`|z_{u_e} − z_{v_e}| ≤ r`）、
`min r`；给定 `R* > 0`。若
* **(L1) primal 可行**：存在显式配置 `z*` 使**每条**边距离 `≤ R*` ✓；
* **(L2) dual 可行**：存在显式边力 `f_e = y_e w_e`（`y_e ≥ 0`、`|w_e| ≤ 1`）满足**每个自由节点力平衡**
  `Σ_{e∋v} f_e^{out} = 0` ✓（退化节点按 §2 两支之一，**不得**用双锚 trick ✗），且预算 `Σ_e |f_e| ≤ 1` ✓；
* **(L3) 值等式**：`Σ_{i=1..9} ⟨l_i, U_i⟩ = R*`（`l_i := Σ_{e 连锚 i} f_e` ✓）；

则 fixed-switch 最优值 **恰为** `R*` ✓。
*证明*：弱对偶（§1，`Σ|f_e| ≤ 1` ⟹ `r ≥ Σ_i⟨l_i,U_i⟩` ✓）给 `opt ≥ R*`；(L1) 给 `opt ≤ R*` ⟹ 相等 ✓。
**这是"有这些 conditions 即 optimum = R*"的完整逻辑骨架** ✓（不需要 Sion、不需要 tight 预算形式 ✓）。
