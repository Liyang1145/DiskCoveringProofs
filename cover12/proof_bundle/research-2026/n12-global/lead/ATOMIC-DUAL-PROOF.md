# Finite atomic dual for a whole two-hub box

Scope: radius U, ten boundary-active disks normalized to center annulus [1−U,sqrt(1−U²)], two inactive hubs h1=(x−s,y),h2=(x+s,y), s>0. No symmetry assumption. H is a closed rational box containing legal hub triples. Certificates may exclude an expanded box containing illegal triples; witnesses are necessary only for the legal triples.

## Exact witness measure
Choose any finite rational unit vectors v=(c,t), c²+t²=1. Boundary atoms are v. Hub atoms are hj+Uv. Retain hub1 atom only if Uc≤s_lo; retain hub2 atom only if Uc≥−s_lo. Thus each retained hub atom lies outside or on the other hub for every triple in H: distance²−U²=4s(s−Uc) for hub1, 4s(s+Uc) for hub2.

Every retained atom must be covered by the ten ring disks. On S1 neither inactive hub reaches. At a hub atom strictly outside the other hub, a small outward radial perturbation leaves both hubs and stays in intD, then finite-union closedness applies. At an intersection atom p, put n1=(p−h1)/U and n2=(p−h2)/U. For0<s<U, n1·n2=1−2s²/U²>−1, so v=n1+n2 satisfies v·n1=v·n2=2(1−s²/U²)>0. Therefore p+εv is strictly outside both hubs for every sufficiently small ε>0 and stays in intD. Closedness again applies. This explicit perturbation covers intersection atoms without any general-position or arc-branch premise. The s=U face has no legal k10 triple: when x<a0 the core bisector endpoints require s²+(y+sqrt(a0²−x²))²≤U² and hence s<U; when x≥a0, strict inactivity gives x+s<1−U, hence s<1−U−a0=U. Thus s=U is retained only as part of the conservative rectangular superset, never as a legal witness premise. Inactive hubs ensure their circles lie in intD. We never assert this necessity for the expanded box's nonlegal triples.

Give each atom any nonnegative integer weight w. Multiplicities/coincident atom locations are permitted: the measure is a weighted sum of Dirac masses; every covered atom contributes its weight even if several locations coincide. Total demand T=sum w is exact. If every possible ring captures weight at most M and 10M<T, no ten rings can cover the required atoms.

## Whole-box ring bound
Each atom's moving Cartesian coordinates have exact rational enclosing intervals obtained from H and its exact unit vector. For any Cartesian ring-center rectangle B, bound below the minimum squared distance from B to each atom coordinate rectangle. Include its weight unless this lower bound is strictly greater than U². Sum is therefore an upper bound, for every ring center in B and every hub triple in H. It is harmless that different atoms' closest positions would require different hub triples.

Partition [-1,1]² dyadically. Discard B only if a certified norm² interval lies strictly outside [(1−U)²,1−U²]. Otherwise accept B only if 10 times its integer upper-capture sum is strictly less than T. No unproved point sampling enters acceptance. Empty DFS stack means the entire normalized ring domain is covered. Bounds on numeric errors are proved in hubline_atoms_fast.py and independently derived in members/upper-audit/atomic-audit/REPORT.md. Binary64 endpoints are exact dyadics; midpoint splits are exact within enforced depth. Integer sum T<2^60 prevents int64 overflow; multiplication by10 uses Python int.

## Pure-integer alternative kernel
The independent `members/upper-audit/integer-atomic/py/integer_kernel.py` removes the floating-distance premise. With S=2^26, round each exact atom rectangle outward to the integer grid (floor lower, ceil upper). Ring endpoints are dyadic integers in the same units. The integer rectangle distance squared is a lower bound for S² times the true distance squared. Include each atom unless this integer is greater than ceil(U²S²). For annulus rejection, compare maximum norm² strictly below floor((1−U)²S²), or minimum norm² strictly above ceil((1−U²)S²). These enlarged tests are conservative in the required directions.

All endpoints have magnitude at most2S, so differences have magnitude at most4S and the two-coordinate squared norm is at most32S²=2^57, well below signed int64 overflow. Nonnegative weights have total below2^60; total and the factor10 comparison are Python integers. Dyadic splitting stays on the integer lattice, and insufficient resolution returns unresolved, never success. This implements the same mathematical obstruction using only rational setup and exact bounded integer arithmetic. Its first11 tested hub boxes succeeded, including an exact6-unit demand-minus-ten-capture margin; whole-manifest replay remains a separate obligation. The same proof allows S=2^28: the conservative squared-distance bound becomes32S²=2^61<2^63. Outward atom rounding is finer and the fixed16-unit minimum box-width threshold becomes smaller. A leaf unresolved at2^26 may be replayed at2^28, but only a saved successful replay with its actual scale and inputs bound can certify it; failure at the coarse scale must not be relabelled as success.

## Atom-count generalization and partitioned execution
The argument is unchanged for N=8192 or any explicitly saved finite list of rational unit vectors: no uniform-spacing or quadrature premise occurs. `integer_kernel_n.py` independently constructs rational atom rectangles and nonnegative integer weights, and inherits the frozen integer `bound`/`certify` methods. N8192 certificates therefore require both source hashes and the explicit vector-file hash. Per-leaf `atomN` defaults to2048 only for legacy leaves; unknown atom counts must be rejected by the verifier, not guessed. Cache reuse requires the identical H, weights, N, vector hash, and both kernel hashes, together with a certified source record bound to its source snapshot. A cache key's self-consistency alone is not evidence that the stored verdict was obtained.

Parallel workers replace only the pending boxes of the immutable stage11825 snapshot. Eleven roots result from bisecting its first pending box twice, keeping the other seven unchanged. Their interiors are disjoint and their closed union equals the old pending union. Each branch frontier must independently be an exact canonical binary partition of its declared root. The unified manifest consists of the old terminal leaves plus each branch's new terminal leaves; old pending boxes are removed and replaced by the new pending boxes. A branch's empty queue excludes only that branch root. Empty unified queue, exact full-root partition, valid prune evidence, and all atomic replays are separate necessary conditions for the global domain exclusion.

## Proposals versus premises
A numerical LP returns smooth Fourier coefficients only to propose useful weights. Rational generator coefficients are checked nonnegative; stereographic unit vectors are exactly rational even though initial angle proposals use tan. Rational complex powers evaluate densities, followed by exact integer rounding. The resulting nonnegative integer weights and rational atom locations, not smooth densities, numerical arc integration, or uniform-grid accuracy, are the certificate premises. Failure at low atom count is a method/proposal failure, never a covering construction.

## Global domain wrapper
lead/hubline_domain.py starts at s∈[1/20,U], x∈[0,1−U−1/20], y∈[0,3U−1]. This contains every legal normalized k10 triple not already excluded by d≤1/10 or d≥2U. It subdivides at exact rational midpoints, retaining two closed children. A hub box may be discarded only by: (i) exact interval norm lower bound violates inactive outerhub bound; (ii) a fixed rational point on core circle has exact lower distance>U to both hubs; (iii) if x_hi<a0, the exact lower value sl²+(yl+sqrt(a0²−xh²))² exceeds U². This is tested without radicals: q2=a0²−xh², rhs=U²−sl²−yl²−q2, and accept infeasibility iff rhs<0 or 4yl²q2>rhs². Signs and the strict xh<a0 guard justify squaring; the test is exact. Each is a necessary-cover constraint. All other terminal boxes require an atomic certificate. Saved pending boxes are an explicit unresolved gap; a partial file is not global proof.
