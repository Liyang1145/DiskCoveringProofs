# 复核：`lead/ONE-THIRD-LOWER-BOUND.md`（$r_D(12)>1/3$ 的初等全局下界）

复核者：finite-reduction（本成员）。方式：逐步解析核对（只读该文件与其依赖 `lead/FOUNDATIONS.md` §1）；未改动被复核文件。结论：**推理正确，未发现数学错误**；给出逐步清单与两条建议（均为写法明确化，不是纠错）。

## 1 逐步核对（$r<1/3$ 不可能）

| 步骤 | 内容 | 核对 |
|---|---|---|
| 1 | 活动盘覆盖弧半角 $\le\asin r$：中心 $c=tu$（$t>0$；$r<1/3$ 时 $c=0$ 不活动），覆盖方向满足 $\cos\theta\ge\gamma=\frac{1+t^2-r^2}{2t}$，AM-GM 给 $\gamma\ge\sqrt{1-r^2}>0$，故半角 $\alpha=\arccos\gamma\le\asin r<\pi/2$ | ✓（$t>0$ 前提与 $t\to0$ 的极限情形需分开；文件已用"$c=0$ 不活动"覆盖） |
| 2 | $\sin(\pi/9)>1/3$：$g(x)=3x-4x^3$ 在 $[0,1/2]$ 严格增（$g'=3-12x^2>0$），$s=\sin(\pi/9)\in(0,1/2)$，$\sin(\pi/3)=g(s)=\sqrt3/2$；若 $s\le1/3$ 则 $\sqrt3/2\le g(1/3)=23/27$，与 $3/4>529/729\iff2187>2116$ 矛盾 | ✓（数值与等价性均核对；无需 $\pi$ 的十进制） |
| 3 | $k$ 个活动盘总测度 $\le k\cdot2\asin r<k\cdot 2\pi/9$；$k=9$ 时 $<2\pi$，不能覆盖圆周 | ✓（严格性来自 $r<1/3<\sin(\pi/9)$） |
| 4 | $a=1-2r>r$；活动盘心 $\|c\|\ge1-r$，故对 $\|y\|<a$ 有 $\|y-c\|\ge\|c\|-\|y\|>(1-r)-(1-2r)=r$：活动盘不碰**开**核心 | ✓ |
| 5 | 开核心 $\subseteq$ 至多 2 个非活动盘；有限闭并是闭集，故**闭**核心 $B(0,a)\subseteq$ 同两盘；特别覆盖 $S(0,a)$ | ✓（关键：有限性，不是可数并） |
| 6 | 半径 $r<a$ 的盘在 $S(0,a)$ 上覆盖弧半角 $\le\asin(r/a)<\pi/2$（同 AM-GM 缩放：$\cos\theta\ge\frac{a^2+t^2-r^2}{2at}\ge\sqrt{1-(r/a)^2}$） | ✓（$t=0$ 时覆盖为空，因 $a>r$） |
| 7 | 两段测度 $<\pi$ 的弧不能覆盖圆周 $\Rightarrow$ 矛盾；故 $r\ge1/3$ | ✓ |

## 2 逐步核对（端点 $r=1/3$ 排除）

| 步骤 | 内容 | 核对 |
|---|---|---|
| 1 | 同计数给 $k\ge10$；$a=1-2r=1/3=r$；$\le2$ 个 hub 覆盖闭核心 $B(0,r)$ | ✓（步骤同 §1.4–1.5，$a=r$ 时"开核心不碰"仍然成立，且闭包论证不变） |
| 2 | 活动心 $\|c\|\ge2/3=2r$；$B(c,r)\cap S(0,r)$ 为空或单点（三角不等式取等，点为 $(r/\|c\|)c$） | ✓ |
| 3 | hub 非活动 $\Rightarrow\|c\|+r<1\Rightarrow\|c\|<2r$；$\|c\|=t>0$ 时在 $S(0,r)$ 上覆盖弧为 $\cos\theta\ge t/(2r)>0$，半角 $<\pi/2$（**严格**短半圆）；$t=0$ 覆盖整个 $S(0,r)$ | ✓（"严格"是承重点：两个 $\le$ 半圆仍可能覆盖全圆，两个**严格**短半圆不能） |
| 4 | 两 hub 都不为 0 $\Rightarrow$ 两严格短弧测度 $<2\pi$，不能覆盖 $S(0,r)$ $\Rightarrow$ 至少一个 hub 恰为 0 | ✓ |
| 5 | 情形 (ii-a) hub 全为 0（或缺席）：$S(0,r)$ 全被覆盖；在 $S(0,r)$ 取点 $x$ 避开活动盘至多 $\le12$ 个切点（开弧去掉有限点仍非空） | ✓ |
| 6 | 情形 (ii-b) 另一 hub 非零：其弧是 $S(0,r)$ 的非空真闭弧，补集是非空**开**弧；在其中取 $x$ 并避开有限切点 | ✓ |
| 7 | 向外微移 $x_\varepsilon=(1+\varepsilon)x$：非零心盘由连续性保持 $\|x-c\|>r$；0-hub 因 $\|x_\varepsilon\|=(1+\varepsilon)r>r$ 失效；取 $\varepsilon<1/r-1=2$ 保 $x_\varepsilon\in D$ | ✓ |
| 8 | 得 $x_\varepsilon\in D$ 未被任何盘覆盖，与覆盖矛盾；故 $r=1/3$ 亦不可能 | ✓ |

## 3 严格化链条与一处建议（非纠错）

- 文件末"Compact attainment C925 then yields $r_D(12)>1/3$"**是必要的**，不是冗余：仅排除 $r=1/3$ 只给"$1/3$ 不可达时 $r_D$ 仍可能等于 $1/3$"（对所有 $r>1/3$ 有覆盖、$1/3$ 处无覆盖，逻辑上未被 §1–§2 排除）。排除该情形需要：`FOUNDATIONS.md` §1 的**投影引理**（任意中心可径向投影入 $D$ 而不增大 $R$，其代数 $|x-tu|^2-|x-u|^2=(t-1)(t+1-2x\cdot u)\ge(t-1)^2\ge0$ 对 $t\ge1,|x|\le1$ 已核对）把最小化限制到紧集 $D^{12}$，加上 $R$ 对配置的 $1$-Lipschitz 性（$\Rightarrow$ 连续）$\Rightarrow$ $\min R$ 可达 $\Rightarrow$ $r_D\in$ 可覆盖半径集 $\Rightarrow$ 若 $r_D=1/3$ 则存在半径 $1/3$ 的覆盖，与 §2 矛盾。建议在被复核文件中把这三句话写全，避免读者把 C925 读成多余。
- 建议把 §1 步骤 3 的严格性来源写全（$9\cdot2\asin r<9\cdot2\pi/9$ 需 $\asin r<\pi/9$，由 $r<1/3<\sin(\pi/9)$ 与 $\asin$ 单调）。
- 与已有资产无冲突：该结论只删 $[0,1/3]$（非锐界）；与登记上界 $0.3611\ldots$ 相容。
