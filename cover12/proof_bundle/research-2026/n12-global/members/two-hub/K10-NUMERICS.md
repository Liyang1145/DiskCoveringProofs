# k=10 分支数值：器械、控制、临界半径、极值结构、方法边界

等级：**数值（诊断）**。所有读数都来自有限搜索与有限候选集；它们能判死具体构型、能给结构提示，**不能**认证"所有 k=10 构型 R>U"。范围：半径 r 的 k=10 族 = 10 个内根边界盘（半角 `α_i≤asin r`，`ρ_i=ρ_−(α_i;r)`）+ 2 个非活动 hub（`‖h_j‖<1−r`），旋转固定 `φ_1=0`（23 自由参数）。

## 1. 器械与校准（先校准再使用）

- **目标函数** `R_cand(C)`：`members/finite-reduction` 的有限候选集（固定点 `(1,0)`、非零心反径点、每对不同心的中垂线∩`S^1` 两点、每个非共线三元组落在 `D` 内的外心）上的 `f_C(x)=min_i|x−c_i|` 最大值。按该成员的有限归约定理 `R(C)=max_{K(C)}f_C`；数值上 `R_cand≤R`，故它是**下偏**读数：能判死（`R_cand>r` ⇒ 不覆盖），不能认证覆盖。
- **已知答案校准**：C182 精确有理构型（`session2/n1314/cfg/cert_n12_othern.json`）→ `R_cand=0.3611029637445088`，与 `U` 差 `1.1e-16`；`n_active=9`（与 C182 = 9 边界盘一致）。
- **独立器械一致**：`R_cand` 与我自写的矢量化候选集在 5 个随机构型上逐点一致（最大差 2.7e-15，`R_cand` 差 0）；`candlib.R_ref`（网格+投影模式搜索）与 `R_cand` 在全部搜索输出上一致到 ≤1e-6（见各 JSON 的 `R_ref`）。
- **正控制**（证明该族确实能覆盖）：`r=0.45` 得 `R=0.406486`（`n_active=10`）；`r=0.40` 得 `R=0.384623`（`n_active=10`）。二者均 `<r`，即 k=10 覆盖在较大半径确实存在，搜索器械可用。
- **负控制**：同一器械对 C182 在 `r=0.3` 给 `R_cand=0.3611>r`（不覆盖），方向正确。

## 2. k=10 临界半径（多起点搜索，`Nelder–Mead`，`R_cand` 目标）

`run_search.py` 每档 2 个种子 × 16 起点 × 5000 次评估；记录该族在该半径下找到的最小 `R`：

| 0.365 | 0.372499 | 否（+0.0075） |
| **U=0.361103** | **0.372850** | 否（+0.0117） |
| 0.355 | 0.377283 | 否 |
| 0.345 | 0.376922 | 否 |
| 0.335 | 0.378944 | 否 |

**读数**：k=10 族的临界半径 `r*∈(0.370,0.380)`（`m(0.380)<0.380<m(0.370)`），且 `R_10 := min` 该族覆盖半径 `≤0.372499`（r=0.365 的最好构型），即 **`R_10−U ≤ −0.0114`，方向与要证一致**：k=10 在 `r≤U` 的最优构型比 U 差 ≈0.0114。搜索只给上界方向（找到的更差构型不排除），故这是"有真实余量"的证据，不是排除。

## 4. 极值构型结构（`analyze_extremal.py`，r=U 的最优）

- 两 hub 范数 ≈`0.2625`/`0.1197`，夹角 ≈`3.0715`（近对跖），`d=0.382<2U`；核心条件 `β_1+β_2=3.659≥2π−δ=3.212` 有余量。
- 10 个 ring 半角之和 `3.068<π=3.1416`（该半径下不覆盖故无须 ≥π）。
- 构型近 2 重旋转对称（`φ_i+π` 与自身相差 ≤0.05）。
- `f_C` 的两个最大点是**内部点** `|x|≈0.334, 0.356`，各为 3 盘等距（ring+hub+hub 或 ring+ring+hub）——即瓶颈在"hub blob 与 ring 带之间的接缝"，不在 `∂D` 上。

## 5. 方法边界（记录，不是判死）

- **均匀权的两层径向容量失败**（`radial_capacity.py`）：对每个 `σ_0` 比较 `10·max_ρ[2α(ρ)+2γ_ring(ρ)]` 与 `2π+μ(σ_0)`（`μ` 用 hub 覆盖上界），最好比值 `1.176`（`σ_0≈a`），其余 `≥1.36`。故"原点同心内圆 + 均匀权"路线在本问题不可能成立。
- 更强：`AVERAGE-TRICK.md` 证明**任何非负权**在单圆上都达不到低于弧长比的单盘捕获份额（`∂D` 上为 `asin(U)/π=0.11759971254822`，而每盘预算是 10%）。⇒ 余量只能来自外圆弧与 hub 弧的**几何锁定**，这正是 `DUAL.md` 用的 coupled contribution。
- 本目录**没有**用 dense grid 覆盖半径当 upper，也没有批量族优化当证明。
