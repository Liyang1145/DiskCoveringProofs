## 0. 结论

1. **S=2^28 的 int64 安全成立**，且余量可量化：实际最坏 `d² ≤ 18S² = 1.297e18`，
   代码断言上限 `32S² = 2.306e18`，两者都 `< 2^63−1 = 9.223e18`（分别 7.11× / 4.00× 余量）。
   无中间量溢出（`dx² ≤ 9S²`）。阈值 `U2_ceil / inner_floor / outer_ceil` 在 28 尺度分别
   9.396e15 / 2.941e16 / 6.266e16 ≪ 2^63，且**逐位等于** ceil/floor 定义。
2. **非负权与舍入定义成立**：权重由精确有理密度经 `assert v ≥ 0` 后 `round(v·10⁹)`（Python 半偶舍入，精确），
   丢零权只**减小**需求；坐标一律 floor 下 / ceil 上（外扩）⇒ 计入判据是 capture 的**上界**。
   独立检验：4800 组 (盒, 原子) 上「真距离² ≤ U² ⇒ 必被计入」**0 反例**。
3. **全 ring 域 DFS 成立**：根盒 = [−S,S]²（= 实坐标 [−1,1]²）含归一化 annulus（`√(1−U²) < 1`）；
   discard 仅当盒与 annulus **严格不交**（400 组抽样 0 反例）；分裂保持整格点（奇偶 assert 为不变量）；
   分辨率 = 16 单位 = 16/S（26 尺度 2^-22 / 28 尺度 2^-24）；未决返回 `unresolved`/`budget`，不冒充成功。
4. **exposure 筛选：对 relaxed 区间安全（充分），不是对 legal 子集的"必要性"**。
   恒等式 `dist²−U² = 4s(s∓Uc)`（hub1 取 `−`，hub2 取 `+`）精确；保留条件 `Uc ≤ s_lo` / `Uc ≥ −s_lo`
   保证被保留的原子在**整个 relaxed H 的 s 区间** [s_lo, s_hi] 上都落在另一 hub 之外或之上
   （因而在任何 legal 子集上也成立）⇒ **充分**。
   反向话要说准：被丢弃的原子只在 `s = s_lo` 这一**可能非法**的取值上严格落在另一 hub 内部；
   若 s_lo 不是 legal 三元组的 s，则"丢弃它"**不**代表它对 legal 子集不必要，只是**保守地少收需求**
   （少收只会削弱不等式，不会造成假证明）。**不得**表述为"保留它们不安全"或"筛选对 legal 集必要"。
   抽样（2048 向量 × 该叶盒）：保留原子在 [s_lo, s_hi] 上全部满足 ≥0；丢弃原子在 s=s_lo 全部 <0。
5. **发现 1 个真实（非可靠性）缺陷**：`certify(max_depth=23, …)` 的 `max_depth` **只被回显**，
   不参与停止判据（停止靠 `w ≤ 16`）；返回 dict 的 `depth` 字段是常量 26 尺度下的数值。
   在 S=2^28 下按坐标分裂次数应为 25，而字段仍写 23 ⇒ **unresolved 记录的 `depth` 字段在 28 尺度上不可信**。
   见 §6。不影响 certified 结论（certified 分支不含 depth 字段）。
6. **未发现**影响 certified 的漏洞。精确适用域见 §7。

## 1. int64 安全（逐步推导）

设尺度 `S = 2^Sexpt`，整数单位 = 1/S。

| 量 | 代码位置 | 界 | 26 尺度 | 28 尺度 |
|---|---|---|---|---|
| 原子端点 | `maxend`，`__init__` assert `≤ 2S` | \|A\| ≤ 2S | 2^27 = 1.342e8 | 2^29 = 5.369e8 |
| ring 端点 | `bound` 内 assert `−S ≤ lo ≤ hi ≤ S` | \|B\| ≤ S | 2^26 | 2^28 |
| 单坐标差 | `dx = max(Ax0−bx1, bx0−Ax1, 0)` | ≤ 3S（保守写法 2S+2S=4S） | ≤ 2.013e8 | ≤ 8.054e8 |
| 中间量 | `dx*dx` | ≤ 9S²（=2^56 / 2^60） | 6.49e16 | **6.49e17** < 2^63 |
| 结果 | `d2 = dx*dx+dy*dy`，assert `≤ 32S²` | ≤ 18S²（断言 32S²） | 1.44e17 | **2.31e18** < 9.22e18 |
| 权重和 | `W[mask].sum()` int64；`total < 2^60` assert | ≤ total | 3.3e11 | 3.3e11 |
| `10·val` 比较 | `int(...)` 后 Python int | 任意精度 | — | — |

实测（28 尺度，来自 escalated evidence 与本审计重算）：`max_d2_seen = 2.68e17`（= 0.116·32S²）、
`max_endpoint_units = S`（非 2S，还剩 2× 余量）。**全部断言在 28 尺度上留有余量而非贴边。**

阈值（精确有理 → 整数，`ceilF/floorF` 已验证是真 ceil/floor，656 样本 0 反例）：

```
S=2^26: U2_ceil=587248451585182  inner_floor=1838321733031375  outer_ceil=3916351175785315
S=2^28: U2_ceil=9395975225362900 inner_floor=29413147728502004 outer_ceil=62661618812565037
```
三类都用精确有理比较生成，且 `U2_ceil == ceil(U²S²)`、`inner_floor ≤ (1−U)²S² < inner_floor+1`、
`outer_ceil−1 < (1−U²)S² ≤ outer_ceil` 均逐条验证通过。

**为什么能到 28 而不能更高**：断言上限 `32S² < 2^63` ⇔ `32·2^(2k) < 2^63` ⇔ `S = 2^k < 2^29`，
故断言本身只允许到 **S = 2^28**（2^29 时 32S² = 2^63 恰不满足严格小于）。实际最坏 `18S² < 2^63` 允许到 `S ≤ 2^29`，
但构造器硬门 `20 ≤ Sexpt ≤ 28` 才是决定性的；**29 未被保证**（阈值与网格定义都需重新论证），不要外推。

**total / 10·M 的溢出与 strict gap（单列，按要求换推理复核）**
* `M`（单叶 capture 权上界）= `int(W[d2 ≤ U2_ceil].sum())`：numpy int64 求和，**上界即 `total`**
  （同一权重数组、无重复计数以外的放大），而 `total < 2^60` 由构造器 assert 保证 ⇒ 求和本身不可能溢出。
* `10·M` **不**在 int64 里算：`bound` 返回前已 `int(...)` 成 Python int，`certify` 里 `10 * val < self.total`
  是 Python 大整数比较 ⇒ 即使将来 `total` 接近 2^60 也不会回绕。这一点由 §8 第 2 组在 26/28 两尺度上
  以 `10*total < 2^63` 的形式另行 assert 兜底（构造器同时断言 `total < 2^60`）。
* **strict gap**：接受条件是**严格**不等式 `10·val < total`；`val`、`total` 均为整数 ⇒ 等价于
  `total − 10·val ≥ 1`。记录里的 `gap_integer = total − 10·max_integer_capture`：对三个 28 尺度叶
  独立重算得 `674622 / 2959381 / 300128` 全部 `> 0`（§8 第 6 组 0 反例）——"gap 为正"不是 ≥0 的宽松写法。
* 反向核对：26 尺度同一盒 `10·val − total = +207945318 > 0` ⇒ 正确判为 unresolved；
  28 尺度 `total − 10·val = 1106726432 > 0` ⇒ 正确判为接受。两个方向都用**同一**整数比较，无浮点。

**哪一步真正吃紧了**：不是总距离和，而是**中间乘积** `dx*dx`：`dx ≤ 3S` 时 `9S²`，28 尺度 6.49e17（距 2^63 14×）；
断言里的 `32S²` 走的是"4S 保守写法"，比实际宽 1.78×，属**保守而非贴边**。若将来把 ring 端点 assert 放宽到 ±2S，
则 `dx ≤ 4S`、`d² ≤ 32S² = 2^61` 仍安全（这正是文档给出的保守链）——即两条链都闭合，没有"靠运气"的地方。

## 2. 非负权与舍入定义

* **密度计算**：`v = w0 + Σ w_k cos(kθ) + v_k sin(kθ)`，用**精确有理**复幂（`c,t` 是显式有理单位向量）逐项累加，
  无浮点介入；随后 `assert v >= 0`（精确有理比较）。⇒ 负密度是**硬失败**（AssertionError），不会静默取绝对值/回绕。
  注意：原子测度本身只要求"非负整数权"，`v ≥ 0` 是**更强的**生成器卫生检查，不是测度合法性的必要前提。
* **舍入**：`wt = round(v * 10**9)`。Python 的 `round(Fraction)` 是**精确**半偶舍入（不经过 float），返回 int；
  `wt = 0` 时 `continue` 丢弃该原子。丢弃只**减小** `total`（需求），方向上只会**变弱**（更保守），不会造成假证明。
* **坐标外扩**：下端点 `floorF(rx[0]*S)`、上端点 `ceilF(rx[1]*S)`；矩形因此**包含**真实有理矩形。
  外扩只会**减小**测量距离 ⇒ 计入的权只会**变多** ⇒ capture 是上界。独立验证（§8 第 7 组）：
  120 个随机 dyadic 盒 × 40 个随机原子 = 4800 组，`真距离² ≤ U² ⇒ 被计入`**0 反例**。
* **annulus 舍入**：`high < floor((1−U)²S²)` 才丢（严格），`low > ceil((1−U²)S²)` 才丢（严格）。
  方向正确：`high` 是盒内 max norm² 的**上**界、`low` 是 min norm² 的**下**界，
  故两者分别保证"整盒严格在洞内/严格在外圈外"。独立验证：400 个随机盒中，
  「丢弃 ⇒ 与 annulus 不交」0 反例；「与 annulus 相交 ⇒ 未丢弃」0 反例（后者是完备性方向）。

## 3. 全 ring 域 DFS

* 起始栈 = `(−S, S, −S, S)` ⇒ 实坐标 [−1,1]²。归一化 ring 域 = annulus `1−U ≤ ρ ≤ √(1−U²)`，
  而 `√(1−U²) < 1` ⇒ 根盒**真包含**整个合法域（这正是证明所依赖的"保守矩形超集"）。
* 合法性覆盖：任一 annulus 点所在盒都不会被 discard（discard 需**严格**不交），故
  「栈空」⇒ 保留盒覆盖整个 annulus；每个保留盒要么被接受（`10·val < total`），要么继续分裂。
* 分裂精确性：根宽 `2S` 是 2 的幂，每次减半仍为 2 的幂，`a+b = 2a + w`（w 为偶数）⇒ `(a+b) % 2 == 0`
  是**不变量**而非检查；真的不满足时会抛断言而不是静默错分。
* **分辨率与"深度"三个不同口径（术语澄清；先前版本第 ⑤ 条把公式写错，已改）**：
  * 停止条件 `w ≤ 16` 单位 ⇒ 真实边长 `16/S`（26 尺度 2^-22、28 尺度 2^-24）；
  * **单坐标分裂次数**（把根宽 2S 降到 ≤16 所需）：`2S / 2^k ≤ 16 ⇔ k ≥ Sexpt − 3`
    ⇒ 26→**23**、28→**25**（先前误写 `Sexpt−1`，与 23/25 不符，已更正）；
  * **DFS 树路径长度**（每步只裂**一轴**）：一次分裂只把一轴减半，而一个盒只在**两轴都 ≤16** 时才会被判 unresolved，
    故一条根到叶路径最多走 `2(Sexpt − 3)` 步 ⇒ 26→≤46、28→≤50（不是 23/25）。
    已接受叶可以早停，故实际路径更短；证据中的 `boxes` 是遍历节点数，与这两者都不同。
  28 尺度同时得到「更细的盒」与「更细的原子矩形」两种收紧。
* 失败语义：`unresolved`（分辨率不足）与 `budget`（盒数上限）是**独立状态**，都不等于成功；
  只有整栈耗尽且每盒接受才返回 `certified`。**不存在**"抽样通过即成功"的路径。
* **26→28 翻转的机制（本审计直接复算）**：对 idx 4398，用 scale-26 整数核在**记录的 unresolved 盒**上重算得
  `bound = 32608767913`，与 escalated evidence 记录的 `cap` **逐位相同**；把同一实盒 ×4 抬到 28 尺度得
  `bound = 32477300738`，于是 `10·bound = 324773007380 < total = 325879733812`（余 1.107e9）。
  即翻转是**分辨率效应**（更细矩形少算了一个不该算的原子），不是新前提、也不是放松判据。

## 4. exposure 筛选：对 relaxed 区间的安全性（充分方向）

* 恒等式（精确）：hub1 原子点 `h1+Uv` 到 h2 的距离² − U² = `4s(s − Uc)`；hub2 原子点 = `4s(s + Uc)`。
  ⇒ 只要 `s > 0`，hub1 原子在另一 hub **之外或之上** ⇔ `Uc ≤ s`；hub2 ⇔ `Uc ≥ −s`。
* **充分性（真正被用到的一侧）**：代码筛选用 `s_lo`（盒内最小 s），保留 `Uc ≤ s_lo` / `Uc ≥ −s_lo`
  ⇒ 对盒内**全部** s（含每个 legal 子集上的 s）成立 ⇒ 每个保留原子在整段 relaxed 区间上都在另一 hub 之外或之上，
  因而是"必须被覆盖"的候选。抽样验证：该叶盒 2048 向量上，保留原子在 s∈{s_lo, (s_lo+s_hi)/2, s_hi} 全部满足 ≥ 0。
* **丢弃方向要说准（先前版本在此过度断言，已改）**：被丢弃的原子只在 `s = s_lo` 这一点上**严格**落在另一 hub 内部，
  而 `s_lo` 是 relaxed 盒的下端、**未必是 legal 三元组取到的 s**。因此：
  * 「保留它不安全」**不成立**：保留一个只在 s < Uc 处才被遮住的原子，对 legal 子集仍然是合法需求；
  * 「丢弃是必要的」同样**不成立**（除非 s_lo 本身落在 legal 集合里，那是额外前提）；
  * 正确表述：丢弃只是**保守地少收需求**（少收 → `total` 更小 → 不等式更难成立 → 不会制造假证明），
    代价是可能损失一点点力度。抽样里"丢弃原子在 s=s_lo 全部 < 0"只是**该点**的读数，不是 legal 集上的必要性。
* 「必须被覆盖」的论证（来自 `ATOMIC-DUAL-PROOF.md`，非本核）：保留原子在暴露弧上；
  严格在外者作外向扰动后仍在 intD 且在两 hub 之外，用闭集有限并的闭性回推；交点原子用 `n1+n2` 方向同样处理；
  s=U 面无合法 k10 三元组。**这些是 wrapper 的合法性前提**，整数核不检查（见 §5）。
* S¹ 原子（j=0）不筛选：两 hub 非活跃（圆在 intD 内）故不可及 ∂D，S¹ 必须由 10 个 ring 覆盖。
  「hub 非活跃」由 wrapper 的 infeasible 判据负责，**不在核内**。

## 5. 核不检查、必须由调用方（wrapper/verifier）保证的前提

1. H 的每一点都是**合法三元组**（s>0、s≤U、d=2s≤2U 与分离/hub 非活跃等）；核只处理"矩形超集也能证"的情形，
   不做合法性过滤。**注意**：`__init__` 的 `assert H[0][0] >= 0` 的报错文案写的是 `[0,U]`，实际**只查 s_lo ≥ 0**，
   未查 `s_hi ≤ U`。这不影响核内方向性（恒等式只需 s>0），但**文案强于检查**，属接口卫生项。
2. 尺度必须与证书绑定：26 与 28 是**不同对象**（同 (N,H,W) 的两个合法证书）。
   finite-reduction 的 cache key 已含 scale（`key_from_parts(..., scale)`），与本节结论一致。
3. 原子向量必须显式保存且逐点 `c²+t²=1`（28 尺度不改变这一点；N8192 需附带向量文件 hash）。
4. 权重非负、整数、`total < 2^60` 且 `10·total < 2^63`（构造器 assert 已内含）。
5. **annulus 归一化前提**：两条 discard（整盒严格在洞内 / 严格在外圈外）之所以合法，是因为归约
   （`K10-HUB-LINE-CHART.md` / `INNER-ROOT-REDUCTION.md`）已把 ring 中心规范化到 `[1−U, √(1−U²)]`。
   核**不证明**该规范化，只在该前提下工作：DFS 覆盖 [−1,1]² 减去被丢弃盒 ⇒ 与规范化合起来覆盖全部合法中心。
   若归一化前提被撤销，这两个 discard 就是漏洞；在当前链条里它是**上游前提**。

## 6. 发现的真实（非可靠性）缺陷

**D1 — `depth` 字段在 28 尺度上会报错值（当前证据里尚未发生，属潜在缺陷）。**
`certify(self, max_depth=23, budget=4000000)`：`max_depth` **不参与**任何停止判据；
停止由 `if w <= 16: return dict(status='unresolved', …, depth=max_depth)` 决定。
于是返回的 `depth` 恒为调用参数（默认 23），而独立判据给出的**单坐标分裂次数**是 `Sexpt − 3`
（26→23、**28→25**；推导见 §3，先前版本此处误写 `Sexpt−1`，已更正）。
证据现状：`escalated-scale28-evidence.json` 三条记录的 `"depth": 23` 都来自 **scale-26** 运行，
在 26 尺度上**恰好正确**；缺陷要到"28 尺度上出现 unresolved"时才现形——那一刻字段仍写 23，独立口径是 25。
影响：只污染诊断/记录字段，不影响 `certified`（该分支无 depth 字段），也不影响任何结论；
但任何按 `depth` 推断分辨率的审计工具会读到错值。建议（不改冻结核）：读取方忽略该字段，
或在新核里回报真实口径（并明确是"单坐标分裂次数"还是"DFS 路径步数"，两者见 §3）。

**非缺陷但值得记录的两点**
* `assert d2.max() <= 32 S²` 是**保守断言**（实际 18S²），不是贴边的紧界；28 尺度上两者都安全。
* 原子端点 assert 是 `≤ 2S`，实测只到 `S`（余 2×）；放宽到 ±2S 的 ring 端点也仍闭合（见 §1 两链）。

## 7. 精确适用范围（可直接引用的口径）

任何由本核产出的 `certified` 断言，其成立条件为**同时**满足：
* 尺度 `Sexpt ∈ [20, 28]`（构造器硬门），`S = 2^Sexpt`；26 与 28 的结果**互为不同对象**，不可互相代用；
* 原子 = 显式保存的**有理单位向量表**（逐点 `c²+t²=1`，N 任意），权重 = `round(v·1e9)` 的**非负整数**；
* `total < 2^60`、`10·total < 2^63`；
* H 为有理闭盒、每维 `lo ≤ hi`、`s_lo ≥ 0`；**盒内三元组的合法性（hub 非活跃、s ≤ U、d 与分离条件）由 wrapper 保证**；
* 结论形式：对**盒内任一** ring 中心（若落在 annulus `1−U ≤ ρ ≤ √(1−U²)` 且该点所在叶被接受），
  单环 capture 权的整数上界 `val` 满足 `10·val < total`；因此 10 个 ring **不可能**覆盖全部保留原子。
  保留原子在 relaxed H 的**整段** s 区间上都落在另一 hub 之外或之上（§4），故对任何 legal 子集同样成立。
* 交付的 `certified` 只覆盖**该叶声明域**；全域结论还需 wrapper 的 partition/覆盖证据（不在本核）。

**不可由本核推出**：跨尺度代用（26 的 unresolved 不能当 28 的结论，反之 28 的 certified 也不能回写 26）；
未列出的更大 N 或更高尺度；**丢弃原子的"必要性"**（本核只在 relaxed 盒上少收需求，不对 legal 子集断言必要性，见 §4）。
