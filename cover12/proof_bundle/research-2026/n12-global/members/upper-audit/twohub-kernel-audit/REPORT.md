## 2. 表达式的独立重建与校准（G1/G2）

**定义复核（我独立推导，与 DUAL.md §1 一致）**：`E_j` 是 `S(h_j,U)` 上被另一 hub 盘挖掉的部分——
以 `away_j=dir(h_j−h_{j'})` 为心、半宽 `π−b` 的弧（`cos` 判据：`x=h_j+U(cosθ,sinθ)`（θ 从 away 方向量），
`|x−h_{j'}|≤U ⟺ cosθ ≤ −d/(2U) ⟺ |θ| ≥ π−b`，故暴露集为 `|θ|≤π−b` ✓；`d≥2U ⇒ b=0 ⇒ 整圆` ✓）；
`A_j` 是 `S(h_j,U)` 上被环盘 `B(c,U)` 覆盖的部分：`|x−c|²≤U² ⟺ ℓ_j ≤ 2Ucosθ ⟺ |θ|≤β_j=acos(ℓ_j/(2U))` ✓；
`A₀` 由 `|x−c|≤U`（`|x|=1`）给 `α(ρ)=acos((1+ρ²−U²)/(2ρ))` ✓。弧积分用 `F_W(θ)=w₀θ+Σ_k (w_k sin kθ − v_k cos kθ)/k` ✓。

**两条独立路线**（`py/direct_cap.py`，dps=60）：
* R1 = 原函数差值；R2 = 对每个交集段独立 `mp.quad`（tanh-sinh）。交集按整数 k∈{−2..2} 的展开区间求交，
  两段情形逐段单独积分（这正是 interval 核必须包住的数学对象）。
* 110 个控制点上 `max|R1−R2| = 8.8e-62`；`req` 两法差 1.6e-61。
* 与成员浮点核交叉：`dual_refined_fixedK.json` 的 `m_local = 0.0969384926…@(0.673909311376261, 1.5047619108735262)`；

## 5a. unwrap 分支的 guard 充分性（Lead 指出，我复核并给出可证形式）

修复版 L164–183 的做法：把极坐标盒**四角**的 `atan2` 区间各自按整数 `k` 抬升到 `base` 附近，
再用 `if max(his) - min(los) >= mp.pi: return None` 判"窗口是否可用"。**这条检查本身不足以排除域绕圈**：

* 四角值的 lifted span < π 只说明四角能被放进一个宽 <π 的窗口；它**不**排除整个盒的像
  （连续二维像）绕过割线——像连通，含四角值，但一个含这些四角值的连通集仍可以是整圆。
* 真正需要的是"角点极值性 + 抬升一致性"的**可证**版本：
  (i) 沿曲边 `ρ=const`：`d(arg(ρu_φ−h))/dφ = ρ(ρ−⟨h,u_φ⟩)/ℓ²`，由守卫 `ρ_min > |h|_max` 得**严格正** ✓；
  (ii) 沿径向边 `φ=const`：`d(arg)/dρ = −(u_φ × h)/ℓ²`，**符号与 ρ 无关**（沿整条边定号）⇒ 单调 ✓（不需要额外守卫）；
  两式合并（`ℓ_min = ρ_min − |h|_max > 0`）给出盒上总变差界
  `V = δρ·|h|_max/ℓ_min² + δφ·ρ_max(ρ_max+|h|_max)/ℓ_min²`；
  只有当 `span(lifted corners) + V < π`（**区间算术判定**）时，抬升才是**唯一且正确**的，
  `ψ := [min los − V, max his + V]` 才是可信包夹。
* 数值量级：认证配置初始网格（10×40）最低 ρ 行 `δφ=0.157, δρ=0.0294, ℓ_min≥0.4389` 给 `V ≈ 0.50`，
  高 ρ 行 ≈0.35 ⇒ 对粗盒 `corner-span + V` 可达 `π` 量级，**当前检查确有充分性缺口**（严谨性缺口）。
* `mp` 端点减法要改成区间：`base=(elo+ehi)/2`、`m−base`、`max(his)−min(los) >= mp.pi`、以及
  `while m + 2*float(mp.pi)*k − base > float(mp.pi)` 都用 nearest-mpf 判号；应改为 iv 减法后判**确定符号**，
  抬升整数 `k` 也应由区间包含性判定（而不是中点的启发式）确认。
* **有界实测（补强，非证明）**：`py/coarse_box_guard.py` 对内核自己的初始网格 80 个粗盒（最低/最高 ρ 行）
  做箱级包含 probe（7×7 子网格 max 直接值 vs `ehi(ub)`）：**0 违反**，最紧余量 3.84e-2；
  即当前 guard 在我抽样的粗盒上**未实际失效**（缺口是"未证"而非"已错"）。

5. `L242–263` 交集与三分支：`lo<hi` 取 `[lo.lo,hi.hi]`（⊇ 真交集）、`hi<lo` ⇒ 空、
   未定序用 `fhi − flo`（**已是 iv 差**，取上端）；`W≥0` ⇒ F 单调 ⇒ `∫ ≤ ehi(fhi−flo)` ✓。
   三 shift 覆盖：ψ∈[−2π,2π]、E⊆[−2π,2π] ⇒ 足够；副本互不相交（2β≤π）⇒ 无重复计数 ✓。
6. `t_j = 1−U` 闭扩域：`|h|+U = 1 ⇒ S(h,U) ⊆ D̄` ⇒ `E_j∩D = E_j`（D 闭）⇒ **无需 D-clip** ✓

   `acos` 的单调性而非四角包夹）。
4. **后台重跑**：`logs/fixed_sweep.txt`（`py/run_fixed_sweep.py 400000 14`，max_boxes=4e5）用于回答
   "修复版能否收敛"。本报告不等该结果；收敛与否都不改变 §4 的"记录 PASS 作废"结论。
