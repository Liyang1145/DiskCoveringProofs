## 0. 一句话结论

**n12 的“单一常应力 + 全域 Hessian 次式 M ⪰ 0”路线不能原样搬到 n14 候选**——但这是**方法限制的定位**，不是判死：
在 10 anchor + 14 site + 14 活跃面 witness 的网络（r\*-cap 域）上，(α≥0, Σα=1, 自由节点平衡, capped-simplex KKT) 的**应力锥为空**；
唯一非负方向（支撑 4 条边 = 两个 cap-活跃 site 的锚边）在两个 active gap 上的导数**同号为正**（+0.0096 / +0.3034），
即它对 θ\* 是**上升方向**而非下降方向 ⇒ 无法把 θ\* 证成该能量的全域最小点。n12 的对照（那边 KKT 恒等成立、M 余量 +2.37e-3）在同一核上**逐位复现**。

## 3. 应力锥与 KKT（r\*-cap 域，修正后的正确条件）

设自由节点平衡 `Aα = 0`（55 独立行）、`τ_i = −2(Tα)_i`（锚点切向残差）、
`g_k = Σ_{i=k+1..9} τ_i`（= ∂E/∂Δ_k，注意 g₉ ≡ 0 恒等 ✓ 已数值验证 max|g₉|=0）。
capped-simplex 的 KKT（min 问题，cap 活跃集 A={4,9}）：
`g_k = c (k ∈ I)`、`g_k ≤ c (k ∈ A)`，c 自由（ΣΔ=2π 的乘子）。

* **结果（高精度，mpmath dps=60）**：差异形式齐次系统 `[A ; {g_k−g_0}_{k∈I}]` 为 63×62，**nullity 2**；
  * kernel 0：**非负**、支撑 4 条边（即两个 cap-活跃 site 的锚边），`|Aα| ≤ 3.5e−54`、`g_I spread ≤ 2.7e−55`，
    但 `g_4 − c = +0.00959687`、`g_9 − c = +0.30335039` —— **两个 active 不等式都是正号，违反** ✗
  * kernel 1：归一化后含负元 ✗
  ⇒ **(α≥0, Σα=1, Aα=0, KKT) 无解**（不是数值容差问题：核向量代入后残差 ~1e−54，违反量 ~1e−2）。
* **机制**：唯一非负应力只由“chord midpoint = site”的两个 cap-活跃 site 支撑，其能量 `E = R²(1−cosΔ)/(1−cosL\*)`
  在两个 cap 活跃 gap 上**随 Δ 递增**，而 cap 处的最小点需要该导数为 **≤ 0** ⇒ 该能量把 θ\* 当**上坡点**，不能用来证 θ\* 是最小点。
* 对照诊断（**非证书网络**，因 Lead 指出 slack 面三边必须为 0）：16-face 网络（含 2 slack 面）在 KKT 下锥非空、
  但解集退化到一点，且 **λ_min(M|1⊥) = −4.8124e−03**（全体锥顶点一致）；把 c₅ 从 −1 改成 0 仍为 −2.28e−3，
  改成 +1 才 +1.8e−4 ⇒ **M 的负方向来自 d=5（锚点对径）对的 cos = −1**（候选处实际角正是 180.0°）。
* 局部 Hessian（用候选真实角、同 q）：1⊥ 上 λ_min = **−2.383e−03** ⇒ 该应力下 θ\* 是 E 的鞍点（不是最小点）。
* 子网络扫描（去 0/1/2 个活跃面，106 个）：硬 KKT 可行 **0 个**；软 KKT 最小违反量 ~1e−9（=求解器容差，与上面“核向量违反 ~1e−2”合并看，判定为**精确不可行**）。

## 4. 为什么这仍是“方法限制”而不是判死（Lead 口径）

1. 我固定的是 n12 式网络（10 anchor + 全部 14 活跃面 witness）。**真实 sharp 结构可能还需要别的约束类型**：
   若 sharp 结构包含 *core 覆盖*（4 个内部 hub 必须覆盖 1−2U 闭核，C1142 机制）或 *k11* 分支的三角结构，
   其松弛会有更多边/更多自由节点 ⇒ 应力锥可能非空。**这是最值得先试的下一步**（混合松弛）。
2. 我用的是 r\* 的**数值**（30 位）而非精确根；cap 活跃性对 3.5e−17 的 L\*−L_U 差敏感 ⇒ 精确根/精确 cap box 是必要条件（且决定 c_d 的有理常数）。
3. d=5 对径对的 cos = −1 使 M 的通用次式必然粗糙 ⇒ **变量消元/SOS 重分配**（把 d=5 的负系数吸收进 d≤4 的正系数，用 (z_i−z_j)² ≤ 2(z_i−z_k)²+2(z_k−z_j)² 之类）是明确的备选表示，需在 n14 上单独设计。
4. Taylor+κ 路线（`NETWORK-TAYLOR-CERTIFICATE` 式）在本网络只能给 `E ≥ E_ref + min(grad·d) − (κ/2)max‖d‖² < R²`，
   **不足以**给出 sharp R²（可用于“排除 U 以下某类网络”的较弱结论）。
