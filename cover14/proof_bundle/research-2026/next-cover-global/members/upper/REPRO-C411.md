## 4. 候选集完备性审读（承重部分）

`f(p)=min_i|p−c_i|` 在闭单位盘上取到最大，设 p* 为极大点，A(p*) 为活跃集（活跃即等距，这是定义）：

1. **p* ∈ int D，|A| ≥ 2**：若 |A| = 2，必要条件 `0 ∈ conv{∇d_i}` 强制 `p*` 落在两心中点，
   而在中点处 f 沿**垂直中线方向**按 `sqrt(d²+t²)` 增大（另两心在邻域内仍更远）⇒ **不是局部极大**。
   故 |A| ≥ 3，三活跃心非共线（共线时不可能同时等距三点），p* = 三心外心 ✓ 枚举在案。
   （旧核注释只写“至少3个活跃且等距 ⇒ 三盘外心”，**未写** |A|=2 的排除；这一步是完备性的必需环节，此处补上并验证。）
2. **p* ∈ ∂D，|A| ≥ 2**：活跃即等距 ⇒ p* 在一对盘心的中垂线上 ⇒ 枚举中垂线∩∂D ✓（两点都给）。
3. **p* ∈ ∂D，|A| = 1**：f 在圆周上的局部极大 ⇒ p* 是该心在圆周上的最远点 = 对径点 ✓。
4. origin 作为候选（构造器补齐用；见下面的退化审读）✓。

**「盘心恰在原点」的退化子情形：先前版本的"缺口"断言已撤销（lead 指正后审读修复并实测）。**
设 `c_0 = 0`：`f ≤ 1` 于 D；在 ∂D 上 `d_0(p) = |p| = 1`，故 `c_0` 恰在 `f(p)=1` 处活跃。
令 `P = {p ∈ ∂D : g(p) ≥ 1}`（`g` = 其余盘心的最近距离，P 闭），`P` 上处处 `f = 1 = R`：
* **P = 整圆周** ⇒ 代表点 `(1,0) ∈ P` 本身取到 `R` ✓；
* **P 为真闭弧** ⇒ 端点处 `g = 1` 精确成立 ⇒ 该端点 `c_0` 与某其他盘心都活跃且等距 1 ⇒ 端点在"0 与该心的中垂线 ∩ ∂D"上
  ⇒ **被 pair 候选捕获** ✓；
* **P = ∅** ⇒ 边界极大点上 `c_0` 非单活跃；"唯一非原点盘心在 ∂D 单活跃"要求该心对径（距离 `1+|c_i| ≥ 1 > f`，矛盾）
  ⇒ 一切极大点活跃数 ≥ 2（内部→外心、边界→中垂线）⇒ 均在候选集内 ✓。
实测（`py/repro_c411_independent.py` 第 3 层三例：仅原点 / 原点+(3/2,0) 真弧 / 原点+(2,0) 整圆）：候选集极大值均 `= 1`，**PASS**。
⇒ 该退化**不构成缺口**，"候选集可能不完备"的断言不再成立；§0 表与 §7 已同步。

## 5. 精确字面对象与输出审读（本次最实际的发现）

     而证书余量 `T − R(C)` 只有 **1.648e-17** ⇒ **余量小于数据自身的 float64 表示误差**。
   ⇒ 下游任何重算/复核必须用 `th`（或显式保存的精确有理数），**不得**用 `centers` 字段。
3. **阈值口径（已按 lead 意见修正其用途）**：`R(C) = sqrt(q0)` 是**该有限字面有理构型自身的实际覆盖半径**，

   **不是**理想最优的精确根，且很可能**比 exact optimum 微大**（最优点 ≤ 本构型的 R）。
   因此：**非锐分支的排除阈值继续用 `U`**；**尖锐 k10 不能用 `sqrt(q0)` 当靶子**，必须另行隔离优化方程的根（见 §7）。
   另外不要用 `R_float_recheck`：它比真值高 3.648e-17，是 C412 判死的那个 float64 产物（与 C412 陈述吻合）。
4. **输出面**：旧件 `c407_lead_result.txt` 的措辞 `R(C) enclosure = [x, x]` 易被误读为“区间宽度为 0”；
