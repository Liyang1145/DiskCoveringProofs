# n=26 精确全局最优性复验（2026-11-12）

对单位闭圆盘的 26 盘覆盖，最小共同半径为
$r_D(26)=\rho=0.234700090400448239616790133776692\ldots$。
精确值是[独立证明第 6 节](https://github.com/nannnannan/DiskCoveringProofs/blob/9414602a6a8bbb743b7000b938556ec28a4cf4f9/external-submissions/2026-11-09-n26-offline-proof/n26/proof.md#6-一个精确的代数覆盖半径)
中 $F=F_d=F_h=0$ 的隔离根的半径坐标。

## 证明来源和维护者复算

- 独立的精确计算证明由 nannnannan 提交在 [PR #6](https://github.com/Liyang1145/DiskCoveringProofs/pull/6)，固定提交
  为 `9414602a6a8bbb743b7000b938556ec28a4cf4f9`。正文同时给出达到构型和任意圆心摆法的全局下界。
- 11 月 11 至 12 日，维护者恢复了固定提交的分片和 45 个证书文件，并复算了覆盖、解析和拓扑分支。
  两个 25 盘分支以及 26 盘的 14、15、16、17 弧分支通过。16 弧无外弦分支只剩四个同构填法，
  候选角域证书的 1,751 个排除叶和 4 个局部叶全部通过，开放叶为 0。
- 通过接触恒等式、驻点方程和有理区间计算，独立证明的三变量隔离根映入
  [本机 26 元多项式系统](continuations/2026-11-08-terra/workspace/round-20261107b/PROOF.md)
  的隔离盒。根的唯一性将外来证明的下界和本机同根覆盖接在同一个精确半径上。
  [复算状态 JSON](REPLAY-20261112.json)记录各检查的通过标志与哈希，逐支原始日志由维护者保留。

## 如何复算

固定提交中的[说明](https://github.com/nannnannan/DiskCoveringProofs/blob/9414602a6a8bbb743b7000b938556ec28a4cf4f9/external-submissions/2026-11-09-n26-offline-proof/n26/README.md)列出完整入口。进入其
`external-submissions/2026-11-09-n26-offline-proof/n26` 目录后运行：

```sh
python restore_certificates.py
python check_global.py
```

需要 Python 和支持 C++17 的 `g++`。证书分片、源代码与
[提交者复算记录](https://github.com/nannnannan/DiskCoveringProofs/blob/9414602a6a8bbb743b7000b938556ec28a4cf4f9/external-submissions/2026-11-09-n26-offline-proof/replay/n26.txt)均可从固定提交取得。

原生几何与算术路线仍有 16 个候选根、4,957 条条件前缀和 344 个开放子域。
这些计数描述各自路线的历史进度。上面的全局最优性来自经复验的独立证明。
