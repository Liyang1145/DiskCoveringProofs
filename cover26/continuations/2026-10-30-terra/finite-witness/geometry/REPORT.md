# 半径 9/40 的有限点下界：一次数值探索及严格反证

## 结果

一个 241 点、五圈加中心的样本**不能证明 26 盘不够**：已找到并精确验证 23 个半径 9/40 的闭盘覆盖这些点。`verify_finite_cover.py` 只用 Python 整数及单平方根符号比较，重新计算 `finite_cover_23.json` 内每个候选圆心实际覆盖的点，且全部 241 个样本点都位于单位闭盘内。23 个盘不必覆盖样本点以外的位置，故这不提供单位盘的上界，也不证明该样本的精确最优值等于 23。

五圈点数分别为 80、64、48、32、16，加原点；单位圆圈内缩 10⁻⁶，各圆心坐标取六位十进制定点值。点位置由浮点三角函数产生，随后把这些十进制值作为精确有理数，整数比较检查所有点均在单位闭盘内；候选提出不作为证明。数据见 `five_ring_exact.json`。

数值阶段 241 点对应的离散覆盖 LP 值约为 21.4444，整数求解器返回 23（双界同为 23）；该求解器使用浮点且不作为精确最优性证明。更强的严格事实是：`finite_cover_23.json` 保存具体 23 个圆心的有理或单平方根表达，`verify_finite_cover.py` 独立验证了它们确实覆盖全部点。由此本实例不可能给出大于 23 的有限点覆盖下界。按后续指示，另测试了一次更密错列格；结果及超时状态见 `dense/REPORT.md`。

## 任意圆心的有限 mask 枚举

对有限样本 W，如果一个半径 r 的圆盘覆盖一个非空子集 S，那么可行圆心属于点集 S 所对应的闭半径 r 圆盘之交。若 S 是单点，可以采用该点自身为圆心。若 S 至少含两个不同点，该圆盘交为非空紧凸集，并存在两条不同约束圆周的交点：若交只有一个点，它至少落在两条边界上；若交有内部而边界没有任何两约束圆周交点，其整条边界必须来自单一约束圆盘，但不同圆心的相等半径圆盘不能包含彼此，矛盾。该边界交点作为圆心仍覆盖 S，可能覆盖额外样本点。

因此，枚举所有单点圆心以及两点间距不超过 2r 的两个半径 r 圆周交点，并求其样本覆盖 mask，随后删除被其他 mask 包含者，可覆盖任意实圆心的所有可行 mask。相切及覆盖边界上的等号均保留。`exact_masks.py` 使用统一坐标分母 10⁶、r=225000/10⁶，对 4040 对候选样本点进行整数与单平方根的精确符号比较，得到 4545 个不同的覆盖 mask 和 913 个极大 mask。JSON 的第 i 位对应第 i 个点，每个 mask 的 `mask_witnesses` 记录该 mask 的一个精确圆心描述。

单平方根判断没有用浮点阈值：对 A+B√D 的符号，在 A、B 同号时直接判断；异号时比较 A² 与 B²D，等式时保留零。数据中两点圆周交点的圆心为中点加减垂直向量乘一个非负平方根；脚本直接整数化上述判定。所有 mask 支配关系为位集合精确包含关系。该枚举程序与单独的23盘覆盖验收程序使用相同显式点集，但后者对选出的23个圆心重新逐点计算，不依赖整数优化器对可行性的浮点判断。

执行：

    python exact_masks.py
    python verify_finite_cover.py

数值探索及求解脚本 `explore.py`、`solve_sample.py` 依赖 NumPy/SciPy；它们不参与严格23盘覆盖结论的验收。所有工作仅涉及该有限样本，没有排除其他点集、其他证书或半径 9/40 的单位盘覆盖。
