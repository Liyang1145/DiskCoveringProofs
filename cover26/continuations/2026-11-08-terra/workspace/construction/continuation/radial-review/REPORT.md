# n=26 的新严格下界：独立有理数验收

## 结论

26 个半径为 2/9 的闭圆盘不能覆盖单位闭盘。因此，允许圆心在整个平面的定义满足

    r_D(26) > 2/9 = 0.222222... .

该结论独立于任何原 n26 候选根/杆系统。结合已有构造，现有严格范围为

    2/9 < r_D(26) <= 1/(sqrt(6)+sqrt(3)) < 0.239146312.

这不证明全局最优值。

## 带权圆周弧长的必要条件

令 r=2/9。选取下列 15 个半径 t 和非负整数权重 w（权重不需要归一化）：

| t | w |
|---|---:|
| 23/100 | 23488 |
| 19/75 | 19949 |
| 83/300 | 25455 |
| 3/10 | 18639 |
| 97/300 | 11565 |
| 26/75 | 9087 |
| 37/100 | 440 |
| 59/100 | 104502 |
| 37/60 | 59049 |
| 193/300 | 43611 |
| 67/100 | 33041 |
| 209/300 | 22845 |
| 217/300 | 19185 |
| 3/4 | 640 |
| 1 | 446238 |

总权重 W=837734。若单位盘被 26 个半径 r 的闭盘覆盖，那么每个半径为 t 的同心圆周也被覆盖。圆周上一个盘贡献的角测度至多 2A_t(d)，其中 d 为其圆心到原点的距离，

    A_t(d) = arccos((t²+d²-r²)/(2td))  若 |t-r| < d < t+r，
             0                            其他情况。

这里所有 t>r，圆心位于原点时无贡献，内外切线时交集是单点、角测度为零，也不存在整条圆周被单个覆盖盘覆盖的情况。由角测度次可加性，每个圆周有 ∑_i A_t(d_i)≥π。乘以非负权重并求和，得到必要条件

    π W ≤ 26 sup_{d≥0} ∑_t w_t A_t(d).

脚本完全精确地证明右侧小于 26·100269，而 πW > (333/106)·837734，二者之差至少 1312029/53>0。故上述必要条件不可能成立。

## 全距离域的有理数界

只需考虑 0≤d≤1+r=11/9；其余距离与所有这 15 个圆周都不相交。将 [0,11/9] 均分成 4400 个闭区间，步长 1/3600。对每个 t 和每一闭区间先与 [t-r,t+r] 相交。若相交不足一段，则角测度贡献为 0。否则设

    C_t(d) = (d+(t²-r²)/d)/(2t).

由于 t>r，C 的最小值只可能在两个端点或临界点 d²=t²-r² 取得。端点值为有理数；临界点处 C=sqrt(t²-r²)/t，脚本用整数平方根给出严格安全的有理下界 c。故区间内 arccos C≤arccos c。

脚本再以整数平方根将 y=sqrt(1-c²)/c 向上界住；因为 c>0，arccos c=arctan y。对 y<1/4，使用 y-y³/3+y⁵/5 上界。对 y≥1/4，设 u=(y-1)/(y+1)，利用 arctan y=π/4+arctan u，负 u 取截至七次、正 u 取截至九次的交错级数上界。全程是 Python `Fraction` 和整数平方根比较，不用浮点或 SciPy；圆周、端点和临界点均已覆盖，**不是只在网格点采样**。π 的 333/106 与 355/113 两侧有理界由 Machin 恒等式及交错级数在脚本中独立验证。

运行 `python independent_atan_2_9.py`，验收为 4400 个区间，最大区间编号 2898，精确检查 max score <100269、严格余量 >24700。`independent_atan.py` 使用第一组权重复核较弱半径 11/50。两份脚本均禁用 `python -O` 下的运行。权重由另一研究路线提出；本验收器的 atan 变换、平方根有理界及最终不等式独立于其 cos Taylor 验收器。

最后，任意圆心可投影到单位闭盘而不增大到单位盘内任何点的距离。故可将 26 个圆心限制于紧集 D²⁶。覆盖半径函数 max_{x∈D} min_i |x-c_i| 连续，因而达到最小值。既然半径 2/9 不可行，最小值严格大于 2/9；不能仅凭某个半径不可行而省去这个紧性步骤。
