# 新径向分支下界与半径 9/40 的有限松弛障碍

## 已严格验收的备用下界

任意26个闭盘覆盖单位闭盘的最小半径满足

    r_D(26) > 2243/10000 = 0.2243.

这份证明不依赖另行研究中的 Voronoi 面积路线，也不声称原有 n26 全局证明已完成。所有圆心、重复与退化均允许。

令 r=2243/10000。实际与单位圆周有交的盘数记为 B。边界角长要求 B≥14；所有碰边盘均避开 |x|<1−2r，剩余盘覆盖此内核。由于 r/(1−2r)<sin(π/7)，而 r_D(8)≥sin(π/7)，至少9盘不碰边，所以 B≤17。`verify_2243_reduction.py` 严格有理验算相关正弦下界。小阶界的证明是：若8盘半径<sin(π/7)，边界需要8盘全部碰边，且它们因半径<1/2均无法覆盖原点。

对 B=14,15,16,17，各自使用一组独立非负整数权重与采样同心圆。每一采样圆半径 t 都严格大于 r。对于中心范数 d，令 F(d) 为加权覆盖半角和。将 d 分为 [0,r]、[r,1−r]、[1−r,1+r]；相应的全区间严格有理上界为 M0,M1,M2。含原点盘至少一个，且它不是碰边盘；恰有 B 个盘碰边。任何 d>1+r 的盘对采样圆角长为0。故覆盖必有

    π Σw ≤ M0 + (25−B) max(M0,M1) + B M2.

对四组权重，`radial_2243_verify.py` 逐区间精确验出逆向严格不等式；B14/17 步长1/10000、B15/16 步长1/20000，每个区间覆盖所有实数 d，分组边界均为分割点。上界用余弦式端点与唯一驻点的精确有理界，加 12 次余弦 Taylor 上界验收；浮点 acos 只生成角度候选，不能影响验收。四支严格余量分别为

    B=14: 681928562097/10600000 > 0
    B=15: 6550511327/10600000 > 0
    B=16: 239044957953/53000000 > 0
    B=17: 87087314919/1325000 > 0.

圆心可投影到紧集 D，覆盖半径函数在 D^26 上连续并达到最小值，因此排除 r 的覆盖可推出严格大于 r。针对脚本后续只改变了 B14/17 的步长条件，B15/16 保留其已验收的同一步长和计算；若要进行新平台重放，需重新执行下列四支，不能仅凭摘要。

    python round-20261030b/lower/verify_2243_reduction.py
    python round-20261030b/lower/radial_2243_verify.py 14
    python round-20261030b/lower/radial_2243_verify.py 15
    python round-20261030b/lower/radial_2243_verify.py 16
    python round-20261030b/lower/radial_2243_verify.py 17

当前尚未完成独立第二种角函数验收，报告范围是作者侧精确验收，不把数值优化器输出当作证明。

## 半径 9/40：可核验的有限径向松弛障碍

`radial_relax_expanded_B16.json` 提供 26 个按重数计的有理中心范数。`verify_radial_obstacle_expanded_B16.py` 检查 B=16、至少一盘含原点，核心盘数8档、外圈盘数6档、6个内圆正弧盘数及两内圆共同盘数量。对21个指定同心圆，程序用余弦 Taylor **下界**验证每个盘的半角的有理下界，并用 π<355/113 验证半角总和大于π；最小严格余量至少 `775189/113000000`。该检查是有理数计算，浮点仅用于提议角度下界并由精确比较纠正。

这明确说明：上述特定有限个角容量和盘数条件无法排除 B=16。它不是覆盖，也不验证其余同心圆或角位置之间的耦合；不得把该径向数据声称为平面构型。B15 加强整数模型20–25秒内没有 incumbent，属于超时未决，不构成不可行证明。所有原 n26 16/4957/344 的几何/算术义务保持不变。
