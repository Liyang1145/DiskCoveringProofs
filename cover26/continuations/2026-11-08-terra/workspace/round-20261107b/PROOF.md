# 一个精确隔离的 26 盘候选及同根覆盖

日期：2026-11-07，Asia/Shanghai。本轮对应用户建立的持续证明目标。

本补篇从本地已验证的 MinMax Arena 小数构型独立重建一个整系数多项式
系统，证明它在给定有理盒内有唯一实根，并证明同一根给出的 26 盘覆盖
单位闭圆盘。令该根的半径坐标为 rho，则

    0.229 < r_D(26) <= rho,
    rho < 0.234700090400448239616790133776693.

其数值位置为

    rho = 0.23470009040044823961679013377669212756049596365497139178592406...

省略号仅为显示；rho 的精确定义是下面的多项式系统及有理隔离盒。
这不是匹配下界、局部最优性或全局最优性证明。没有假设任意最优覆盖
具有这里使用的反射对称性；对称性只用于构造这一个可行上界。

## 1. 坐标与多项式系统

取 14 个几何未知量

    X=(x0,x1,y1,x2,y2,x3,y3,y4,p,q,s,t,v,r).

前 8 个外圈圆心依次为

    C0=(x0,0), C1=(x1,y1), C2=(x2,y2), C3=(x3,y3),
    C4=(0,y4), C5=(-x3,y3), C6=(-x2,y2), C7=(-x1,y1).

C_(i+8)=-C_i，0<=i<8。其余圆心为

    C16=(p,0), C17=(-p,0), C18=(q,0), C19=(s,t), C20=(0,v),
    C21=(-s,t), C22=(-q,0), C23=(-s,-t), C24=(0,-v), C25=(s,-t).

对三点 A,B,C，记

    T(A,B,C)=4 r^2 cross(B-A,C-A)^2
                -|B-A|^2 |C-B|^2 |A-C|^2.

在三点不共线时，T=0 当且仅当其外接圆半径为正 r。

对两点 A,B，令 h_A=1+|A|^2-r^2，h_B=1+|B|^2-r^2，并记

    n(A,B)=(h_A B_y-h_B A_y, A_x h_B-B_x h_A),
    d(A,B)=2 cross(A,B),
    Bdy(A,B)=|n(A,B)|^2-d(A,B)^2.

d 非零且 Bdy=0 时，Q=n/d 位于单位圆上，并且
|Q-A|=|Q-B|=r。这由 2A dot n=h_A d、2B dot n=h_B d 直接展开得到。

按下列顺序定义 G0,...,G11：前 8 个是 T(C_i,C_j,C_k)，三点编号为

    (16,18,19), (16,19,20), (1,2,19), (16,17,20),
    (3,4,20), (3,19,20), (0,1,18), (1,18,19).

后 4 个是 Bdy(C_i,C_(i+1))，i=0,1,2,3。它们均为整系数多项式。

再引入 12 个实未知量 lambda0,...,lambda11。完整 26 元系统 F=0 为

    Gk(X)=0,                               k=0,...,11;
    sum_k lambda_k partial_i Gk(X)=0,       i=0,...,12;
    sum_k lambda_k partial_r Gk(X)=1.

这些驻点方程只用于选择一个孤立的代数候选。不要求乘子符号，不据此
声称最小值或证明任何优化的充分条件。`exact_model.py` 用标准库的稀疏
整系数多项式运算重建 F；`candidate_model.py` 则用于可选的数值提议。

## 2. 精确有理根盒与存在唯一性

`root-proposal.json` 的 `center` 是 26 个有理数 c：其中每个十进制字符串
均按精确有理数解释。每一坐标的半宽都为 epsilon=10^-75。定义闭盒

    X_box = {z: |z_i-c_i|<=epsilon for all i}.

同文件给出有理矩阵 Y，作为 Jacobian 逆的提议。验证器不信任提议器
或其浮点计算，而是独立重建整系数 F 和全部精确偏导，检查

    eta=||Y F(c)||_infinity < 10^-95,
    theta=sup_(z in X_box) ||Id-Y F'(z)||_infinity < 10^-60,
    eta+theta epsilon < epsilon.

矩阵范数用最大行绝对值和。所有端点以整数/10^115 表示，每次乘除
向外取整。中心输入和 Y 的有理值亦完整包含在区间中；导数对整个闭盒
验算，中心单点残差不替代导数域。

映射 H(z)=z-YF(z) 以常数 theta<1 在 X_box 上压缩，且由最后一个
不等式将闭盒严格映入自身。Banach 不动点定理给出唯一不动点。
||Id-YF'(c)||<1 还说明 YF'(c) 可逆，故 Y 可逆，不动点恰为 F 的零点。
因此该闭盒存在唯一实零点，其 r 坐标 rho 是本补篇精确指定的候选。
其他坐标也都是同一个唯一根的坐标，没有将不同近似值拼成构型。

根盒的 r 投影严格位于

    0.234700090400448239616790133776692127560495963654971391785924
    < rho <
    0.234700090400448239616790133776692127560495963654971391785925.

这个数值区间与旧 README 相符，但这里未取得旧 SYSTEM/ROOT-CERTIFICATE
原字节，未证明两套代数定义的根完全相同。新证书使用新的独立定义，不
重标原来的候选根、正式分支或算术支撑账本。

## 3. 同根的接触等式与严格余量

对每个相邻外圈圆心，令

    Q_i=n(C_i,C_(i+1))/d(C_i,C_(i+1)),        i mod 16.

验证器以整系数多项式恒等比较，证明全部 16 个 Bdy 多项式分别等于
G8,...,G11 中的一个，且精确展开验证前述两个线性恒等式。区间检查
分母严格为正。因此在所隔离的根上，Q_i 是单位圆上的精确点，且严格
等式 |Q_i-C_i|=|Q_i-C_(i+1)|=rho 成立。

不能用包含零的距离差区间直接“验过”这些等式。本轮用多项式方程给出
等式，用区间只验不等式和非零分母。

`topology.json` 列出 34 个中心三角形，沿用已验证有理构型的编号。
对其中 30 个，验证器逐一展开外接半径多项式 T，证明其与 G0,...,G7
之一完全一致。三角形行列式严格非零，故它们在该根上的外接半径均
精确等于 rho。其余 4 个

    (2,3,19), (5,6,21), (10,11,23), (13,14,25)

的外接半径以全盒区间严格验得小于 0.232<rho。所有外心也严格位于
单位圆盘内。故每个中心三角形的三个 rho 盘都有一个共同点。

## 4. 由有向链与圆弓证明覆盖

公共点引理：若同半径 R 的盘以 A_j 为心并共有点 W，则这些盘的并
包含各圆心的凸包。对凸组合 Z=sum mu_j A_j，方差恒等式给

    sum mu_j |Z-A_j|^2
      =sum mu_j |W-A_j|^2-|Z-W|^2 <= R^2.

至少一个距离至多 R。因此全部 34 个中心三角形都被相应三盘覆盖。

三角形 conv(Q_i,C_i,C_(i+1)) 被这两盘覆盖：公共点引理先覆盖圆心
线段，每个线段点属于某一盘；该盘也含 Q_i，凸性覆盖到 Q_i 的整条
线段。另一个三角形 conv(Q_(i-1),Q_i,C_i) 的三个顶点都在盘 i 中，
也由凸性得到覆盖。

这构成 42 个顶点、107 条边、66 个抽象有向三角形的链。检查器重新
计算一致的抽象定向，逐边验证：每个内部边恰出现两次且方向相反，
唯一边界为 Q0,Q1,...,Q15 的正向环。不能用各三角形图像的几何方向
替代抽象定向；几何翻折及退化三角形都允许。尤其不能沿用旧有理版
验证器中所有图像面积非零的要求，本精确候选允许所有者面塌为线段。

闭盒区间检查 Q0..Q3 位于第一象限，接着每四点依次处于第二、第三、
第四象限；每对相邻锚点的 cross 和 dot 都严格正。因此锚点正向绕行
恰一圈，形成单位圆上的简单凸多边形，相邻圆弧角度在 (0,pi/2)。

对不在任何三角形边上的多边形内点，内边抵消使三角形像绕数之和
等于边界绕数 1，故该点至少位于一个三角形像内。有限个闭三角形像
的并闭，取极限覆盖整个闭多边形。几何翻折、重叠和退化不影响此论证。

区间还检查每个 C_i 的方向严格位于 Q_(i-1) 与 Q_i 的短圆弧方向间。
该弧上到 C_i 的距离最大值在两个端点，二者均精确为 rho。圆盘的
凸性遂包含该弧及其闭圆弓。16 个闭圆弓与锚点多边形的并恰为单位
闭圆盘，得到同一半径 rho 的完整覆盖。

## 5. 重放、拒绝控制与未完成工作

在本目录运行 `python replay.py`。根与覆盖验收仅用 Python 标准库，
不调用 SymPy、SciPy、NumPy 或 mpmath。这些库仅供重新生成提议时使用。
运行记录、进程退出码和输入 SHA256 保存在 `REPLAY.json`。

`verify_root.py --negative-control` 将盒中心的半径增加 10^-12 而保留
原半宽和 Y，必须因不能映入自身而拒绝。

`verify_cover.py --negative-control` 保留同一组代数圆心，把半径缩为
rho-10^-40。它使用中心面 (0,1,18) 的精确外心作为目标盘内见证，
严格区间检查其到全部 26 个圆心的距离均大于缩小半径。这验证本构型
在其精确紧接触处不能直接缩半径，不证明其他圆心布局不能更好。

本轮没有证明 rho 以下任意覆盖不可能。0.229 的全局下界仍由前一补篇
提供；0.23 及候选处的匹配下界都未完成。原生 16 根、4957 条件前缀、
344 算术 OPEN 子域未支付，缺失的旧来源闭包也没有被新系统替代。
