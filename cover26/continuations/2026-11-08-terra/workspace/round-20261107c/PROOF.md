# 三角形全角域的凸面积损失引理

日期：2026-11-07，Asia/Shanghai。此补篇证明可供下界继续使用的几何引理，
不声称新的 n=26 全局半径下界。当前范围仍为前两轮的
`0.229 < r_D(26) <= rho`。

## 引理

定义凸函数

    H_h(x)=x^2,                      |x|<=h;
    H_h(x)=2h|x|-h^2,                |x|>=h.

任意非退化三角形的角度为 alpha,beta,gamma，外接圆半径不超过 R 时，

    area <= R^2 [3sqrt(3)/4
             -(4/5) sum_(theta=alpha,beta,gamma) H_(1/5)(theta-pi/3)].

所有角度均用弧度。这是对整个三角形角度域的结论，包含任意钝角情形；
没有用对称三角形的数值优化代替全域验算。

## 1. 减少到两个闭参数

置 d=pi/3，A=3sqrt(3)/4，delta_i=theta_i-d。若实际外接半径为 R_T，
正弦定理与面积公式给

    area/R^2=2(R_T/R)^2 sin(alpha)sin(beta)sin(gamma)
              <=2sin(alpha)sin(beta)sin(gamma).

利用角和为 pi，可将右边与 A 的差精确写为 sum b(delta_i)，其中

    b(delta)=(sqrt(3)/4)(1-cos(2delta))+(sin(2delta)-2delta)/4.

因此只需证明 sum [b(delta_i)-(4/5)H_(1/5)(delta_i)]>=0。

由对称性取 alpha<=beta<=gamma。它们恰由

    delta_alpha=-w,
    delta_beta=w(3u/2-1),
    delta_gamma=w(2-3u/2),
    0<=w<=pi/3,  0<=u<=1

表示。w=0 是等边情形；其他情况下由给定三角形直接求得 u。
检查器写 w=(pi/3)v，对整个闭方形 (v,u) in [0,1]^2 作二分。

## 2. 等边附近的解析接受域

令 eta=3/50=0.06，mu=31/50。若 2w<=eta，则每个 |delta_i|<=eta。
检查器严格验证

    (31/25) sin(pi/3+eta)^2 < 1,
    eta < pi/6.

由于正弦在该正区间单调递增，(log sin theta)''=-csc(theta)^2
<=-31/25。在 d 处作二阶凹函数界，并利用 sum delta_i=0，得

    2sin(alpha)sin(beta)sin(gamma) <= A exp(-mu s),
    s=sum delta_i^2 <=3eta^2.

对 x>=0，exp(-x)<=1-x+x^2/2。因此面积损失至少

    A mu (1-mu (3eta^2)/2) s.

纯有理区间检查该系数严格大于 4/5。因为 eta<1/5，H(delta_i)=delta_i^2，
引理在该整个域成立，包括等边点的等号情形。这里使用解析域，避免把
等号附近的采样或区间分辨率当成证明。

## 3. 其余闭域的严格有理验算

JavaScript 检查器用分母 10^24 的 BigInt 向外区间。计算 b(delta) 时
将 1-cos(x) 的 x^2/2 主项以及 sin(x) 的 x 主项解析消去。在 H 的
二次分支还先合并二次系数 sqrt(3)/2-4/5，以降低区间抵消误差。
H 在 -1/5、1/5 处分段；一个输入区间跨越折点时，全部相交子段均
验算并取包围，不丢掉任何子域。

正弦/余弦尾和分别取到 x^41、x^40，对 |x|<=5 使用绝对误差
5^43/43!、5^42/42!。这是已进入绝对递减段的交错级数尾界，允许
x 为负。本参数域实际有 |2delta|<=4pi/3<5，程序也检查尾界域。

每个二维盒要么整体落在解析域，要么区间严格证明上述差为正；未通过
则沿较长坐标轴二分并保留两个闭子盒。共处理 18591 个节点，输出
9296 个叶子：32 个解析叶子和 9264 个严格区间叶子。区间叶子的
最小接受余量下界为

    107321285690421446/10^24 > 0.

Python 独立检查不信任报告中的通过标志。它先从根方形重建整个二分
树，检查每个叶子恰覆盖自己的闭域，确保没有域缺失、重叠子树或多余
叶子。再以分母 10^115 的有理区间、独立 Machin 包围及 48/49 次
多项式 Horner 求值，重新接受每个叶子。本次没有额外细分也全部通过。

## 4. 拒绝控制与应用边界

将系数 4/5 擅自增为 9/10，结论是假的。检查器以
alpha=d-0.01、beta=d、gamma=d+0.01 作严格反例：它们的形状面积
损失为 (sqrt(3)/2)(1-cos(0.02))，严格小于 (9/10)*2*(0.01)^2。
这不是一次普通浮点比较。

运行 `python replay.py` 复跑两套验算及该反例控制；输入 SHA256 和
完整输出保存在 `REPLAY.json`。
