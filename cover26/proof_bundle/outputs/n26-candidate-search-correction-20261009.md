# n=26 候选搜索修正记录（2026-10-09）

本轮从归档的 n=25 精确 Q(√2) 构造出发，尝试加入第 26 个圆心并允许
全部 26 个圆心做局部移动。所有数值结果均不是证明。

## 发现的假候选

仅用 204,000 个规则采样点做活动点优化时，得到采样半径约
`0.2385475159`；加入 n=25 的 16 个精确边界锚点后，规则网格审计曾给出
约 `0.2387094742`。这两个数都低于

`r25 = 0.239146311738100268223279244400006341674380742282096500125628...`

但不能直接接受，因为规则径向网格可能漏掉 Voronoi 内部顶点。

## Voronoi/边界几何审计

对 26 个浮点圆心枚举了：

- 所有圆心三元组的非退化外心（落在单位盘内）；
- 所有圆心二等分线与单位圆的交点；
- 每个圆心在单位圆上的圆周驻点；
- 原点。

对初始“低于基准”的构型，2,412 个几何候选点中的最大最近距离为
`0.2395023249505734`，最坏点约为
`(-0.53386690526668, -0.22113491266361)`。这直接否定了
`0.238709...` 作为连续覆盖候选。

把这些几何候选点并入活动集后重新优化，规则样本值收敛到
`0.2392611459851734`；再次做 Voronoi/边界审计，2,839 个候选点的最大最近
距离为 `0.23939354625010598`，最坏点约为
`(0.09140284708307, 0.22125729260594)`。

## 当前结论

这条“n=25 构造 + 一个额外圆心 + 局部移动”的路线目前没有得到低于
n=25 基准的可信 n=26 候选。它提供了一个重要的负面约束：后续优化必须
显式纳入 Voronoi 内部顶点，不能只依赖规则角度/半径采样。
