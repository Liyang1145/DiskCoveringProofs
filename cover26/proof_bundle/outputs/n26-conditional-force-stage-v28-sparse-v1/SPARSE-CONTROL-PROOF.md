# Empty event categories do not remove mathematical gates

Some valid conditional enumeration stages contain no new FORCE_TREE events.
The old checker's negative-control selection assumed at least one such event
and crashed. The failed bundle is preserved. Historical sealed checkers are
unchanged.

The separately named sparse acceptance checker calls the identical original
input gate, exact stage replay, native agreement checks, complete sibling and
closed-boundary reconstruction, strict force/area formulas and 32 feasible
regular-ring controls. Seven original non-angular rejection controls are retained.
No radius, source, graph, tolerance or geometric predicate is weakened.

For the two angular rejection controls, a genuine recorded SPLIT/FORCE tree is
chosen from the current trace when available, otherwise from an actually accepted
conditional ancestor. The ancestry is checked for cycles, each accepted source
is byte-bound, the original trace/event and exact spec are reconstructed, and the
sealed fixture must match that reconstruction. Its positive angular tree is
independently replayed with the unchanged arithmetic before corrupting a closed
half and appending a hidden node. Both corruptions must be rejected.

An ancestor control is only a regression fixture. It pays zero new leaves,
zero current trees and zero transport subtrees; its nodes never enter the new
stage's geometry ledger or event counts. All nine rejection controls remain.

The new acceptance report identifies its own executed checker and hash, separately
from the unchanged original semantic replayer and hash. Both files are sealed.
Fresh native events, independent sparse acceptance, actual publication replay,
native catalogue, latest complete current-chain composition and independent final
binding are still required. No global optimality or completeness is inferred.
