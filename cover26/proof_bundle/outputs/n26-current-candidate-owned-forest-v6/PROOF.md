# Actual current roots and newest accepted per-root forest ownership

This extension uses the original 92 positive rods, exact grounded kernel,
16-anchor frame, same exact root Rstar and original 52-coordinate LOCAL barrier.
It creates no new graph family or coordinate tolerance.

The matching current source loader first semantically folds the actually accepted
candidate layer and all previous payments, with current audit, independent final
digest recheck, actual acceptance and actual published replay. The actual current
whole-root rows are the only legal root ownership records.

Accepted post-curvature forest history is walked through its bound manifests.
For each still-current root, the newest accepted forest for that original root
index is selected, including one from an older layer that dealt with a different
root. Full root dictionaries must agree. An already discharged root cannot be
reopened. Duplicate ownership, altered classifications and cycles are rejected.

A root with no accepted post-curvature forest may begin with one OPEN node on its
entire actual current closed box. This is an explicit unproved structural seed,
not a geometric payment. Original earlier angle-tree payments lie outside this
retained OPEN root and remain bound. A previously attempted root must continue
its newest accepted forest. Every old non-OPEN node and all closed split boundaries
are retained identically; only OPEN leaves and their descendants may change.

The unchanged exact forest replayer reconstructs the full root, all closed halves,
every shared midpoint, every ENERGY/LOCAL/EMPTY proof and every OPEN leaf. Independent
BFS contraction must give the same leaf domains as exact DFS. Numerical stationary
references and curvature optimizers merely propose certificates.

ENERGY requires a strictly positive original-graph closed-box energy/radius margin.
LOCAL requires strict entry into the original 7/800000 barrier and proves radius
at least the same root; equality-feasible LOCAL regions are not declared empty.
A root is discharged only if every leaf is proved. A partial forest retains the
whole original root unchanged. No earlier whole root or regional proof is repaid.

Standalone acceptance, actual publication replay, complete current ancestry join
and independent final byte binding remain distinct obligations. This layer removes
no combinatorial transport subtree and proves no unrestricted global optimum.
