# Accepted-seed candidate ENERGY/LOCAL forest extension

The source is the actual 27-root candidate list after the accepted seven-root
continuation, not the historical lists of 34 or 37 roots. The complete current
audit, its independent final digest recheck, the actual forest acceptance,
actual published replay and the original radius/frame are required. The fresh
source loader semantically folds the accepted continuation using its own gate
and derivation; it does not pass that continuation to the older base-forest gate.

For each selected current root, the accepted seed is read from the actually
bound source proposal. The full current closed root and original ownership
index must match. The original exact forest replayer rechecks the seed and
matches the actual accepted source classification. Every old non-OPEN node
must remain identical at its original index. In particular, no old ENERGY
certificate, LOCAL leaf, EMPTY leaf, closed split or shared midpoint is changed.
Only an old OPEN leaf may become a new closed leaf or a new closed-half split.

The complete extended tree is replayed from the same original full root by the
unchanged exact DFS, with independent BFS contraction and leaf-domain comparison.
Each new split includes both closed halves and their common midpoint. Every node
must be reachable exactly once. Every ENERGY leaf requires the unchanged original
92-rod grounded kernel, exact inverse/Schur identity, feasible rational reference,
full closed-box Hessian bound, nonnegative curvature allowance, exact positive LDL
and full reconstruction, charged rounding error and nonnegative difference dual.
No numerical stationary energy, eigenvalue or optimization success flag pays a leaf.

LOCAL uses the original 52-coordinate barrier and strict 7/800000 entry allowance.
It proves a radius lower bound at the same exact root; it does not declare equality
feasible regions empty. All original root-local positive controls remain required.

A full current root can be discharged only when no OPEN leaf remains. Otherwise,
the whole original root remains in the actual pending list, with its original
closed bounds. All unattempted roots and shared boundaries are retained. Earlier
Dirichlet, curvature and complete-forest whole-root payments cannot be repaid.

The current audit may join a proof-time parent only if that parent and all its
dependencies are identically bound in the actual latest current chain, the actual
incoming candidate rows are unchanged, and the root radius/frame remain identical.
This layer removes no combinatorial transport subtree. Arbitrary-cover reduction,
complete enumeration and final global acceptance are still separate obligations.
Neither a proposal nor an accepted partial forest proves global optimality.
