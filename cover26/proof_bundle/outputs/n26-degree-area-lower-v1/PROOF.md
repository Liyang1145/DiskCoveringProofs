# n=26：Voronoi 度数—边界弦长的严格面积排除

本证书只排除指定的**实际覆盖归约类型**。它不是整个 n=26 的下界，
也不声称每个被排除图的任意弱杆实现均不可能。完整目录尚未穷尽。
机器检查执行整数／Fraction／有理三角函数区间运算；
连续几何依据是下述书面引理，不声称 Lean 形式化或外部独立审稿。

## 1. 运输前提与补标签

使用本阶 U=234701/1000000。任意半径 r<R* 的反例可选
r<rho<R*<U，投影并作带严格余量的一般位置扰动，再删掉冗余盘，
形成 m≤26 个一般位置不可约 Voronoi 裁剪胞腔 C_i=V_i∩D。
各中心在 D 内、属于自己的胞腔内部，并且 C_i 位于所属 rho 盘内。

圆周所有权不返回的证明需要不可约性：若某胞腔在同一短足迹内返回，
取两个严格所有点 a,b 及其间另一胞腔 T 的所有点 x。
弦 [a,b] 上严格属于前一胞腔。若 T 的裁剪胞腔越出该弦和短弧围成的
圆弓，凸性使其穿过弦，矛盾。因此 T 全在圆弓内；圆弓被前一圆盘覆盖，
又与 T 的私有点矛盾。所以边界胞腔按一个简单循环排列。

裁剪 Voronoi 胞腔与外胞腔组成球面胞腔分解。一般位置使每个顶点恰有
三胞腔相接；凸性和不返回使两胞腔至多共享一条边。
取对偶并删掉外顶点开星，得到简单三角盘。
其边界为 B 个不同所有权胞腔，每个中心面有一个共同 rho 见证，
相邻边界中心有单位圆交接锚点。

本阶预算给 B≥14；边界圆盘避开 |x|<1−2rho，缩放后内部盘半径
小于 U/(1−2U)<443/1000。明确采用已登记的 Fejes Tóth 八盘半径定理，
故原始内部胞腔至少九个，B≤17。该外部定理本证书不重证。

若 m<26，在中心面星形补点，几何中心复制该面旧中心。
旧标签图度数只增加，边界 B 不变。新标签没有自己的原始 Voronoi 胞腔；
给它分配面积 0。下文对旧胞腔使用**补点后的较大度数**，
等价于在多边形边上加入重复顶点／零扇角。Jensen 上界仍然有效。
因此本面积下界适用于目标枚举中的星形补标签图，不偷换成“26 个圆心
必须互异且都保持原始 Voronoi 邻接”的额外假设。

## 2. 面积记号

令 t=U²。内部标签度数为 k，边界标签的中心图度数为 d。
原始内部胞腔是至多 k 边、包含所属中心的凸多边形，其顶点距中心≤U。
以中心作扇形，扇角非负、≤pi、和为 2pi。由 sin 在 [0,pi] 上凹，

    area(C_i) ≤ A_k := (t/2) k sin(2pi/k).

对于边界胞腔，把唯一圆周短弧换成弦得到凸多边形 P_i，
它有至多 d+1 个顶点。设所有权角为 delta=2pi*s，0≤s≤C，
C=754112/10^7；所有边界 s_i 之和为 1。
两个锚点的弦长 L=2 sin(pi*s)。圆弓面积为

    cap_i = (delta−sin(delta))/2.

需要 P_i 的面积上界，并不能把整个边界胞腔当成普通直边多边形。

## 3. 边界多边形上界

首先通用上界为

    P_regular(d) = (t/2)(d+1) sin(2pi/(d+1)).

当所属中心 c 位于 P_i 内时，由扇角和 2pi 的 Jensen 不等式立即得到。
若 c 不在 P_i 内，由 c∈C_i 可知它只违反新加的弦半平面，而不违反
其余直边半平面。其余 d 条边相对 c 的有向三角面积非负，极角总转角
Theta≤pi；弦边贡献非正。因此

    area(P_i) ≤ (t/2) d sin(Theta/d) ≤ (t/2) d sin(pi/d).

这是半圆扇形型上界，不大于 P_regular(d)，故通用上界仍成立。
允许插入零扇角处理补标签所增加的度数。

当 L>U 时，若 c∈P_i，弦两端相对 c 的扇角 theta∈[0,pi] 满足

    L² ≤ max(U²,4U² sin²(theta/2)).

理由：对端点半径 r0,r1∈[0,U]，表达式
r0²+r1²−2 r0 r1 cos(theta) 分别对二者凸，最大值在矩形四角取到。
所以 theta≥2 beta，其中 beta=arcsin(sin(pi*s)/U)。
其余 d 个扇角的和为 2pi−theta，于是

    area(P_i) ≤ F_d(theta)
      := (t/2)[sin(theta)+d sin((2pi−theta)/d)].

在 theta≥2pi/(d+1)、theta≤pi 时，F_d 非增：
其导数为 (t/2)[cos(theta)−cos((2pi−theta)/d)]≤0。
故当 beta≥pi/(d+1) 时可用

    P_special(d,s)=(t/2)[sin(2beta)+d sin((2pi−2beta)/d)].

若 c∉P_i，第一个半圆型上界恰为 F_d(pi)，仍不超过 F_d(2beta)，
所以同一个特殊上界适用。若上述两个触发条件不能严格核验，
证书只使用较宽的 P_regular，不作额外几何限制。

## 4. 全盘面积与一维对偶

各原始胞腔分割单位圆盘，圆弓与多边形面积精确相加。
新补标签面积为 0，给它们加上非负 A_k 只会放宽不等式。
消去 sum(delta_i)/2=pi 后，任何真实运输类型都必须满足

    0 ≤ sum_internal A_k
        + sum_boundary [P_d(s_i)−sin(2pi*s_i)/2],
    sum_boundary s_i = 1.

取有理对偶斜率 lambda=−23/4。若对每个 d 和整个 [0,C] 有

    P_d(s)−sin(2pi*s)/2 ≤ a_d+lambda*s,

则必要条件为

    0 ≤ sum_internal A_k + sum_boundary a_d + lambda.

因此右端的严格负有理上界就是该度数类型的严格排除证书。
不需要求真实角隙，也不依赖对偶斜率来自何种数值搜索。

## 5. 连续区间证书的检查

把 [0,C] 完整分为 8192 个有理闭区间，公共端点均包含。
对每个区间 [lo,hi]：

1. 若 sin(pi*lo) 的严格下界大于 U，整个区间不可能是实际角隙。
2. 否则，只有 2 sin(pi*lo)>U 被严格核验时才使用特殊弦长触发。
   beta_lower 来自分母 4·2^24 的有理网格；
   检查 sin(2pi*beta_lower) 的上界≤sin(pi*lo) 的下界/U。
   此处 beta_lower 用“周”为单位。
3. 若 beta_lower≥1/[2(d+1)]，用 F_d(4pi*beta_lower) 的严格上界；
   否则用通用多边形上界。特殊函数在相关角度域非增，
   故左端点导出的上界覆盖整个区间。
4. sin(2pi*s) 在本域递增，而 −lambda*s 递增。
   因而区间上界为

       polygon_upper(lo) − sin_lower(2pi*lo)/2 − lambda*hi.

逐个区间核验该值不超过 a_d，并核验内部 A_k 的上界。
全部系数向上取整到分母 10^12。图度数重新从完整面集合计算，
用有理整数和判断严格负号。其余图一律保留为 unresolved，不以数值
接近零或未被这一种面积法排除来推断可实现性或最优性。

三角函数区间使用已绑定的标准库整数实现：Machin 公式加交错级数
隔离 pi，约化到绝对值小于 1 的区间，再用带显式余项的 Taylor 包络。
无浮点最大值、有限采样通过或浮点优化器参与证书接受。
