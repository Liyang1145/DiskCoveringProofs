# n=26：面积包络与图角约束的有理对偶证书

作用范围和 Voronoi／星形补标签面积引理见 `BASE-PROOF.md`。
本证据包保留并绑定该证明、原始选取目录和原整数三角函数实现。
所有新增接受判断均为整数或 Fraction，不调用浮点 LP 求解器。

## 1. 多个全域支撑线

沿用 t=U²、U=234701/1000000 及边界角隙 s_i（单位为周）。
令 h_d(s)=P_d(s)−sin(2pi*s)/2。对本证书列出的每个有理斜率 lambda_j，
在整个 0≤s≤754112/10^7 上用原 8192 个完整有理区间检查

    h_d(s) ≤ a_(d,j)+lambda_j*s.

每条线都单独是全域上界，所以可同时使用，不是根据未知真实角隙
擅自选一条局部切线。系数均向上取整到分母 10^12。
原来的单斜率上界是其中一条线，但新的证明不依赖它已排除了多少图。

对边界中心 i 引入辅助量 y_i，可设 y_i=h_(d_i)(s_i)，因而必须满足

    y_i−lambda_j*s_i ≤ a_(d_i,j)    对所有 j.

内部胞腔面积和仍由原证书的 A_k 上界。
任何该运输类型的真实覆盖都满足

    0 ≤ sum_internal A_k + sum_boundary y_i.

## 2. 图上的角约束

锚点 q_i 属于中心 i 与 i+1 的盘；s_i 是 q_(i−1) 到 q_i 的正向角隙，
归属于中心 i。故 q_i 到 q_j（i<j）的正向差为
sum_(k=i+1)^j s_k，不是 sum_(k=i)^j s_k。

中心图距离至多 1、2、3 的两锚点端点集合之间，经共同见证可连成
四、六、八杆路径；二杆长度上界 U。对应的最短圆周角帽分别是
1555305、2486507、3880649 除以 10^7。
端点集合重合时使用四杆帽只是放宽。

令 k=j−i，角帽为 c，单隙帽为 c0。若 k*c0<1−c，
正向长弧已被相邻角隙预算排除，故正向窗口角隙和≤c。
若 (B−k)*c0<1−c，则反向窗口和≤c。
两方向均强迫会矛盾；本证书的来源图已经通过旧角筛，不存在该情形。
没有被强迫的长短方向不添加约束。
同时保留 0≤s_i≤c0 和 sum s_i=1。

数值提出器用最短路 BFS 建立这些窗口；精确检查器从完整面集合
重新计算邻接，并用 1／2／3 跳位集闭包独立重建所有窗口。
每张图必须完整匹配它所引用的边界度数／角窗口案例，不能只匹配度数型。

## 3. 有理非负对偶

对所有支撑线、角窗口和上下界不等式赋非负有理权重。
每个 y_i 所属支撑线权重之和被精确要求为 1。加权求和得到

    sum_i y_i + sum_i gamma_i*s_i ≤ H,

其中 H 和 gamma_i 均由有理数重新计算。由 s_i≥0、sum s_i=1，

    sum_i y_i ≤ H−min_i gamma_i.

该式不要求浮点驻点残差为零，也不要求采用浮点等式乘子。
提出器把浮点权重舍入为有理数，再逐个 y_i 归一化；
精确检查器重新验证权重非负、和恰为 1，并重新计算 H、gamma。

每张图的严格排除条件是

    sum_internal A_k + H−min gamma < 0.

最后向上取整到分母 10^12，再检查整数和严格负。
因此舍入只会放宽，不会将未证明的浮点负号变成排除。

## 4. 完备性与非主张

SOURCE.json 和原完整子树目录定义本证书的选取范围。
CASE-CERTIFICATES.json 保存有理权重；
MULTISLOPE-GRAPH-LEDGER.json 对选取范围中每一图给出案例和有理上界。
逐图重新计算度数、图窗口和内部面积，完整检查映射没有遗漏。

本证书只排除已收录运输类型。即使整个选取范围全部排除，
也不代表整个 B14 族或其他族穷尽，因为待办前沿仍存在。
任意覆盖归约的最终联合接受、四族穷尽和全局下界仍保持 pending。
不声称排除所有弱杆实现，也不声称 n=26 已证明最优或可进入 n=27。
