原文的半径记号 R_n 指 n 个单位半径圆盘所能覆盖的目标圆盘的最大半径；
半径结论为 R_n = 1 + 2 cos(2π/(n−1))，n=8,9,10。
因此，通过相似缩放，覆盖单位圆盘的八个等半径圆盘必须满足
q ≥ 1/(1+2 cos(2π/7))。这与当前冻结依赖登记的半径结论一致。

该页随后给出圆心距离的正弦表达式。当前框架仅使用前述半径结论，
不导入该圆心坐标表述或唯一性结论，避免混淆半径与构造坐标。

当前保守筛选阈值 U=234701/1000000 给出精确核心缩放比：

U/(1−2U) = 234701/530598。

与使用的较弱有理下界 443/1000 比较，严格余量为
353914/530598000 = 176957/265299000 > 0。
因此，当某些边界盘避开半径 1−2ρ 的开核心时，
不超过八个剩余等半径盘不能在 ρ<U 的条件下覆盖该核心闭包。
有理下界 443/1000 与外部公式之间的严格比较仍由既有冻结三角区间门核验。
