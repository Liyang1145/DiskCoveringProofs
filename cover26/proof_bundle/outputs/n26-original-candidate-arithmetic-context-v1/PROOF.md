# Fixed original arithmetic resource: independent reconstruction, not geometry

This resource is only the lossless typed projection of the original n26
92-rod candidate model. It is not a current candidate source, a seed forest,
a graph replacement, a new radius bound, or a transport exclusion.

The immutable exporter identified a proof-time accepted source, its actual
published replay, a complete current checkpoint and independent final rehash.
The new frozen verifier calls the unchanged full legacy source gate again:
all original geometry, prior payments, retained roots and source contracts
are independently reconstructed. It does not rely on an exported success flag.

From the resulting actual values, the verifier independently selects the
original cap, reference, 16-anchor matrix, radius and first five original data
objects, the exact original kernel and curvature-source acceptance.
The complete canonical typed encoding must equal the export. Integer, Boolean,
Fraction and finite floating metadata remain distinct; tuple/list identity,
dictionary order and signed zero are retained. Floating metadata is not
promoted to an exact geometric bound. Unknown/executable tags are rejected.
The original kernel, frame and 7/800000 LOCAL allowance cannot be substituted.
The actual original known-feasible tiny-box positive control is rerun and
compared with exact scalar types, not permissive Boolean/integer equality.

Synthetic codec/projection controls are data-only. Additional controls applied
to the actually reconstructed resource reject altered family, vertex frame,
kernel identity, radius, rods, LOCAL allowance, scalar/container types,
dictionary order and positive-control omissions. They earn zero geometry.

Every original producer dependency and every frozen resource dependency is
bound after the full semantic replay. Only duplicate reads of the same final
file are factored; no semantic gate is skipped. The acceptance and a separate
actual publication replay are distinct obligations.

The historical source checkpoint's pending-root count is explicitly not a
current candidate count. No pending rows or per-root seeds are supplied as
current ownership by this resource. Its acceptance removes zero roots,
zero leaves and zero combinatorial subtrees and leaves all global obligations
pending. Even successful resource acceptance is not itself a faster source
interface. Any future lemma-reuse interface requires explicit independent
acceptance of latest-layer identity, all prior proof receipts, newest accepted
per-root forests and unchanged current whole-root rows. A cached status marker
cannot replace that composition.
