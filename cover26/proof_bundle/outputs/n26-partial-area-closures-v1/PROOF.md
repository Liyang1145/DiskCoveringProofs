# B14：覆盖整棵后续子树的面积对偶

本证书沿用已接受多斜率面积包络及其连续几何作用范围。
不是单点求解，也不是当前已枚举图的有限排除。
它对指定前缀下**每一种可能完成的度数分配与角隙**给出上界。

## 1. 保守度数域

根面剥离状态中，已有顶点未来只能和包含它的待补区域中新邻点相连。
若区域边界为 K、内部预算为 J，该区域对已有边界顶点最多贡献
尚未相邻的 K−1 个边界顶点和 J 个新顶点。
对多个待补区域相加即为上界；重复计数只会放宽。
不在任何待补边界的已有顶点不能再增加度数。

尚未引入顶点最终属于某个 J>0 的待补区域，度数最多 K+J−1；
先取全部这类区域的最大值是保守上界。
最终边界／内部顶点度数至少 2／3，且已加入邻接不会减少。
所有度数至多 25。完整简单三角盘总度数为 150−2B。
精确检查器从重建状态独立计算每个顶点的整数允许区间。

## 2. 度数变量的放宽

对顶点 i 和允许度数 d，引入 z_(i,d)≥0，
sum_d z_(i,d)=1，sum_(i,d) d*z_(i,d)=150−2B。
真实完成取其实际度数的指示量，因此该放宽不会丢失真实完成。

边界辅助量 y_i 必须满足每个已接受支撑线

    y_i−lambda_j*s_i−sum_d a_(d,j) z_(i,d) ≤ 0.

另保留部分邻接已经强迫的角窗口、0≤s_i≤cap2/D 以及 sum s_i=1。
原内部面积上界 A_d 进入目标

    O = sum_boundary y_i + sum_internal sum_d A_d z_(i,d).

任何真实覆盖运输完成必须有 O≥0。

## 3. 有理对偶直接核验

给不等式非负有理权重；每个 y_i 的权重和精确为 1。
重新相加得到

    sum y_i + sum gamma_i*s_i + sum eta_(i,d) z_(i,d) ≤ H.

令 A_(i,d)=A_d（内部）或 0（边界），任选有理数 nu。
由总度数等式和各顶点质量等式，

    sum (eta_(i,d)−A_(i,d)) z_(i,d)
    ≥ nu*(150−2B) + sum_i min_d(eta_(i,d)−A_(i,d)−nu*d).

再由非负角隙和为 1，有 sum gamma_i*s_i≥min gamma。
因此

    O ≤ H−min gamma−nu*(150−2B)
        −sum_i min_d(eta_(i,d)−A_(i,d)−nu*d).

精确检查器验证右端严格负。nu 和权重虽由浮点 LP 提出，
接受只用有理数重算、非负性、精确质量和及有限整数度数最小值。
无需相信浮点残差或浮点 LP 的最优性。

## 4. 前沿完全替换

从已独立重建的新阈值 B14 二层前沿出发。
为定位待排除前缀，每次把当前祖先替换为**全部**即时孩子；
只有目标前缀本身具有严格负对偶时才移入几何排除账本。
其余兄弟全部保留，检查最终前沿与证书声明完全相同。
不把子树图数视为已数清，也不改写原始组合枚举检查点。

本轮两个前缀为 (0,0,0) 与 (0,0,1,0,0)。
它们互不重叠，各自覆盖无限精度几何变量域和该有限递归子树的全部完成。
所谓“整棵排除”是不能产生真实覆盖运输类型，不是组合子树为空。
剩余前缀仍须继续枚举／排除，B14 尚未穷尽，更不代表 n=26 全局完成。
