# Complete source replay for actually adopted extended forests

This new source adapter does not modify an older dispatcher or the running
latest-forest builder/checker. The adopted latest current AND its actual
independent final are required. Their true source owner must be identified
through bound enumeration ancestry; acceptance, pending roots, latest history
and actual own executor must be bound by the genuine current inventory.
An actual old owned/mixed/product acceptance cannot be relabelled as this
extended-forest layer merely because root counts match.

Receipt association is an explicit separate preliminary step. Its tests use
in-memory synthetic shapes only, plus an actual old owned-v8 acceptance that
must be rejected as the new adopted layer. Neither a receipt guard nor a
successful final inventory scan returns a geometry model.

The complete source entry rehashes EVERY formal-current dependency and invokes
the SAME actual frozen full geometry main in a separate process with a fresh
explicit semantic report. This keeps the frozen executor's original import
universe intact; caller modules are not injected into or excused from an old
frozen metadata gate. The actual full source/model/history/forest computation
must succeed and match the real own acceptance/publication/current replay.
Failure partials and the full executed command remain preserved.

The adapter then reconstructs the ORIGINAL full source/model/payment/history
again with the actual separately bound proof-time formal and candidate-owner
pairs. It does not deserialize a typed model from a report. Both latest
records and old baselines are freshly replayed with this real model, as are
all actual forest controls and exact strict ledgers. All output classifications,
whole-root payments, remaining roots, newest histories and positive controls
must independently reconstruct and match the real sealed outputs. Exact
root/history accounting and every original formal byte are checked again.

The returned geometry values exist only as this actual completed in-memory
reconstruction. The entire source report, executed checker, model reconstruction
and newest histories are included in the caller's dependency inventory.
No new payment or global proof is created by the source loader. Further
continuation must start from the retained actual grown-v9/root25-v3 nodes,
supports and ledgers, never from an older equal-count tree.

As of implementation, no adopted extended receipt exists yet. The complete
entry remains unexecuted until actual own geometry, SAME-main publication,
complete-current adoption and independent final all pass. Compilation and
receipt-contract tests are not evidence that those gates have completed.
Global enumeration, unrestricted joint acceptance, lower bound and optimality
remain separate obligations.
