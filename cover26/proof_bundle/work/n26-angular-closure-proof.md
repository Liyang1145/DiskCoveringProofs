# n=26：祖先前缀的完整角盒力证书

本证书只使用已接受 n=26 杆图和整数力下界，不采用候选对称性、
局部驻点、角采样或浮点优化器的最优性状态。
力守恒／Cauchy 论证见此前 `n26-force-forest-v1/PROOF.md`。

## 1. 从一个宽角盒到完整二叉角树

对每个指定祖先前缀，从冻结的根面剥离递归重建部分杆图和全部必要角差约束。
整体旋转固定 q0=(1,0)。角差闭包给每个其余锚点的有理根区间。
真实覆盖运输完成的全部锚点均在这一根盒中。

进入节点时，用必要角差约束收紧所有角区间。每条新下界来自已有下界减去
一条必要差分上界，每条新上界来自已有上界加上一条必要差分上界，
因此真实角解不被丢失。若任何下界大于上界，则整个盒确实无真实解。

节点只允许三种：

- SPLIT：在当前收紧后的某一轴内部选择明确有理中点 m，
  子盒分别使用 [lo,m] 和 [m,hi]。共同端点包含在两边，联合恰覆盖父盒；
- FORCE：在整个当前角盒的弧半平面上重建整数力，并检查严格半径下界>U；
- EMPTY：精确必要差分约束已经使盒为空。

从根完整遍历所有孩子，检查每个节点只到达一次、所有节点可达，
拆分孩子索引不同且前向、节点数满足满二叉树账本。
不允许 OPEN、LOCAL 或未付款的角叶。

即使父盒的凸松弛不能给出排除，只要两个完整子盒均严格排除，
就能排除整个父盒。没有只挑选“容易排除的角区间”或遗漏边界点。

## 2. 为什么祖先证书覆盖当前后代

祖先前缀已付的中心面、圆心、共同见证和杆在每个后代中持续存在。
其必要角域仅使用祖先已经加入的邻接，因而是后代真实角解的宽包络。
所以完整角树一旦排除祖先杆图，就同时排除祖先前缀下的全部真实运输完成。

当前已接受前沿中，所有以该祖先为前缀的待办都可以移入这一严格下界账本。
先检查各祖先互不重叠，再逐个从完整原前沿求出所有后代；
不是挑选数值找到的后代，也不声称后代组合图已全部数清。
没有该祖先前缀的其他待办逐项原样保留，验证剩余集合完全一致。
此前已严格排除的后代证据也原样保留，但不重复增加“新图数”。

## 3. 源与实现检查

每个祖先都重新调用冻结枚举程序，取得精确状态、已有面、邻接及孩子数，
再用独立递归逐项对照。完整原前沿、此前接受件、程序源码／二进制、
角树、整数系数及日志均绑定。

字节绑定与有限程序对照并不自行证明连续几何；
连续下界由明确杆条件、全部角盒覆盖和每叶精确整数力不等式推出。
外部八盘定理以及任意覆盖归约最终联合接受仍使用此前明确限定。

## 4. 非完成声明

本文的三棵祖先角树覆盖此前前沿中的部分子树。
四族尚未穷尽，全局下界和与 R* 的同根合成尚未闭合。
不从这些部分结果推断 n=26 最优性，也不启动 n=27。
