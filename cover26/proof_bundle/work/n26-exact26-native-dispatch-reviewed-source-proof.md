an explicit pending dictionary plus a separate retained-terminal set.

origin flag and reference frontier are checked before dispatch.

- split removes the parent and inserts ALL immediate reference children.
- empty requires a nonterminal state with no legal child.
- terminal requires exactly26original labels and no pending region, and is

  and a strict negative all-completion dual bound.

conditional wrapper additionally retains the full known candidate terminal
