# n=26：部分杆图的整数力下界与完整前沿推进

本稿给出新力证书的连续数学依据。整数核验不等于 Lean 形式化，
也不等于 n=26 全局最优性完成。仍沿用明确登记的任意覆盖运输义务。
此前面积和归约证明保存在相邻接受件中。

## 1. 本阶的部分杆图

当前阈值 U=234701/1000000；角帽为
(754112,1555305,2486507,3880649)/10^7。
不使用 n=20 的半径、维数、角帽或完成计数。

一个剥离前缀有 B 个圆周锚点、M 个已引入圆心及 F 个已付中心面。
为每个中心面增加一个共同见证。杆图顶点数为 B+M+F≤76，
杆数为 2B+3F：

- q_i 连到 c_i 和 c_(i+1)；
- 每个面见证连到该面的三个圆心。

任何真实覆盖运输完成都给这个部分杆图一个实现，所有杆长≤rho<U。
未知未来顶点不需要纳入力证书；当前已存在的见证和杆不会消失。
普通引入及星形补标签均保持这些条件。

整体旋转使 q_0=(1,0)，只用了圆盘问题本身的旋转不变性，
不假定 D2 对称性或候选驻点关系。

## 2. 必要角域

令 q_i 的正向角为 2pi*t_i，t_0=0。
相邻角隙非负、≤cap2/D，并绕单位圆恰好一周。
部分中心图的 0／1／2／3 跳路径分别给二／四／六／八杆弦长界。
只有相邻预算排除长弧方向时，才添加短方向差分约束。
Floyd–Warshall 的每个路径和仍是必要差分约束。

由矩阵 M_(i,j) 给 t_j−t_i≤M_(i,j)/D，推出

    −M_(i,0)/D ≤ t_i ≤ M_(0,i)/D.

全部真实锚点落在这些角区间中；保留较宽的独立角盒只会放宽。
本阶各根角区间宽度小于半周，可用已绑定的有理三角函数包络构造

    (a_i/QA)·q_i ≥ b_i/QB,
    QA=10^15, QB=10^18.

这里 a_i 是靠近区间中向量的整数向量，b_i 通过余弦下界及明确舍入误差
向下取整。所有半平面均覆盖整段圆弧，不是只检查圆弧采样点。

## 3. 力的守恒与半径下界

给每条定向杆 e=(u,v) 一个二维整数力 f_e。
div_i 是所有出力减入力量。选非负整数 lambda_i、任意整数向量 beta_i，
要求

    div_i=lambda_i*a_i−QA*beta_i       (1≤i<B),
    div_i=0                          (所有圆心和见证),
    div_0=−sum_(i>0) div_i.

对任何杆长≤rho 的实现 z，有

    rho*sum_e |f_e|
      ≥ sum_e f_e·(z_u−z_v)
      = sum_i div_i·z_i.

圆周锚点满足 |q_i|=1，q_0=(1,0)，故右端至少为

    sum_(i=1)^(B−1) [
      lambda_i*(QA*b_i/QB−a_(i,x))
      −QA*(|beta_i|−beta_(i,x)) ].

把力范数之和向上取整为 S，把上式中的 beta 范数向上取整，从而将分子
向下取整得到 L。当 L>0 时，

    rho ≥ L/S.

检查器用整数平方根计算所有上取整范数，并检查 L/S−U 严格正。
由此排除整棵前缀的全部几何完成，不是只排除数值找到的一个构型。

## 4. 精确重建，而非浮点平衡残差

证书只存非负 lambda、整数 beta，以及杆图生成树外各弦的两个整数坐标。
生成树和弦按确定 BFS 次序从完整部分杆图重建。
先放置弦力，再从树叶向根消去守恒余量，唯一确定树边力。
之后再从所有杆逐点重算 divergence，与上面的目标逐坐标相等才接受。
没有浮点残差容差，也不要求信任浮点优化器返回最优状态。

这种循环坐标表示参考已归档的 compact-force 方法，
但本稿的维数、图构造、阈值、角域与接受判断均针对 n=26 重建；
数学下界由本节守恒恒等式及 Cauchy 不等式直接证明。

## 5. 森林证书与兄弟保留

起点是此前已接受的 282 个必要覆盖运输前缀。
每个事件只有以下作用：

- FORCE：重建整个根角域并通过上面的严格整数力下界后，排除整子树；
- AREA：用已接受的多斜率系数及全部后续度数域，通过严格有理对偶后排除；
- EMPTY：部分状态尚未完成但确实没有任何合法孩子，组合子树为空；
- SPLIT：将父前缀替换为全部即时孩子，包含唯一后继的强制推进；
- TERMINAL：若仍未排除完整图，保留在 unresolved 前沿，不能称为空。

每个事件都重新调用冻结的原枚举程序：
拆分核对一层完整前沿，其余事件核对当前状态及全部孩子数。
再由另一套最短路 BFS 递归逐项比较，绑定退出码、参数、结果和日志字节。
预算结束时所有未选兄弟与未知终端图均保留。

新待办数量可因拆分增加，不能当作进度百分比，也不将组合队列清空。
原始 B18、四族组合检查点及此前全部已接受证据均原样保留。

## 6. 接受范围

FORCE 叶排除满足当前锚点角域的全部弱杆实现，因而也排除真实覆盖运输。
AREA 叶仍只使用此前明确限定的 Voronoi／星形补标签面积条件。
两类下界不混淆作用范围。

本证据仍未穷尽四族，未付全局下界，未证明局部或全局最优。
只有所有必要前沿、全局下界和同根上界联合闭合后才能进入 n=27。
