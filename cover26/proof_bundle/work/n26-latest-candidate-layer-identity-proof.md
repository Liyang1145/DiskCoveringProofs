# Latest candidate layer identity is stronger than equal remaining root rows

This is a current-source ownership requirement, not a new ENERGY, LOCAL,
emptiness, combinatorial transport or global radius proof.

A partial forest can add proved leaves while retaining its whole original root
in PENDING-ANGLES. Therefore two layers can have identical remaining root counts
and identical complete root dictionaries while having different newest accepted
partial forests. An older discovery may not overwrite that newer current layer.
Keeping the older files in a flat inventory alone is insufficient if the next
source loader follows an older forest source and never visits the newer seed.

The per-root current join identifies the actual latest candidate layer before
replaying a new overlay. An explicitly enumeration-only current audit may omit
candidate pointers. Its prior-current-audit digest must locate unchanged bytes
in the actual current inventory. Every ancestor inventory must be an identical
subset of that current inventory, with unchanged radius and remaining root
count; cycles and unknown pointerless schemas are rejected.

At the first explicit candidate current layer, both actual acceptance and
pending-angle pointers must equal the overlay's real source paths. Their current
bound digests, exact radius and root ownership are checked. An older source is
rejected even if all remaining complete-root dictionaries are identical.
The existing owned forest checker still independently reconstructs every
ENERGY/LOCAL leaf, closed split boundary and newest accepted per-root seed.

Thus a proof-time candidate-v5 discovery may join a later enumeration-only
stage-v13 or stage-v14 only while v5 is still the actual latest candidate layer.
If another candidate refinement has become current, the discovery must instead
continue that actual source and preserve its newest seeds. This guard adds no
permission for count-only source splicing or concurrent stale-layer composition.

The current parent's digest is captured before its snapshot is read and checked
again after the full join. The latest-layer identity receipt, executed guard,
regression, regression script and this explanation are bound in the resulting
complete current inventory.

Ten synthetic rejection controls include an older source with identical whole
root counts and rows, missing or changed ancestors, ancestry cycles, incomplete
ownership pointers, changed ancestor inventory/count, unsupported schemas and
altered source bytes/rows. Actual snapshot tests resolve both a direct v5
candidate checkpoint and stage-v13-with-scope's bound v5 ancestor.
These ownership tests earn zero geometric payments and prove no global optimum.
