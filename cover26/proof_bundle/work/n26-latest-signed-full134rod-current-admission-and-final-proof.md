# Distinct latest-forest current admission and independent final

These are new named executors. Frozen old source dispatchers and admission
programs are not edited. Every code/fixture test here remains distinct from
actual complete-current adoption.

The identity gate follows only explicitly bound enumeration ancestry and
recognizes the new extended-forest current schema. It binds actual acceptance,
pending whole roots, latest partial history and own frozen geometry executor.
Equal root counts do not authorize replacing the latest candidate layer.
All extended modes, controls and full-source-replay markers are explicit.
Older owned, mixed and product identities delegate to their unchanged gates.

The admission requires an actual completed parent/current-final pair and
rehashes its ENTIRE inventory. It preserves the actual same-radius transport
frontier. Actual own geometry acceptance and actual SAME-main publication are
required; no typed arithmetic model, diagnostic control or synthetic receipt
is a substitute. The geometry proof-time source must be exactly the genuinely
current source or an identically bound unchanged ancestor with the same source
acceptance and full root ownership. A receipt on owned-v8's 25 roots cannot be
silently recast as a receipt on mixed-source's 16 roots.

The complete frozen geometry main is actually executed AGAIN as a separate
process. Its report must equal the real acceptance/publication. Exact latest
root/history accounting is independently reconstructed, all actual historical
closed-type receipts are replayed, every terminal obligation is retained,
and the full new inventory is rehashed before writing the current report.
Own admission/helper bytes cannot change while executing.

The independent final imports only a pure root/history accounting module,
not the geometry/source adapter or diagnostic producer. It checks EVERY
current dependency, genuine own geometry/publication/current semantic reports
and frozen executor bytes, exact whole-root partition and newest histories,
actual latest layer pointers, untouched transport frontier and all bound
historical type/receipt/terminal files. Critical root/history/ledger inputs
are hashed again after accounting, and the actual current/final executor
snapshot must remain unchanged. Original LOCAL is not emptiness.

Synthetic new-schema identity and final-receipt shapes were exercised ONLY
in memory. Twenty identity corruption paths and sixteen final association
corruption paths were rejected. Actual original owned-v8 identity delegation
was checked separately. The actual full geometry, complete-current admission
and entire independent final have NOT run as part of those tests.

The prepared runner refuses live complete-current joins or independent finals,
existing targets/partials and missing actual own geometry/publication. It
serially executes admission then the independent final, never overlaps the
original stage pipeline. Its arguments must name the genuinely latest completed
parent and actual proof source when execution becomes possible.

Even an eventual completed latest-forest current/final pair does not close
the full n=26 transport catalogue or unrestricted joint reduction. An actual
new source semantic adapter and future continuation must preserve these extended
histories; no older dispatcher can be overwritten or used to reset them.
Global lower bound, optimality and progression to n=27 remain pending.
