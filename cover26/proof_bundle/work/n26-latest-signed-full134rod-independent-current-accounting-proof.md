# Independent exact latest root/history accounting

This pure accounting gate imports no geometry checker, source dispatcher,
typed arithmetic context or diagnostic producer. It is not a replacement for
the entire actual source/model/forest replay, actual same-main publication,
complete-current admission or final inventory rehash.

The gate independently reconstructs the exact classification and root partition
for both actual latest root25 v3 and grown root28 v9. A whole-root lower bound
is possible only when the actual complete pending-leaf list is empty. A root
with original LOCAL cannot be called empty. All source rows retain their exact
order and entire closed domains. Boolean, repeated or missing owners fail.

For every retained partial root, the actual latest nodes, both distinct support
tables, exact strict ledger, original arithmetic baseline and prior accepted
history must be preserved exactly. Every unchanged prior history remains in
the output. Old nonOPEN nodes, support prefixes and strict ledger entries
cannot be reset. Every expected latest role and every output ledger is explicit;
omitting root28 for an easier root25-only acceptance is rejected.

The actual independent test uses the real completed v3/v9 records and their
real controls, plus the original owned-v8 pending roots and actually accepted
prior-history DATA. It builds labelled, in-memory synthetic final-shaped
objects to exercise accounting checks. These objects are not written as a
geometry acceptance or current receipt. In particular the mixed-curvature
bundle's source-history snapshot is used only as bound original-source DATA,
not as evidence that the mixed16-root layer has been adopted.

Actual records still leave all25source whole roots unresolved. Six latest
partial histories must be preserved, and no new whole-root payment is allowed.
Twenty-one actual missing/repeated/substituted root, wrong role, reset latest
tree/support/ledger, false payment/count and scope controls were rejected.

The eventual independent final executor must additionally verify the genuine
completed-current schema and its full inventory, actual frozen geometry
executor bytes, actual acceptance/publication/current semantic replay, actual
latest source ownership, exact transport frontier and every retained historical
receipt. This test does not establish any of those broader gates.
If candidate ownership changes to the mixed/product layer, bind and replay
that actual source explicitly; equal root counts or source-history DATA cannot
authorize adopting an older proof-time source as current.
