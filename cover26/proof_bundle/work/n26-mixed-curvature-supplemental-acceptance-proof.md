# Two-mode supplemental candidate-root acceptance

This is a new own-executor interface. It does not alter or relabel any old
frozen owned, conditional, constant-hull or diagnostic executor.

The common source gate is the unchanged COMPLETE original owned-candidate
gate. It uses the actual completed explicit owned current audit, independent
final rehash, source acceptance and actual publication replay. It reconstructs
the original 92-rod/62-vertex model, all old payments and complete current
per-root forest history. No typed diagnostic context is a replacement for
that gate. Whole source rows and latest partial histories must match exactly.

The new checker supports exactly two explicit modes:

- Constant-hull signed Taylor curvature, using the already tested closed-slab
  replayer and its actual thirteen rejection controls and six tiny positives.
- Integrated-Taylor signed curvature, using exact positive normalized
  integral weights on closed t strips, charged weighted spectral rounding,
  exact LDL/full reconstruction, contained closed slab minimization and the
  original LOCAL remainder. Its actual twelve rejection controls and its
  own tiny-domain curvature checks are separately executed.

The combined checker also executes four mixed-mode controls: duplicate root
ownership across modes, unknown mode, constant cover relabelled as integral,
and integral cover relabelled as constant. All twenty-nine actual controls
must run; separately stored mode arithmetic reports are not substitutes.
Every imported critical execution module and the checker's own file are
bound to their copied bytes. The actual report identifies its own checker.

The supplemental complete closed-root covers partition the incoming original
whole-root obligations into freshly proved lower-bound payments and unchanged
remaining rows. Each proved root has a central original LOCAL part, so it is
not claimed strictly empty. The ORIGINAL 52-coordinate allowance 7/800000
never changes. Existing forests remain bound and untouched, even for roots
with a new supplemental universal cover. Remaining roots keep their newest
partial histories explicitly. Overlapping supplemental slabs are not counted
as new unique paid leaves in the older forest.

Standalone acceptance requires executing the whole own checker with the
complete source gate and actual controls, then a real fresh same-executor
publication replay. Arithmetic/metadata unit fixtures explicitly do not
execute that full gate, pay no roots and remain unverified geometry.

A distinct complete-current join must subsequently preserve the actual
transport frontier, historical closed full-type pool and all proof receipts,
re-execute the frozen overlay semantic checker and controls, bind the current
parent/final rehash and real publication replay, and pass an independent final
inventory rehash. A new explicit source/identity adapter must recognize this
new schema and preserve remaining per-root histories. The old owned schema
dispatcher cannot silently treat this as an old forest report.

Global catalogue completeness, unrestricted joint acceptance, global covering
lower bound and optimality stay false until their full original obligations
are independently closed. No n27 completion or start is claimed here.
