# Separate formal current and actual candidate-owner source replay

An enumeration-only current layer and the actual candidate layer's original
current admission are distinct objects. The current layer can retain the
candidate unchanged while adding transport dependencies. Equal counts alone
are not permission to choose an older candidate source.

The new adapter first checks the actual formal current and its independent
final. It identifies the genuinely latest candidate through the original
owned/mixed/product identity dispatch, which follows only explicitly bound
enumeration ancestry. The separately supplied candidate-owner current and
independent final must name exactly the resulting owner hash, source acceptance,
pending-root hash and radius. Both owner files and every owner dependency must
be identically bound in the formal inventory. Actual publication must be bound
by both inventories. No schema is silently relabelled.

This preflight is only identity association. Its independent rejection tests
do not call the full source gate and explicitly cannot create geometry payments.

The complete gate then rehashes EVERY actual formal dependency and invokes the
actual source's unchanged full owned, mixed or product semantic source gate
using the original candidate-owner pair. That gate reconstructs the entire
original model, native geometry, all old payments and newest retained history.
The adapter never imports a typed arithmetic resource or a diagnostic producer.
It retains all resulting inventory paths and checks the formal/owner/source
snapshots again after the actual replay.

This is a source backend for a future distinctly frozen latest signed/full134rod
forest interface, not that interface's acceptance. The future interface must
also replay the actual completed newest root25/root28 forests, keep every old
nonOPEN node, support prefix, strict ledger, closed sibling and shared boundary,
execute actual rejection/positive controls, and publish through the SAME frozen
main. Serialized complete-current adoption and independent final binding are
still required before payments. Source identity tests or successful source-only
replay cannot replace those forest and global joint obligations.
