# n=15、16：原生核心盘归约

这里核验的是严格的必要条件，不是相应阶数的全局最优性证明。选取有理测试半径
(U_{15}=0.318143)、(U_{16}=0.308220)；它们用于定位候选附近的分支，
不把外部候选的显示数字作为证明。下述推论对任意圆心、包括重复圆心和切触，均适用。

## 边界接触盘数

设 (B) 是与单位圆相交的盘数。不论圆心在哪里，每个足迹角长不超过
(2\arcsin r)。此外每个这类圆心的范数至少 (1-r)，其盘遗漏半径
(1-2r) 的开核心；余下的盘覆盖开核心，因有限闭并性也覆盖其闭包。
因此 (B\arcsin r\ge\pi)，且 (r/(1-2r)\ge r_D(n-B))；
没有剩余盘时立即矛盾。

- **n=15, r≤U₁₅：** (sin(\pi/9)>U_{15})，故 (B\ge10)。
  若 (B\ge13)，最多两个盘覆盖核心，要求 (r/(1-2r)\ge1)，
  与 (U_{15}<1/3) 矛盾。因此 (B\in\{10,11,12\})。
- **n=16, r≤U₁₆：** (sin(\pi/10)>U_{16})，故 (B\ge11)。
  若 (B\ge13)，至多三个盘覆盖核心，要求 (r/(1-2r)\ge\sqrt3/2)。
  下列有理比较直接排除此情形。因此 (B\in\{11,12\})。

这些是接触盘计数，不把没有正长度拥有弧的盘误认为 Voronoi 边界拥有者。

## n=15 的十二拥有者分支

在已经按仓库 n=22 路线得出一位拥有者一条连续短弧的归约中，若恰有十二位正长度
边界拥有者，设其中心模长升序为 (D_i)、拥有弧半角为 (t_i)。此分支的其余
三个盘必须处理没有被拥有者覆盖的核心。

沿用本仓库 [n=27 的平移核心盘论证](../cover27/proof_bundle/research-2026-11/followup/proof.md)，
直接用 (U=U_{15}) 扩大原覆盖以及原三盘精确下界 (q=\sqrt3/2)。
令 (L=U(1+1/q))。半径 (L) 的拥有者盘覆盖
(|z|\le1+U-L)：否则可在单位盘内找一个半径严格大于 (L-U)、
又避开十二位拥有者盘的平移核心，余下三盘不可能覆盖。故 (D_1\le L)。
在第一圆心反向移动略大于 (L-D_1) 的距离，且 (D_1\ge1-U)、(L<1)，
同理得到 (D_1+D_2\le2L)。

对 (d\in[1-U,\sqrt{1-U^2}])，函数
(f(d)=\arccos((d+(1-U^2)/d)/2)) 递增且凹：内函数凸且递减，
外函数在正数范围凹且递减。由圆周足迹界 (t_i\le f(D_i))，及
(D_1,D_2\le2L-(1-U)<\sqrt{1-U^2})，Jensen 给出
(t_1+t_2\le 2f(L)<0.118)。所有半角都严格小于 (0.324)；
如果余下十位中至多八位半角大于 (0.215)，总半角小于
(0.118+8(0.324)+2(0.215)=3.140<\pi)，不可能。因此余下十位
至少九位有 (t_i>0.215)，并由 (f(0.740)<0.215) 得 (D_i>0.740)。
这只是严格的角度/径向剪枝，不排除整个十二拥有者分支。

## 有理数核验

以 (3.14159<\pi) 及正弦/余弦交错 Taylor 界（参数均在 ([0,1])）
为基础，以下用标准库逐项核验比较，不使用浮点数：

```python
from fractions import Fraction as F
pi_lo = F("3.14159")
u15, u16 = F("0.318143"), F("0.308220")
sin_lo = lambda x: x - x**3/6
cos_hi = lambda x: 1 - x**2/2 + x**4/24
assert sin_lo(pi_lo/9) > u15
assert sin_lo(pi_lo/10) > u16
assert u15 < F(1, 3)
assert (u16/(1-2*u16))**2 < F(3, 4)
sqrt3_lo = F("1.73205")
assert sqrt3_lo**2 < 3
l_hi = F("0.68551")
assert u15*(1+2/sqrt3_lo) < l_hi
assert (2*l_hi-(1-u15))**2 < 1-u15**2
assert (l_hi+(1-u15**2)/l_hi)/2 > cos_hi(F("0.059"))
assert sin_lo(F("0.324")) > u15
assert F("0.118")+8*F("0.324")+2*F("0.215") < pi_lo
d = F("0.740")
assert d**2 < 1-u15**2
assert (d+(1-u15**2)/d)/2 > cos_hi(F("0.215"))
```
