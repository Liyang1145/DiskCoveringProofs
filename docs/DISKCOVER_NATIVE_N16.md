# n=16：闭单位盘的有理覆盖证书和边界归约

本页独立核验 **r_D(16) ≤ 0.30821981**、精确代数候选整盘覆盖，并把半径不超过 0.308220 的任意摆法的 Voronoi 剥面限制到两族。本页不证明严格下界或全局最优。

## 有理覆盖

令 M=100000000，并把下表每一坐标除以 M：

```text
( 82813759,-25585691) ( 82813759, 25585691)
( 51937996, 53015828) ( 24025478, 80692725)
(-24025478, 80692725) (-51937996, 53015828)
(-82813759, 25585691) (-82813759,-25585691)
(-51937996,-53015828) (-24025478,-80692725)
( 24025478,-80692725) ( 51937996,-53015828)
( 34805538,        0) (        0, 30563471)
(-34805538,        0) (        0,-30563471)
```

这组有理数由[固定版本的外部候选根箱中心](https://github.com/VonEquinox/DiskCoveringSolve/blob/089584973f41e6374ce110f6e5b5ee456df19352/cover16/proof_bundle/core/root16.json)四舍五入得到（源 SHA-256：`a89dfe7e356a670176622e0726a0e7d27f14136e5e1d79326f9afedac285ab9e`）；核验本身完全不依赖该根箱、原构型的达到性或外部程序。

对每个圆心 c，将其闭 Voronoi 单元与单位闭盘相交。线性条件为
`2(v-c)·p ≤ |v|²-|c|²`，对所有不同圆心 v。点到最近圆心的距离在各单元内等于 `|p-c|`。
因为平方距离是凸函数，非平凡直线段上最大值在端点。在单位圆弧上其平方为
`1+|c|²−2c·p`，只须核验弧的端点及圆弧内的背向圆心点 `−c/|c|`。
所有端点来自平分线两两相交或平分线与单位圆相交。即使单元退化成一点或线段，端点仍按同一规则得到。
本构型无重复或零圆心，因此无须处理整圆上的常值情形。

以下检查逐一核验上述有限候选点。全部比较在有理数或单个平方根扩张域中完成；没有浮点数、容差或采样。

```python
from fractions import Fraction as F
from itertools import combinations

ints = [(82813759,-25585691),(82813759,25585691),
        (51937996,53015828),(24025478,80692725),
        (-24025478,80692725),(-51937996,53015828),
        (-82813759,25585691),(-82813759,-25585691),
        (-51937996,-53015828),(-24025478,-80692725),
        (24025478,-80692725),(51937996,-53015828),
        (34805538,0),(0,30563471),(-34805538,0),(0,-30563471)]
centers = [tuple(F(v, 10**8) for v in c) for c in ints]
radius = F("0.30821981")

def dot(v, w):
    return v[0]*w[0] + v[1]*w[1]

def nonnegative(a, b, h):  # a + b sqrt(h) >= 0
    if b == 0 or h == 0:
        return a >= 0
    if a >= 0 and b > 0:
        return True
    if a < 0 and b < 0:
        return False
    return a*a >= b*b*h if a >= 0 else a*a <= b*b*h

assert len(centers) == len(set(centers)) == 16
for c in centers:
    lines = [(2*(v[0]-c[0]), 2*(v[1]-c[1]), dot(v,v)-dot(c,c))
             for v in centers if v != c]

    def check(p, q, h, t, s):
        # p+q sqrt(h) is the point; squared distance is t+s sqrt(h).
        if all(nonnegative(d-a*p[0]-b*p[1], -a*q[0]-b*q[1], h)
               for a,b,d in lines):
            assert nonnegative(radius**2-t, -s, h)

    for (a,b,d),(e,f,g) in combinations(lines, 2):
        det = a*f-b*e
        if det:
            p = ((d*f-b*g)/det, (a*g-d*e)/det)
            if dot(p,p) <= 1:
                t = (p[0]-c[0])**2+(p[1]-c[1])**2
                check(p, (0,0), 0, t, 0)
    for a,b,d in lines:
        k = a*a+b*b
        h = k-d*d
        if h >= 0:
            p = (a*d/k, b*d/k)
            for sign in (-1,1):
                q = (-b*sign/k, a*sign/k)
                check(p, q, h, 1+dot(c,c)-2*dot(c,p), -2*dot(c,q))
    k = dot(c,c)
    assert k > 0
    check((0,0), (-c[0]/k,-c[1]/k), k, 1+k, 2)
```

## Voronoi 边界拥有者与十二拥有者分支

考虑半径 U=0.308220 的覆盖（半径更小时先扩大到 U，不会改变最近圆心关系）。
令 B 为其闭 Voronoi 单元在单位圆拥有正长度弧的中心数；重复圆心合并、零长度弧不用计入。
边界弧总长 (2\pi)，每个拥有者可覆盖的总角长至多 (2\arcsin U)。
所以 B≥11。每位拥有者的圆盘不进入半径 (1-2U) 的开核心。
如果 B≥13，其余至多三个盘就必须覆盖该核心，和
`[U/(1-2U)]² < 3/4` 及三盘最优半径 (\sqrt3/2) 矛盾。
故 B=11 或 12；用 n=22 式 Voronoi 剥面时，只须这两种边界点数。尚须保证一般位置归约和每一兼容剖分的完整生成均有单独证明。

当 B=12 时，设 D₁≤D₂ 是两位最近拥有者的圆心长度，令 L=U(1+√2)。
半径 L 的拥有者扩大盘覆盖半径 (1+U-L) 的同心闭盘：否则在其内部有一点距各拥有者都超过 L，
可在该点取半径严格大于 (L-U) 的闭核心，避开十二盘又仍在单位盘内；但其余四盘最优半径是 `1/sqrt(2)`，矛盾。
先得 D₁≤L。若 D₁+D₂>2L，沿第一圆心反方向移动略大于 L−D₁ 的距离，仍在半径 1+U−L 内，
到第一圆心距离超过 L，而按反三角不等式到其余拥有者也超过 L，矛盾。

令 `f(d)=acos((d+(1-U²)/d)/2)`。在 `[1-U,sqrt(1-U²)]` 上 f 递增、凹（内函数凸且递减，外函数凹且递减）。
因为 D₂≤2L−(1−U)<sqrt(1−U²)，两位拥有者的足迹半角之和 ≤2f(L)<0.400。
其他任一足迹半角 <0.314；d≤0.730 时半角 <0.175。
若其余十位中至多七位中心长度大于 0.730，则总半角 <0.400+7·0.314+3·0.175=3.123<π。
因此其余十位中至少八位长度 >0.730。这条剪枝无需对称假设，不排除整个十二拥有者分支。

用有理比较复验：令 `x=3.14159/10`，检验 `x−x³/6>U`；
用 `sqrt(2)<1.414214` 得 `L<0.74411`，对 `d=0.74411,0.730`
分别比较 `(d+(1−U²)/d)/2` 与对应 `t=0.200,0.175` 的余弦上界 `1−t²/2+t⁴/24`；
`0.314−0.314³/6>U`。这些有理比较和上方覆盖程序均运行通过。

以下先复算精确半径下的闭盘覆盖证书；两族剥面内部的全部连续域排除、候选根与原最优问题的同一性仍未完成。

## 精确代数候选：根存在、唯一和整盘覆盖复算

这里核验精确半径下的闭盘覆盖证书，仍不补完任意摆法排除。
使用上面的固定版本 `root16.json` 文件运行：

```sh
python tools/verify_native_n16_attainment.py /path/to/root16.json
```

本次以标准库精确有理算术运行通过，输出
`N16 EXACT ROOT AND WHOLE-DISK COVER PASSED`。这只下载了固定根箱与候选描述，
没有执行或导入外部验证器。

- **根存在和唯一。** 检查器从 12 个圆周点、16 个中心和 10 个活跃公共点的距离关联表生成 65 个几何多项式，再生成 75 个驻定多项式，共 140 个。对根箱中的固定点映射
  `G(x)=x-YF(x)`，用整数计算中点残差、Jacobian 和二次系数给出的导数变化上界。
  核对每个分量的像严格在箱内且无穷范数 Lipschitz 常数小于 1（核验上界小于等于 `10^-12`）。
  由 Banach 不动点定理有且仅有一个不动点；`I-DG=Y DF` 可逆，故 Y 可逆，不动点确为 F 的零点。
  再利用残差除以 `1-Lipschitz` 缩小根范围，用有理平方比较验证半径隔离区间。
- **中心和环带。** 活跃三角形的公共点由根方程给出；另外八个中心三角形使用由中点坐标计算的有理外心，整个新根盒上逐项验证严格距离余量。
  若同一点 p 到某组三个中心都不超过 r，则它们的凸包被覆盖；这由加权方差恒等式
  `sum_j λ_j |x-c_j|² = sum_j λ_j |p-c_j|² - |x-p|²`（`x=sum_j λ_j c_j`）推出。
  环带三角形使用同一论证，或直接由单盘凸性覆盖。42 个三角形均以严正方向取向，
  有向边链核验恰消去到圆周锚点多边形。三角形指标和等于外边界绕数（避开三角边），
  因此覆盖该多边形，包括由闭包得到的边。
- **圆弓形。** 邻锚点之间夹角均介于 0 与 π/2；检查它们沿正向短弧正好绕圆一次，
  且相关中心方向严格在弧的端点方向之间。故弧上距该中心最远处在端点，
  两个端点由代数距离方程覆盖；再用单盘凸性覆盖整块圆弓形。
- **确为此构型的半径。** 在锚点 q₀处，两个相邻中心与它的距离平方由方程恰等于 t；
  其他十四个中心到它的距离平方严格大于 t。因而这个代数构型的覆盖半径恰为根的半径坐标，
  而不是只证明以稍大半径可以覆盖。

**仍未偿付：** 对任意中心集合排除半径严格小于该根的覆盖。
不能把这里的根唯一性（固定方程、固定小箱）误当成原无限维几何优化问题的全局唯一性或最优性。
