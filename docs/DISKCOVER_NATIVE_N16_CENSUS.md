# n=16：原生 Voronoi 剥面普查

对半径严格小于已复验[候选半径](DISKCOVER_NATIVE_N16.md)的任意摆法，本次把可能的中心剖分归约到两族共 **164** 个规范轨道。剖分普查不是连续域排除，不能据此判定最优。

## 任意圆心与安全剪枝

假定存在半径严格小于代数候选半径 r* 的覆盖。以 r*（不是下面用于角度筛选的上界 U=0.308220）作为归一化试验半径。使用 [n=19 的径向归一化和一般位置论证](DISKCOVER_NATIVE_N19_B14.md#how-contact-count-and-owner-count-interact)：该论证只使用严格余量和半径小于 1/2，故亦适用于 U。它把中心变为互异、模长小于 sqrt(1−r*²) 的一般位置中心，保持严格覆盖；每位正长度 Voronoi 边界拥有者仅出现一次。加入外部胞取对偶，去掉外部顶点及开星后得到简单圆盘三角剖分。边界交接点和三胞点分别为相邻两盘及三个盘内的杆连接见证。由 [边界计数](DISKCOVER_NATIVE_N16.md) 剩 B=11、12 两种边界点数。

以一周为 1，单条拥有弧角差小于 9974/100000。两锚点若存在至多四杆或六杆的已安装路径，则由三角不等式弦长小于 4U 或 6U，较短角差分别小于 21143/100000 或 37566/100000。核对程序用 Machin 公式与正弦交错级数对三项作精确有理验证。剥面时只用已安装路径产生差分约束；仅当该方向的角差上界严格排除长弧分支时，才施加短弧约束。因此被排除的部分剖分不能补全为严格反例。

根面的第三顶点若是边界点，则遍历边界分割与全部内点预算分配；否则暴露一个新内点。真实剖分沿两类操作之一往下走，且余下面数逐步下降。完整剖分按所有有向根边遍历规范化，消去边界二面体和内点重标。双遍历只是同一源程序内的交叉核对，不是两个独立实现。

## 复验

仓库原生 n21 源 `peel21.cpp` 的 SHA-256 为
`7063d6fbd45786696873b13c5d8b07e657bcdf47c685b0aae8392876373e53d0`。
稀疏检出时可用 `git show HEAD:cover21/proof_bundle/research-2026/n21-global/peel21.cpp` 导出原文件再编译。

```sh
out=$(mktemp -d)
g++ -O3 -std=c++17 cover21/proof_bundle/research-2026/n21-global/peel21.cpp -o "$out/peel"
for b in 11 12; do
  for mode in dfs audit; do
    "$out/peel" 16 "$b" "$out/$mode-$b.json" 100000 9974 21143 37566 0 "$mode" || exit
  done
done
python verification/n16/compare_census.py "$out"
```

规范面表和稳定子逐项匹配。复验脚本还检查面数、边关联、顶点覆盖及根计数。达到构型匹配使用 24 种外环二面体重标与全部 24 种内点置换；匹配轨道稳定子为 4。[JSON 回执](../verification/n16/census_receipt.json)保存两个规范轨道集的 SHA-256。
