# n=16：原生连续角域力证书

本页继续 [Voronoi 剥面普查](DISKCOVER_NATIVE_N16_CENSUS.md)。上界候选已由
[有理根箱及覆盖验证](DISKCOVER_NATIVE_N16.md) 独立复算。只把明确通过的连续域记录为排除；
数值 LP、单个姿态、计数或报告不能替代证书复算。

## 证书原理

固定圆周交接点 q₀=(1,0)，按逆时针展开其他锚角。一个可行摆法为每条杆提供
长度不超过真实覆盖半径的向量，共包括两端关联杆及每个三角面的三条见证杆。
沿用已验证的角度差分约束收紧角盒；分裂用同一有理分点，两个子盒同时包含分点。

对具有弧盒的单位锚点 qᵢ，每个真实 qᵢ 满足弧的有理支撑半平面 aᵢ·qᵢ≥cᵢ。
支撑法向量的三角值用 Machin 公式及 Taylor 有理区间控制，额外放松量含法向舍入误差。
给定每杆的有理向量流 fₑ，先严格检查每个非锚点的散度为零。以锚点散度 gᵢ
和非负支撑系数 μᵢ，取 dᵢ=μᵢaᵢ−gᵢ；则杆内积总和至少是

```text
∑ᵢ [ μᵢ(cᵢ−aᵢ,x) + dᵢ,x − |dᵢ| ]。
```

这是把散度求和以 q₀为原点并利用 |qᵢ|=1、支撑半平面所得。
可行杆长上界则要求同一内积总和不超过 U∑ₑ|fₑ|。
所有范数以整数开平方向上封闭，严格比较上述下界大于杆长上界才排除一个角盒。
力证书试验半径 U=0.308219801898618 严格高于根箱的半径上端，
而普查角帽使用更宽的 U₀=0.308220。执行全域检查不需要 SciPy；仅生成未受信提示需要 LP。

## 复算

从普查文档按同样命令生成两个 DFS JSON，再从本库运行（不接受未知图号或不匹配面表）：

```sh
for b in 11 12; do
  python verification/n16/force_exclusion.py --complete-noncandidate --census "$out/dfs-$b.json" "verification/n16/force_b$b.json.gz" || exit
done
```

每个证书从完整根角盒开始，只有经有理不等式证实为空、被严格力分离、或二分且两个子盒分别通过，才能接收。
未能生成完整证书的图不收入证书包。

本次 B=11 的 93 图和 B=12 的 70 个非候选图均已找到覆盖完整域的力证书；
另有唯一的 B=12 候选图不能用同一「超过精确候选半径」的阈值排除。
候选图允许使用[近锚，严格局部最优性](../verification/n16/anchor_isolation.py)作为叶：
仅当整个角盒经正确重标、旋转以及（如适用）反射之后落在锚向量欧氏距离 1/10 内才能接受该叶。
用有理三角界验证弧宽小于半圆且中点与候选点点积为正，再用两端点点积给出距离平方上界，使其总和不超过 1/100。四个允许重标所用的源锚固定分别由 alternate_pins.py 核验，不把不同固定锚的邻域当成相同。
角盒不落入隔离域时，只能用完整力证书排除，不能把「接近」视作结论。
