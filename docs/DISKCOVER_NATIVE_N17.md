# n=17、18：任意圆心覆盖的边界盘数限制

这是任意摆法下的精确必要条件，采用仓库把边界所有者与内部中心分开
的思路（见 [n=22 全局源证明 §3](../shared/proof_bundle/research-2026/n21-25-synthesis/round3-high/N22-GLOBAL-PROOF.md)）。
本页不使用外部证明或候选对称性作前提，不声称已经证明最优半径。

**结论。** 设用至多 17 个等半径闭盘以半径 $r\le 3/10$
覆盖单位闭盘，则与单位圆周相交的盘数 $B$ 满足 $11\le B\le13$。
用至多 18 个盘以 $r\le291/1000$ 覆盖时，同样有 $11\le B\le13$。
允许圆心在单位盘外、重复以及仅切触。这里的 $B$ 计所有实际与圆周相交的盘，
不是经过组合补点之后的图数据。

## 证明

设圆盘半径为 $r<1$，圆心到原点的距离为 $d>0$。
它在单位圆上截出的非空足迹是单一闭短弧（切触时退化为一点），半张角
$$
  \alpha=\arccos\frac{1+d^2-r^2}{2d}\le\arcsin r.
$$
不等式由 $d^2+1-r^2\ge2d\sqrt{1-r^2}$ 得到。
原点为圆心而半径 $r<1$ 时没有足迹。缩放后，半径 $t>r$
的任意同心圆周，每盘可覆盖的弧长比例不超过
$\arcsin(r/t)/\pi$。所以 $k\ge2$ 个盘覆盖半径 $t$ 的圆周
必有 $r\ge t\sin(\pi/k)$；若 $r\ge t$ 则此式也自动成立。
少于 $k$ 个盘可以重复补足 $k$ 个，不影响覆盖。

若 $r\le3/10$，由
$\sin(\pi/10)=(\sqrt5-1)/4>3/10$（等价于 $5>(11/5)^2$），
十个盘不能覆盖单位圆周。因此 $B\ge11$。同一结论也适用于
$r\le291/1000<3/10$。

任何与单位圆周相交的盘，其中心距离 $d\ge1-r$。
若 $|x|<1-2r$，则 $|x-c|\ge d-|x|>r$。
所以这 $B$ 盘不能参与覆盖开盘 $|x|<1-2r$，其余盘必须覆盖它。
其余盘的有限闭并是闭集，因此也必须覆盖闭盘 $|x|\le1-2r$。

* $n\le17$：若 $B\ge14$，至多余三个盘，故
  $r\ge(1-2r)\sin(\pi/3)\ge\sqrt3/5>3/10$，矛盾。
* $n\le18$：若 $B\ge14$，至多余四个盘，故
  $r\ge(1-2r)/\sqrt2\ge418/(1000\sqrt2)>291/1000$，
  最后一步为整数比较 $418^2>2\cdot291^2$，矛盾。

## 接入全局枚举时的范围

若整个盘已覆盖，且所选几何归约把外层顶点映射到真实的、不同的
圆周所有者，则顶点数不超过这里的 $B$。在通常的无返回边界所有权
归约中，外层所有者本身也以足迹覆盖整圆，所以下限同为 11。
补点若只细分内部三角面、不增加外层顶点，不改变这个范围。
对于没有上述对应关系的组合编码，不能直接用本页删掉图类型。

因此在候选半径分别被严格证明小于 $3/10$ 和 $291/1000$ 后，
原生的严格反例搜索只需处理外层顶点数 11、12、13。仍需核验
上界构型、Voronoi 归约和所有这些剩余类型的连续域排除；
本页未执行全局重放，也不提供这些证书。

### n=17：13 个边界盘的分支下界

若 17 盘覆盖且 $B=13$，只有四盘能覆盖内盘。将上述弧界用于
这四盘，得到 $r\ge(1-2r)/\sqrt2$，即
$r\ge1/(2+\sqrt2)$。所以在这条严格阈值以下只需检查 $B=11,12$。
这不能在 n=17 候选半径附近排除整个 $B=13$ 分支。

## n=17：独立的有理构型上界

本库的 [整数验证器](../tools/check_native_n17_upper.py) 验证：

> $r_D(17)\le 0.29853158925642805986984377443$。

命令：

```sh
python tools/check_native_n17_upper.py
```

从闭正方形 $[-1,1]^2$ 开始。若到原点的最小距离平方大于 1，
该方块与目标闭盘不交；否则仅当某一个圆心到该方块的最大距离平方
不超过半径平方时才接受。最小值可将各坐标分别夹到对应区间求得，
最大值亦可分别在区间端点求得。其余方块一分为四，四个闭子方块的并
等于母方块。若最小网格仍有未验收方块，程序报错而不是返回成功。
全部比较在缩放后使用整数平方和交叉相乘；因此有限树验收证明整个
单位闭盘被覆盖，不只是采样点。新鲜运行验证了 13,056 个覆盖叶、
3,193 个外部叶和 5,416 个四叉分割节点。

构型搜索和验证分开。为了得到候选圆心，从
[固定上游候选数据](https://github.com/VonEquinox/DiskCoveringSolve/blob/089584973f41e6374ce110f6e5b5ee456df19352/cover17/proof_bundle/core/root17.json)
（SHA-256 `f520c34816aab807fd115933a1159151ec7e71e4b8fb3b9b9d85d7c554050ac2`）
取中点数组 `xnum[22:56]/Qx`，分量四舍五入至最近的
$2^{-104}$ 倍数，写入验证器。没有运行上游代码，也不需要信任
上游根的存在性、隔离区间或最优性。这里证明的只是固定有理构型的
上界；没有相等的任意圆心下界，也没有把有理半径当作最优值。

## n=17：同根的精确代数构型

也可核验固定构型的精确半径，而不限于上面的有理近似上界：

```sh
curl --fail --location --output root17.json https://raw.githubusercontent.com/VonEquinox/DiskCoveringSolve/089584973f41e6374ce110f6e5b5ee456df19352/cover17/proof_bundle/core/root17.json
python tools/check_native_n17_root.py root17.json
```

验证器先匹配上述固定 SHA-256，不执行外部代码。输入只提供候选
中点与预条件矩阵；本库验证器自行从 63 根杆以及 11 个单位圆约束
生成 157 维整数二次系统（74 个约束和 83 个驻定方程），不读取外部
方程、Jacobian 或验收结果。令中点为 $z$、预条件矩阵为 $Y$、
映射为 $\Phi(x)=x-YF(x)$。检查器用整数重算 $F(z)$ 和 $DF(z)$，
并以二次项绝对系数尾界，逐行验证
$$
  |(YF(z))_i|/\rho+
  \sum_j|(I-YDF(z))_{ij}|+
  \rho\sum_k |Y_{ik}|d_k < 1.
$$
其中 $d_k$ 是第 $k$ 条方程所有合并后二次单项式系数绝对值的两倍和，
上界控制 Jacobian 的行和变化率。对 $\rho=10^{-60}$、$10^{-80}$
分别验证。该不等式同时给严格自映和严格收缩；由 Neumann 判据
$YDF(z)$ 可逆，故 $Y$ 可逆，固定点也是方程根。两盒嵌套，唯一根相同。
用小盒的有理区间运算继续验证半径平方坐标 $t_*$、正杆权、
圆锚及有向三角形。具体地：

* 13 个活跃中心面以三条杆的公共点覆盖；7 个非活跃中心面用有理外心
  作公共见证，对整个小盒逐个验证距离平方严格小于 $t_*$。
  若一个公共点 $p$ 到三顶点的距离都不超过 $\sqrt{t_*}$，对其凸组合
  $x=\sum_i\lambda_i c_i$ 的加权平方距离和等于
  $\sum_i\lambda_i|p-c_i|^2-|p-x|^2\le t_*$，故至少一个盘包含 $x$。
* 24 个环带三角形用一盘凸性或两个顶点与共同锚点覆盖。
  共 44 面，逐个定向为正并核对内部有向边相消，剩余边界恰是凸
  十二边形。其内部非边界点的绕数为 1，故必在至少一个面内，
  再取闭包得到全部多边形。
* 对每条锚点边，所有其余锚点严格在左侧，锚点顺序就是凸包边界。
  正叉积及正点积保证每段圆弧是前向短弧，圆心在相应正角锥内。
  到圆心的最大距离在弧端点，端点杆长度恰为 $\sqrt{t_*}$，
  故闭圆弓由相应盘覆盖。
* $q_0$ 到所有非相邻圆心的距离严格大于 $\sqrt{t_*}$，
  到两相邻圆心的距离恰为该值。因此这个构型的最小覆盖半径
  **恰为** $\sqrt{t_*}$，而不只是小于等于它。

新鲜输出：`n=17 boxed root and exact full-disk attaining construction: PASS`。
这支付了同一隔离根的存在、全闭盘覆盖和构型紧性；不排除其他
摆法以更小半径覆盖，不能据此声明任意圆心全局最优。

## n=17：原生拓扑普查

```sh
python tools/check_native_n17_census.py --output-directory /tmp/n17-census
```

以本库整数验证的有理上界 $U=0.29853158925642805986984377443$
作为筛选阈值。依照 n=22 的 Voronoi 归约，从严格反例取得非退化的
不可约覆盖及按圆周正序的不同所有者。先保留严格余量做径向投影和
一般位置微扰，再删冗余盘；圆心数少于 17 时只星形细分内部面，
重合的新组合中心沿用该面原有接触见证，不增加边界所有者。
上述限制给出 11、12、13 三个外层顶点数。

令第 $i$ 个锚点为相邻所有者的共同点，角坐标按一整周归一化。
相邻锚点由两根长度至多 $U$ 的杆相连，每个中心邻接边经一个
面见证由两杆相连。两锚点的短向角距因此分别在 2、4、6 杆时
不超过 $\arcsin(mU)/\pi$（$m=1,2,3$）。对应百万分之一周的
安全整数上界为 96497、203666、353250。验证器用 Machin 公式的
交错有理级数下界验证 $\pi>3.1415926535$，再以正弦交错下界
逐个严格验证这些角上界。若前向最大角距小于一周减该短向上界，
则短路径方向必须前向；反向同理；若双方都不可能则剪去。
差分约束无解的分支不可能有真实嵌入，未剪分支不代表存在嵌入。

程序按根边唯一邻面递归剥离：第三顶点在待处理边界上时分裂区域
并遍历内部顶点数分配，否则暴露一个新内部点。每个真实剖分给出
一条这样的路径，已装边始终保持必要条件。对完整剖分遍历整个
外环二面体群的起点和方向，按以根边为起点的面邻接 BFS 标记内部
点；取排序面掩码表的最小值。稳定子给出每轨道的有根质量
$2B/|\mathrm{Stab}|$。比较 DFS/Bellman–Ford 与反序区域选择/
Floyd–Warshall 两路的完整规范对象，不只比较数量。原生源文件为
`cover21/proof_bundle/research-2026/n21-global/peel21.cpp`，
SHA-256 为 `7063d6fbd45786696873b13c5d8b07e657bcdf47c685b0aae8392876373e53d0`。
