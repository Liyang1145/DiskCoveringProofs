# n=19：原生 Voronoi 根面普查

本次用仓库已有的 n=21 剥面枚举器，重算 n=19 任意严格较小覆盖的
候选拓扑列表。两种遍历的规范面表和稳定子逐项相等。这是**全域拓扑
归约**，不是非候选图在连续角域上的排除。

## 任意圆心归约及安全剪枝

在半径 $1/\sqrt{13}$ 处利用假设更小的覆盖留下严格余量。
[径向归一化与一般位置扰动](DISKCOVER_NATIVE_N19_B14.md)把全部
19 个圆心放到盘内并使之互异；不必删除或复制圆心。它也保证每位
正长度边界拥有者只出现一次。若一个胞元接触圆周而无正长度拥有弧，
该接触必须是边与圆相切或三胞点在圆周上的退化，已被扰动排除。
给胞元分割加外部胞后取对偶，三胞点为三角面，两胞相交至多一条
共边，所有者各有一个与外部相邻的弧。去掉外部顶点及其开星，
得到以 $b$ 个拥有者为边界、$19-b$ 个圆心在内的简单圆盘三角剖分。
[B 与 b 的计数](DISKCOVER_NATIVE_N19.md)只允许 $b=12,13,14$。
边界交接点与三胞点分别提供相邻两盘和三个圆盘中的公共见证。
紧致性保证归一化后最大最近距离仍严格小于 $1/\sqrt{13}$。

一周为单位，单个边界拥有弧的角隙小于 $8946/100000$。
两锚点若有至多四或六条见证杆的路径，其弦分别小于
$4/\sqrt{13}$ 或 $6/\sqrt{13}$。对应较短角差分别小于
$18717/100000$ 或 $31284/100000$。参数只参考
[固定版上游书面推导](https://github.com/VonEquinox/DiskCoveringSolve/blob/089584973f41e6374ce110f6e5b5ee456df19352/cover19/docs/r19_proof_zh.md)
的选择；核对器用 Machin 公式和有理 Taylor 下界独立验证三个正弦不等式。
对任一方向，只有当该方向的弧长上界严格小于长弧门槛时才施加
短弧差分约束。只使用已安装的边来建立杆路径，因此任何被差分约束
排除的部分剖分，其全部补全都不可能来自严格反例。

根面第三点或在当前区域边界上，或是一个尚未暴露的内点。前者遍历
所有分割位置以及内点预算分配，后者暴露一个新顶点。真实剖分沿
这两类恰有对应路径；剩余三角面数每步减一。
规范化遍历每条有向外边为起点，覆盖所有二面体边界重标与内部重标。
两种顺序和差分闭包是同一源文件内的交叉核对，不是独立实现。

## 可重放结果

仓库既有源文件 SHA-256：
`7063d6fbd45786696873b13c5d8b07e657bcdf47c685b0aae8392876373e53d0`。

```sh
out=$(mktemp -d)
g++ -O3 -std=c++17 cover21/proof_bundle/research-2026/n21-global/peel21.cpp -o "$out/peel"
for b in 12 13 14; do
  for mode in dfs audit; do
    "$out/peel" 19 "$b" "$out/$mode-$b.json" 100000 8946 18717 31284 0 "$mode" || exit
  done
done
python verification/n19/compare_census.py "$out"
```

十二拥有者的规范面表中，**34 个轨道**包含
[已证明不能严格改善的应力子图](DISKCOVER_NATIVE_N19_CANDIDATE_GRAPH.md)。
核对器不要求整个剖分与格点构型一致：它在两种外环奇偶选择下搜索
六个互异内点的循环，并逐一比对六个见证面。因此这 34 个轨道
不需任何额外连续盒排除。仍有 23,501 个通过此普查而未由该子图排除
的轨道；其中一些可用其它几何剪枝去掉，数目不是最少或最终的剩余量。
