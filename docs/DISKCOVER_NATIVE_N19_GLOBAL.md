# n=19：全局最优性与精确重放

十九个任意摆放的同半径闭盘覆盖闭单位盘的最小半径为
$$r_D(19)=1/\sqrt{13}.$$
证明采用本仓库的裁剪 Voronoi、根面剥离和精确力证书路线。
它是可重放的计算机辅助证明，不是 Lean 形式化。

- **达到性。** [十九个三角格点](DISKCOVER_NATIVE_N19.md)的有理加一个
  平方根核验覆盖全闭盘，给出精确上界 $1/\sqrt{13}$。
- **化约任意圆心。** 若有严格较小半径的覆盖，在严格余量内归一化
  并向一般位置扰动。互异圆心、无退化 Voronoi 图和单段拥有弧是
  证明后的可用归约，不是对原构型的假设。计数把正长度拥有者
  限制在 12、13、14；[原生根面普查](DISKCOVER_NATIVE_N19_CENSUS.md)
  穷尽必要条件允许的 23,535 个规范拓扑，每个有可核对的杆图。
- **连续域。** [原生力证书完整复验](DISKCOVER_NATIVE_N19_FORCE.md)
  将这 23,535 个拓扑逐一关闭。34 个含[格点应力子图](DISKCOVER_NATIVE_N19_CANDIDATE_GRAPH.md)，
  22 个用[七边形应力证书](DISKCOVER_NATIVE_N19_B12_SEPTAGON.md)；
  其余 23,479 个的全角域由 26,676 个精确力终端盒覆盖，
  3,197 次闭二分无遗漏。证书生成允许使用 LP 提议，接受只用
  整数和有理数复验；不依赖上游的图计数、程序、证书或通过记录。

故不存在任意摆放的十九盘严格改进，匹配上述精确达到半径。

```sh
python verification/n19/replay_global.py --workers 4
```

该入口重新编译固定哈希的原生 C++17 枚举器、复查精确构造并
复验仓库自带的全量证书。Python 标准库足够，不需要网络、
SciPy 或另取作者文件。报告仅在所有拓扑及其整角域都通过后
返回全局最优，不把部分枚举、超时或缺件当作排除。
