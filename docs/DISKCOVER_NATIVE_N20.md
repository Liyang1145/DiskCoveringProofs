# n=20：任意圆心的边界盘计数与达到构型核验方案

这是独立的几何归约，不采用外部证书的排除结论。当前只缩小严格下界证明的分支；**不证明全局最优，也未核验候选达到性**。所有计数均针对整个闭单位盘和任意圆心（不假定对称或非退化）。

## 精确可排除分支

设半径 `0 < r ≤ 34/125 = 0.272`，假设 20 个闭圆盘覆盖闭单位盘。令 B 为与单位圆周相交的覆盖盘数，包含只相切的盘，重复盘按给定的 20 个中心计数。下面自包含地证明 **12 ≤ B ≤ 14**，不依赖五盘最优半径的外部定理。

**下界。** 单个盘在单位圆周覆盖的总弧长至多 `2 asin r`。若圆心距原点 d>0，引入以圆心方向为零点的角坐标，覆盖要求
`cos θ ≥ (1+d²−r²)/(2d) ≥ sqrt(1−r²)`，后一式由算术—几何平均不等式得到。d=0 的盘不覆盖圆周。因为 `34/125 < sin(π/11)`，十一条这样的弧不能覆盖整圆。该比较可仅用有理数验证：取 `x = 157/550 < π/11 < π/2`，则 `sin(π/11) > sin x ≥ x−x³/6 > 34/125`。

**剥离内核。** 每个边界盘圆心的范数至少为 `1−r`。因此范数严格小于 `57/125 = 1−2(34/125)` 的点与边界盘的每个圆心距离都严格大于 r。剩余 `20−B` 个闭盘的有限并集是闭集，故必须覆盖半径为 `57/125` 的整个闭盘。放大后，得到由 `20−B` 个半径不超过 `q = 34/57` 的盘覆盖闭单位盘。

**五盘不够。** 假设至多五盘覆盖，允许重复中心并把半径统一增至 q，因此可按五盘算。包含原点的盘至少有一个。若它的圆心距原点为 `0<d≤q`，则
`(1+d²−q²)/(2d) − 1/(2q) = (q−d)(1−q²−qd)/(2dq) ≥ 0`，
因为 `2q²<1`。故该盘的边界弧半角至多 `φ = acos(1/(2q))`；若 d=0 或不与边界相交，弧长为零，也满足此界。其余四盘的每个半角至多 `θ = asin(q)`。因为 `q<1/sqrt(2)`，有 `0<π−4θ<π`，且
`cos(π−4θ) = −1+8q²−8q⁴ < 1/(2q) = cos φ`。
最后一个严格不等式乘以正数 `2·34·57⁴` 后，右减左为
`57⁵+2·34·57⁴−16·34³·57²+16·34⁵ = 3287773 > 0`。
于是 `φ+4θ<π`，总弧长不足 `2π`，矛盾。故内盘至少六个，得到 `B≤14`。
所以在直接按照“与固定单位圆周相交”分类时，只须处理 `(B,20−B)=(12,8),(13,7),(14,6)`。这项剪枝不能不加核对地移植到别的分类：例如 Voronoi 边界所有者和与圆周相交的所有盘并不总相同。

## 达到构型核验：有限极值点

对于一个给定的 20 中心精确构型，可不用拓扑枚举来核验**上界**：

1. 合并重复中心，逐个构造最近中心 Voronoi 单元；它由这些线性不等式组成：`2(c_j−c_i)·x ≤ |c_j|²−|c_i|²`。令单元与闭单位盘相交。
2. 在单元内校验二次距离 `|x−c_i|² ≤ r²`。平直边上的最大值在端点；圆周弧上的最大值在端点或弧内方向 `−c_i/|c_i|`（`c_i = 0` 时为常数）。因此检查落在全部半平面内的两直线交点、直线与圆的交点以及该弧内方向即可。重合直线不算两个独立约束；如果没有直线切割圆周，须单独处理整圆及空集。与圆相切、只有一点或线段的退化单元也须保留。
3. 数值候选只用来挑选分支。实际核验用有理隔离区间和已验证等式判断候选点是否在单元内及距离上界；区间不能判定等号时不得猜测，须提交等式证书或使用精确代数符号判定。不能只检查按图猜出的顶点，也不能用采样替代。

外部候选参考仅为 [固定提交的 n20 README](https://github.com/VonEquinox/DiskCoveringSolve/blob/089584973f41e6374ce110f6e5b5ee456df19352/cover20/README.md)：报告半径约 0.2708481784，精确半径来自 198 变量二次系统。要把该目标纳入本归约，仍须从精确根证书核实其半径小于 34/125；README 小数不是该核验。本次核查了上述有理比较和分支计数逻辑，未运行外部枚举或根验证器。下一步是制作达到构型证书，再对剩余三类的任意摆法完成严格下界。
