# n=20：任意圆心的边界盘计数与达到构型核验方案

这是独立的几何归约，不采用外部证书的排除结论。当前只缩小严格下界证明的分支；**不证明全局最优，也未核验候选达到性**。所有计数均针对整个闭单位盘和任意圆心（不假定对称或非退化）。

## 精确可排除分支

设半径 `0 < r ≤ 271/1000`，假设 20 个闭圆盘覆盖闭单位盘。令 B 为与单位圆周相交的覆盖盘数，包含只相切的盘，重复盘按给定的 20 个中心计数。则：

- 自包含的界是 **12 ≤ B ≤ 15**。
- 再用 Bezdek 的五盘定理给出的 `r_D(5) > 3/5`，得到 **12 ≤ B ≤ 14**。

**下界。** 单个盘在单位圆周覆盖的总弧长至多 `2 asin r`。事实上，若圆心距原点 d>0，引入以圆心方向为零点的角坐标，覆盖要求
`cos θ ≥ (1+d²−r²)/(2d) ≥ sqrt(1−r²)`，后一式由算术—几何平均不等式得到。d=0 的盘不覆盖圆周。因为 `271/1000 < sin(π/11)`，十一条这样的弧不能覆盖整圆。该比较可仅用有理数验证：取 `x = 157/550 < π/11 < π/2`，则 `sin(π/11) > sin x ≥ x−x³/6 > 271/1000`。

**上界。** 每个边界盘圆心的范数至少为 `1−r`。因此范数严格小于 `229/500 = 1−2(271/1000)` 的点与每个边界盘圆心距离都严格大于 r。剩余 `20−B` 个闭盘的有限并集是闭集，故必须覆盖半径为 `229/500` 的整个闭盘。按比例放大得到
`r_D(20−B) ≤ 271/458`（若 `20−B=0`，覆盖直接不可能）。
四盘定理 `r_D(4)=1/sqrt(2)` 可由上述弧长下界和位于 `(±1/2,±1/2)` 的四中心构型得出：单位盘每个象限中的点到其对应中心距离至多 `1/sqrt(2)`。由于 `2·271² < 458²`，至多四个内盘不够。若使用 [Bezdek 的五盘定理](https://gdz.sub.uni-goettingen.de/download/pdf/PPN301416052_0014/PPN301416052_0014.pdf) 的精确结论（论文使用单位半径覆盖盘；换为单位目标盘后取目标半径倒数），则 `271/458 < 3/5 < r_D(5)`，五个也不够。这里没有将一个四舍五入的半径当作下界。

所以在直接按照“与固定单位圆周相交”分类时，只须处理 `(B,20−B)=(12,8),(13,7),(14,6)`。这项剪枝不能不加核对地移植到别的分类：例如 Voronoi 边界所有者和与圆周相交的所有盘并不总相同。

## 达到构型核验：有限极值点

对于一个给定的 20 中心精确构型，可不用拓扑枚举来核验**上界**：

1. 合并重复中心，逐个构造最近中心 Voronoi 单元；它由这些线性不等式组成：`2(c_j−c_i)·x ≤ |c_j|²−|c_i|²`。令单元与闭单位盘相交。
2. 在单元内校验二次距离 `|x−c_i|² ≤ r²`。平直边上的最大值在端点；圆周弧上的最大值在端点或弧内方向 `−c_i/|c_i|`（`c_i = 0` 时为常数）。因此检查落在全部半平面内的两直线交点、直线与圆的交点以及该弧内方向即可。重合直线不算两个独立约束；如果没有直线切割圆周，须单独处理整圆及空集。与圆相切、只有一点或线段的退化单元也须保留。
3. 数值候选只用来挑选分支。实际核验用有理隔离区间和已验证等式判断候选点是否在单元内及距离上界；区间不能判定等号时不得猜测，须提交等式证书或使用精确代数符号判定。不能只检查按图猜出的顶点，也不能用采样替代。

外部候选参考仅为 [固定提交的 n20 README](https://github.com/VonEquinox/DiskCoveringSolve/blob/089584973f41e6374ce110f6e5b5ee456df19352/cover20/README.md)：报告半径约 0.2708481784，精确半径来自 198 变量二次系统。要把该目标纳入本归约，仍须从精确根证书核实其半径小于 271/1000；README 小数不是该核验。本次核查了上述两个有理比较和分支计数逻辑，未运行外部枚举或根验证器。下一步是制作达到构型证书，再对剩余三类的任意摆法完成严格下界。
