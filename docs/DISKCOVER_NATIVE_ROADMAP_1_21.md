# n<22 独立全局证明的验收清单

目标：对每个 n=1–21 给出同一个精确半径、覆盖整个闭单位盘的达到构型，以及排除任意圆心更小半径的证明。外部作者的构型与数值只用于选候选，不把其通过记录当作本仓库的证明。未通过全部验收条件的阶数不进入严格求解模式。

| 阶数 | 当前走到哪里 | 下一项可以独立核验的工作 |
|---|---|---|
| 1–4、7–10 | 自包含证明及达到构型已接入严格模式；[n10](DISKCOVER_CLASSICAL_N10.md) 的数值比较用有理区间复验 | 保持退出码和未覆盖阶数的拒绝测试 |
| 5–6 | 有已发表的精确定理，严格模式尚不接受 | 单独核对并整理解析证明及构型 |
| 11 | 有全局源证明；Lean 的加权弧、C450 恒等式及内圆弧归约已复验 | 固定 Lean 4.33.1，复用已编译依赖，按独立目标检查 C450 归一化桥接及源段；其余能量、分类与最终定理另计 |
| 12 | 仓库有独立全局源证明和有限复验记录 | 在求解器中绑定同一个候选根、达到证明与全局排除 |
| 13 | [边界盘数缩到 9–12](DISKCOVER_NATIVE_N13.md) | 从固定代数候选生成新的闭盘达到性证书；分别排除四种接触盘预算 |
| 14、21 | 有仓库全局源证明，未做本轮完整复验 | 按各阶冻结文档接通可重复核验入口 |
| 15–16 | [边界数缩到 10–12、11–12](DISKCOVER_NATIVE_N15_N16.md) | n15 的 12 拥有者分支利用已验证的角度/径向限制枚举剩余类型 |
| 17–18 | [边界盘数均缩到 11–13](DISKCOVER_NATIVE_N17.md) | 区别接触盘和 Voronoi 拥有者，证明对所有组合分支的无损归约 |
| 19 | [精确达到上界与 12–14 边界盘归约](DISKCOVER_NATIVE_N19.md)；[14 拥有者精确剪枝](DISKCOVER_NATIVE_N19_B14.md) | 在 12–14 分支分别建立完备的组合归约、区间排除或精确局部证书 |
| 20 | [已验证有理上界；半径 ≤ 0.272 时仅 12–14 个边界盘](DISKCOVER_NATIVE_N20.md) | 精确重建候选、统一边界标签，再逐分支核验下界 |

验收顺序：候选的精确对象和隔离盒；覆盖整个闭盘（非采样）；任意圆心、退化与严格余量的归约；完整的分支目录和每个分支可复核的排除；匹配上下界。望见某个候选、程序成功退出、命中缓存或单个局部分支通过，均不能代替其中其余环节。
