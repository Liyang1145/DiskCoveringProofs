# 单位闭圆盘覆盖：n = 1–22 的统一入口

```sh
python tools/solve_diskcover.py --all
python tools/solve_diskcover.py 22
python tools/solve_diskcover.py 4 --require-global-proof
python tools/solve_diskcover.py 13 --require-global-proof
python tools/solve_diskcover.py 19 --require-global-proof --offline --proof-workers 4
python tools/solve_diskcover.py 17 --grid 5 --max-nodes 20000
python -m unittest discover -s tools -p 'test_diskcover*.py'
```

默认输出归档来源与核验范围，**不表示重新证明**。经典定理、本仓库源证明、外部作者的全局最优性声明分开记录；带小数点的半径只是显示值。附加 `--grid` 才会重新计算有证明保证的连续上下界。离散最优值不是连续最优值。此入口不会运行外部执行器、修改冻结证书或把近似结果标记为精确解。

`--require-global-proof` 仅在有精确达到构型及任意圆心下界的阶数
输出全局精确解。当前支持 **n=1–4、7–10、13、16–19**。其余阶返回
退出码 2，不输出近似值作为解。n=10 的[书面证明和有理检查](DISKCOVER_CLASSICAL_N10.md)
仍由严格模式提供。

## 五个新阶的全量精确复验

n=13、16、17、18、19 的严格模式会**现场执行**对应证明入口，
重新检查同根达到构型、任意圆心归约后的完整图域与每个精确证书。
成功时标准输出才有单个 JSON 对象；运行进度送到标准错误。
半径及圆心以精确公式或同一个隔离代数根的坐标索引表示，
不是把小数当作精确圆心。输入缺失、散列不符、编译失败或
任何证明检查失败时返回非零，绝不倒退到目录或上界冒充答案。

- 需要 Python 3.10+ 和 C++17 编译器 `g++`。接受路径不需要 SciPy
  或 Lean。完整复验可能花几分钟，依赖机器速度与阶数。
- n=13 和 19 不需要下载。n=16、17、18 首次可从固定公开提交获取
  **数字见证数据**，不下载或执行上游代码，并逐文件验证 SHA-256。
- 数据默认放在仓库 `build/proof-data/`，可用 `--proof-data-dir DIR`
  指定位置。下载后可加 `--offline` 复验；该选项绝不联网，
  缺件即拒绝。仍每次复验，不缓存旧通过状态。
- `--proof-workers 1–6` 设置支持多进程证明的并发上限，默认 4。

这些模式重放已经构造的证明，不是任意阶的自动发现程序。
各阶的几何说明、数据来源及可独立复验入口见[验收清单](DISKCOVER_NATIVE_ROADMAP_1_21.md)。

## 小阶全局证明（n = 1, 2, 3, 4）

记目标盘为单位闭圆盘。对 n = 1，两个相对的边界点相距 2，所以覆盖盘的半径至少为 1，圆心取原点即可达到。

对 n ≥ 2，先排除半径已经不小于 1 的平凡情形。一个半径为 r < 1 的盘与单位圆相交时只能覆盖一个短弧：若圆心到原点距离为 d > 0，交弧上的单位向量 x 满足 x 与圆心方向的夹角余弦至少为 (1 + d² − r²)/(2d) > 0；若 d = 0，则没有交弧。弧的半角记为 θ，其端点的半弦长 sin θ ≤ r，且 θ < π/2，故弧长至多为 2 arcsin r。因此覆盖单位圆至少要求 n·arcsin r ≥ π，即 r ≥ sin(π/n)。

对 n = 2, 3, 4，取 α = π/n，在 n 个等分射线上、离原点 cos α 处放置圆心。对扇区内任意点，其极径 s ∈ [0,1]，与射线夹角的绝对值 β ≤ α。点到对应圆心距离的平方为 s² + cos²α − 2s cosα cosβ，是 s 的凸函数，最大值不超过两端的较大值。s = 0 时为 cos²α；s = 1 时至多为 sin²α。因为 α ≥ π/4，所得半径不超过 sin α，刚好达到下界。因此 r_D(2) = 1，r_D(3) = √3/2，r_D(4) = 1/√2。

## 七盘全局证明（n = 7）

若半径 r < 1/2，覆盖原点的盘上每个点离原点至多 2r < 1，所以此盘不覆盖单位圆周。按前节的足迹界，其余六盘各覆盖严格小于 π/3 的弧，和严格小于 2π，矛盾。

取半径 1/2、一个圆心在原点，另六个圆心沿等分射线距原点 √3/2。极径 s ≤ 1/2 的点由原点盘覆盖。在 1/2 ≤ s ≤ 1 时，与最近射线的夹角至多 π/6，点到对应外圆心的距离平方至多 s² + 3/4 − 3s/2。该凸函数在两端均为 1/4，故整个单位闭盘被覆盖，两界相合。

## 离散求解为何给连续区间

令 S_k 为单位盘内所有坐标为 1/k 的整数倍的点。把盘内任意点的每个坐标向零截断到最近的格点；绝对值不会增大，格点仍在盘内，总距离不超过 δ = √2/k。可先把任何盘外圆心径向投影到闭盘：若圆心为 tu，t > 1、||u|| = 1，对任意目标点 x，投影前后的距离平方之差为 (t−1)(t+1−2⟨x,u⟩) ≥ 0。

使用 S_k 同时作目标和候选圆心。若有限问题的最优覆盖半径为 q，连续解的圆心投影再截断，在有限目标集上最多增加 δ，所以 q ≤ r_D(n)+δ；反过来，原盘上的每个点都离有限目标集至多 δ，任意有限全覆盖的构型按三角不等式扩大 δ 后也覆盖整个连续盘。因此 |q−r_D(n)| ≤ δ。

有限阈值只需检查点对距离的平方，使用整数比较。预算用完时仍只以已证不可行的阈值和已核验的构型给出保守边界，不能把未决阈值当作不可行。平方根向外取有理界，输出的连续区间因此不依赖浮点四舍五入。逐步加密网格并完成对应的有限搜索能使理论误差收敛，但高阶、高分辨率的穷举可能不实用。此方法**不是**对高阶精确最优半径的有限终止证明。
