# n=23、24：严格反例运输及完整根面剥离的书面源审查

本稿是新文件，不改历史已绑定源码、证明或活作业。它证明下面的
数学接口；不以本稿的存在、目录清零或程序成功退出宣称全局最优。
实际目录与其生成二进制、启动、全并集、下界账本的当前绑定，
以及同根上界和非严格核心的最后合成，仍须另行逐项接受。

## 1. 对象及严格余量

D 为单位闭盘。阶数 N∈{23,24}，R 为该阶已隔离精确根的半径，
U 为其自己的已验证有理上界：

    U23=249953776586051/10^15
    U24=61325412542131/250000000000000.

本阶预算报告给出 R<U<1/4。反设至多 N 个任意平面圆心的
r 盘覆盖 D，其中 r<R。选 r<ρ<R；以下操作只使用严格余量。

将盘外圆心 c=t u（t>1，|u|=1）投影到 u。对 x∈D，

    |x−tu|²−|x−u|²=(t−1)(t+1−2x·u)≥0.

投影不增距离。把所有圆心微扰到 D 的内部，位移小于 ρ−r；
三角不等式保持 ρ 覆盖。可同时避开重复中心、三中心共线、
四中心共圆、圆周切触、Voronoi 三重顶点落在圆周等有限代数
坏条件：每个是非恒零多项式的零集，其有限并无内点。
这里用相同半径的普通最近点 Voronoi 胞腔，不用加权胞腔。

删除冗余盘直到不可约。余 m≤N，每盘有不在其他闭盘中的
私有点 p：|p−c|≤ρ，而所有其他中心距离严格大于ρ。
所以 p 严格最近于 c；相交 D 的胞腔满维、闭、凸。最近点
胞腔的每一点都属于所属 ρ 盘，因为 D 已被这些盘覆盖。
一般位置对子集仍成立。私有点可以在圆周，不要求它在 D 内部。

## 2. 不返回引理：不可约性不可省略

半径ρ<1 的盘在单位圆上的足迹若非空，只有一个长度小于π
的闭短弧。设某胞腔 C 的圆周严格所有权有两个分离的非空
开弧。在同一短足迹中选分别严格属于 C 的 a,b；取两者间的
短弧，使其中含别的胞腔 T 的严格所有权点 x。

距离平方差对位置是仿射函数。故线段 [a,b] 的每一点仍严格
最近于 C。令 H 为短弧 a→b 和弦 [a,b] 围成的闭圆弓。
足迹短弧包含两端就包含整个短弧；H 是其凸包，故 H 包含于
C 的覆盖盘。若 T 有 y∉H，则 [x,y]⊂T（T 凸）在弦上相交。
交点位于 [a,b]，与那里严格属于 C 矛盾。圆周端点也严格属 C，
故没有绕端点的例外。于是 T⊂H。T 的私有点也在 H 内，被 C
的盘覆盖，违反不可约。因此每个圆周胞腔的所有权不返回。

这不声称任意未删冗余的 Voronoi 图都有不返回性质。

## 3. 简单盘三角剖分与辅助杆

令 B 为圆周所有权胞腔数，I=m−B。各所有权弧由不同胞腔
连续且恰一次组成。已接受本阶预算证明给出

    B≥13，I≥8，故 N23:B∈{13,14,15}；
                     N24:B∈{13,14,15,16}.

预算的 I≥8 只用如下自包含事实：边界中心模长≥1−ρ，
其盘不碰 |x|<1−2ρ；内部盘覆盖核心闭包，缩放半径
q=ρ/(1−2ρ)<1/2。七个 q 盘不能覆盖单位盘：覆盖原点的一盘
不碰圆周，其余至多六盘各圆周足迹长<π/3。
具体 R、U 和正弦间隙由本阶预算接受报告支付，不能借另一阶。

在球面补外胞腔。两个内胞腔的公共直边是凸集合，至多一条；
不返回保证外胞腔与任一边界胞腔至多一条边。一般位置的内部
顶点有三个胞腔；圆周交接点有两个内胞腔和外胞腔。内部胞腔
为满维有界多边形，至少三边。边界胞腔若仅一条内边，其邻
胞腔在两侧都拥有圆周，违反不返回，除非 B=2，而 B≥13。
因此每胞腔至少三边，胞腔对偶为简单球面三角剖分。
删外顶点的开星留下简单拓扑盘三角剖分，边界为 B 循环。

每个中心面取其内部 Voronoi 三重顶点为共同见证；每个边界
边取对应圆周交接点 q_i 为两中心共同锚点。杆长均≤ρ。
不要求中心连线提供平面嵌入；嵌入是胞腔对偶的拓扑嵌入。

若 m<N，在任何中心面作抽象星形细分；新组合中心的几何
位置复制该面一个旧中心，三个新面复用旧见证。反复补至 N。
组合剖分仍简单、边界 B 不变；新增几何退化是允许的，因为
所有杆不等式仍成立。故少盘、重复和原退化反例都运输到
恰 N 个组合中心、2N−B−2 个中心面的必要辅助图。

## 4. 对实际完整剥离递归的归纳

审查对象是 round3-high/peel_degree.cpp 的 visit/possible/canonical
及其完整搜索 stage 派生体；不是 n25 的提前省略 collar 集。
状态中的待补区域有简单循环边界 K 及未暴露内部预算 J。
完成后的面数为 F(K,J)=2J+K−2；K=2,J=0 表示空区域。
初态边界 0,…,B−1，J=N−B，已加入全部边界边。

任取真实完整剖分，选程序所取待补区域的有向根边(a,c)。
其唯一根面第三点 w 只有两种情况。

* w 在当前边界：程序逐一枚举下标 k=2,…,K−1。删除根面后，
  两侧边界分别是 [w,c,…,w前驱] 与 [a,w,…,a前驱]；两区域
  只共享 w，分别沿不同切边邻接根面，并非共享同一条分割边。
  未暴露内部点分属两侧，J_left+J_right=J。程序枚举全部
  0≤J_left≤J，并只禁止给空二边区域分配内部点。
  原非边界的(a,w)/(c,w)若已经使用，再加会造成重复边或
  与已剥离区域冲突；真正简单剖分不会落入此禁止分支。
* w 尚为内部：赋予 next 的首次暴露标签，只作内部重标号。
  删除根面后边界为[a,w,c,…]，预算变为 J−1。
  程序保留该分支，加入两新边。没有第三种情况：已暴露而
  不在该区域边界的点不属于其闭包，不能是它的根面第三点。

第一种两子区域的总未付面数为 F(K,J)−1；第二种
F(K+1,J−1)=F(K,J)−1。故以待补面数归纳终止且穷尽每个
真实简单盘剖分，内部首次暴露重标号不会漏同构类型。
状态数组上界 N≤25、F≤47 对这些阶足够；溢出与节点限额
是失败，不能充当目录完成。

## 5. 剪枝为什么不排掉真实实现

选边界二面体标号中让 0 号中心最终度最小的一种。
不在任何待补区域边界的原边界中心，其所有边已最终确定；
0 号当前度仅是其最终度下界。如果它大于某已终结中心度，
该标号不可能是上述最小度代表。因此这一剪枝至少保留一个
标号，不要求未知几何具有对称性。

每边界锚点 q_i 连到中心 i 与(i+1) mod B。相邻锚点间两杆
路径给短弦≤2ρ；中心图一边有三杆面见证的两杆替代路径，
所以代码 one/two 的中心图距离1/2分别给锚点间四/六杆路径。
由本阶有理正弦验证得到自身二/四/六杆帽。只是图距离，
不是中心连线长度或共线假设。

所有权弧角隙非负，总和一周，相邻角隙至多二杆帽A。
对 j−i=k，前向弧≤kA，后向弧≤(B−k)A；短弦约束的
两个可能分支是前向角≤C，或前向角≥1−C。
只有 kA<1−C 时才强迫前向≤C；反向同理。两方向都被
强迫时，与总和一周矛盾；都不被强迫时代码不添方向约束。
必要差分约束全为整数帽/整数周尺度 D。真实实数解乘 D
后取 floor，仍满足 x_v−x_u≤整数常数。故整数负环判定
不能误删真实解；不需在枚举入口把真实角量化成锚点采样。

完整 stage 若调用 already_paid，每次成功返回前都会递增
proof_prunes。实际记录 proof_prunes=0 的运行没有此类删枝。
这个事实须由各实际 stage 绑定核验，不能推论其他运行也为零。

## 6. 完整终态规范化与运输

canonical 检查全部标签使用、每个边界边恰一面、每个内部边
恰两面、Euler 特征、全部顶点 link 为所需连通路径/循环，
以及面双邻接连通。取全部2B边界循环/反射根中的最小度轮廓，
保留所有达到该轮廓的根；对每根，内部标签按固定面双图 BFS
首次暴露规则唯一生成。两同构嵌入选择对应根得到相同遍历；
同一根不需额外穷举内部排列。完整排序面数组比较，不以哈希
无碰撞假设替代同构判定。稳定子数不是下界支付。

实际实现限制到外露/两边界面子图仍合法。严格力树必须在它
自己的全部必要连续角域接受；删面扩大自由域，不能借强图树。
源→目标映射须逐中心单射、逐杆及逐面核验。边界正向
i→shift+i 时锚点同式；反向中心 i→shift−i 时，锚点
q_i→q_(shift−i−1)。旋转固定 q_0=(1,0) 只是坐标规范。

严格力叶给 W≤rS，精确有理验收 W/S>U，因此排除ρ<R<U。
B15达到核心则需该阶完整同根非严格定理；不能以外露面身份
或近似半径替代完整核心的对应图/域/端点运输。
