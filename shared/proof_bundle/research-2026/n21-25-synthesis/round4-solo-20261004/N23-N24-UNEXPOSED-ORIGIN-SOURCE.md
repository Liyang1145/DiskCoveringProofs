# n=23、24 的原点圆心未外露必要条件

本结论是实际单位闭盘覆盖的必要条件，不是任意弱图几何
不可实现声明，也不是任何完整竞争家族已经支付的声明。
它不调用 n=25 的最优性、数值诊断或对称构型假设。

## 适用前提

固定 N 为23或24。至多 N 个任意平面圆心的半径 ρ 盘覆盖单位
闭盘，且 ρ≤U<1/4。按严格余量、一般位置、删冗余和普通最近
胞腔归约，得到原边界圆心及单位圆交接锚点。每个边界圆心 b
至少有单位圆锚点 q 满足 |q-b|≤ρ；每个中心面有公共见证 w，
到其三个圆心的杆均≤ρ。这是覆盖到辅助图的独立源接口前提。

原 N25-COLLAR-COVER-INTERFACE 的投影、严格余量、私有点、
不返回和胞腔对偶剥离论证本身不使用数25。若删冗余后 m<N，
可在一个中心面作星形细分，新中心几何复制该面一个旧中心，
三新面复用原见证。重复至恰 N 个组合标签。旧盘及原点覆盖
不被删除；组合剖分简单，几何中心不必互异。此处只推广这些
定性步骤，不能把 n25 的边界数、角帽、力树或核心下界搬到
n23、n24。各阶完整必要家族及最终归约仍须分别验收。

## 距离论证

边界圆心有 |b|≥1-ρ。若圆心 c 出现在含边界圆心 b 的中心面，
公共见证给出 |c-b|≤2ρ，因而 |c|≥1-3ρ。
边界圆心也满足这个较弱下界。因此任一外露圆心均有

    |c| ≥ 1-3ρ > ρ.

它的 ρ 盘不含原点，而原点必须被某个保留盘覆盖。因此 N 个
标签中至少一个不属于任何含原边界中心的面；外露标签数 V≤N-1。
该结论允许圆心重复、中心边的直线画法相交和退化见证。

纯内部面不得计作外露面。若读取完整三角盘，必须仅对含原
B 个边界标签的面取圆心并集；全部 B 个边界标签还带2B根锚杆。
若读取已压缩外露面图，不能只信声明的centers=N，而必须检查
真实保留面及隐含边界标签的并集确实包含全部 N 个标签。

若只有一个未外露标签 h，外露盘遗漏开盘 |x|<1-4ρ。
h 的盘须覆盖此开盘及其闭包，故 |h|≤5ρ-1≤5U-1。
本轮没有把这条非均匀原点杆约束接入力内核。

## 本地两阶常数与严格间隙

只使用本阶冻结的 constants/n23.json 与 constants/n24.json：

- U23=249953776586051/10^15，1-4U23>0，故 V≤22。
- U24=61325412542131/250000000000000，1-4U24>0，故 V≤23。

若 U=1/4，局部共线链 q=1,b=3/4,w=1/2,c=1/4 的四段长度
全为1/4，c的盘恰能触及原点。本接受接口必须拒绝在该等号
或更大阈值上使用上述统一严格排除。V<N只表示未被这一必要
条件排除，绝不表示存在覆盖或该图已经支付。

本条件只能在所有来源、完整性、圆心/锚点映射和本阶常数均
绑定后加入实际覆盖竞争族账本；发现集或有限图不得冒称全族。
